45.7 Exchange-coupling example

From here on, using the actual input examples stored in the directory work, we show concretely the procedure from the SCF calculation to the execution of jx.

As an example of a cluster calculation, run a normal OpenMX calculation as follows using the input file Fe_Cluster_jx.dat stored in the directory work.

     % mpirun -np 2 ./openmx Fe_Cluster_jx.dat

The input file Fe_Cluster_jx.dat is for the SCF calculation of an Fe dimer. If this calculation finishes normally, the scfout file Fe_Cluster_jx.scfout is generated. Next, run the jx calculation as follows.

     % ./jx Fe_Cluster_jx.scfout Fe_Cluster_jx.config

Here, Fe_Cluster_jx.config is stored in the directory work. Then, the following message is printed to the standard output.

As an example of a bulk calculation, run a normal OpenMX calculation as follows using the input file Fe_Bulk_jx.dat stored in the directory work.

     % mpirun -np 28 ./openmx Fe_Bulk_jx.dat

The input file Fe_Bulk_jx.dat is for the SCF calculation of Fe (bcc structure). If this calculation finishes normally, the scfout file Fe_Bulk_jx.scfout is generated. Next, run the jx calculation as follows.

     % mpirun -np 84 ./jx Fe_Bulk_jx.scfout Fe_Bulk_jx.config | tee jx.log

Here, Fe_Bulk_jx.config is stored in the directory work. Then, the following message is displayed on the screen.

Figure 43(a) shows the exchange coupling constant J of Fe (bcc structure) obtained in the calculation, plotted as a function of distance. Similarly, (b) shows the result for Co in the hcp structure, (c) for Ni in the fcc structure, and (d) for the Fe dimer. In these calculations, A6.0H-s2p2d2 (where A = Fe, Ni, Co) was used as the basis-function set, and GGA-PBE was used as the exchange-correlation functional. In addition, a ferromagnetic spin configuration was assumed. The input files used in the calculations are Fe_Bulk_jx.(dat,config), Co_Bulk_jx.(dat,config), Ni_Bulk_jx.(dat,config), and Fe_Cluster_jx.(dat,config). These input files are stored in the directory work, so the same calculations can be performed. For details of the calculations, refer to Ref. [20].

Using the obtained exchange coupling constants, it is also possible to calculate the Curie temperature of a periodic system within the framework of the mean-field approximation. The Curie temperature TC of a general periodic system is obtained as the maximum eigenvalue of the following eigenvalue equation.

T⁢⟨s→i⟩z = 23⁢kB⁢∑jJ~i⁢j⁢⟨s→j⟩z (48)
J~i⁢j ≡ Ji⁢j−Ji⁢𝟎,j⁢𝟎⁢δi⁢j. (49)

Here, the definitions of Ji⁢j and Ji⁢𝟎,j⁢𝟎 are given in Eqs. (47) and (44), respectively. Table 9 shows the Curie temperatures calculated from Eq. (48) for bcc Fe, hcp Co, and fcc Ni, along with the experimental values.
