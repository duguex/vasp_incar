35.3 Electrostatic potential fitting

For small molecular systems, the electrostatic potential (ESP) fitting method [120, 121, 122] is widely used to determine effective charges. In many cases, the obtained results are consistent with chemical intuition. However, in the ESP fitting method, there are not enough sampling points for atoms far from the surface, and therefore it cannot be applied to very large molecules or bulk systems. In the ESP fitting method, effective point charges are determined by a least-squares procedure so as to reproduce, as closely as possible, the electrostatic potential obtained from the DFT calculation. ESP fitting charges are calculated in the following two steps.
(1) SCF calculation
After a normal SCF calculation, the following two files are output.

    System.Name.out
    System.Name.vhart.cube

No additional keyword is required to generate these two files. These files are ordinary output files from a standard SCF calculation, but the keyword level.of.fileout must be set to 1 or 2.
(2) ESP fitting charges
Compile the program code for calculating ESP fitting charges. Move to the directory work and compile it as follows.

    % make esp

If the compilation finishes successfully, the executable file esp is generated in the directory work. ESP fitting charges are calculated by the program esp from the two files System.Name.out and System.Name.vhart.cube. For example, for the methane molecule shown in Section 5, the ESP fitting charges are calculated as follows.

    % ./esp met -c 0 -s 1.4 2.0

It is sufficient to specify only the file name without an extension, but the two files met.out and met.vhart.cube must be stored in the work directory. The options -c and -s are parameters specifying the constraint condition and the scale factor, respectively. The following explanation is written in the header part of the source code esp.c.

   -c      constraint parameter
           ’-c 0’ means charge conservation
           ’-c 1’ means charge and dipole moment conservation
   -s      scale factors for vdw radius
           ’-s 1.4 2.0’ means that 1.4 and 2.0 are 1st and 2nd scale factors

In the ESP fitting method, fitting is performed under two types of constraints: charge conservation, and charge plus dipole-moment conservation. The latter can reproduce the charge and dipole moment obtained from the DFT calculation, but when the dipole-moment conservation condition is imposed, physically unacceptable point charges may be obtained, especially for large molecules. Therefore, the former constraint is recommended. As sampling points, real-space grid points in the region sandwiched between two shell structures are selected. The shell structures are defined as the union of spheres assigned to each atom. The radii of the spheres are given by the first and second scale factors specified after -s multiplied by the van der Waals radii [123].
