47.1.1 PAO guiding functions

OpenMX Ver. 4.0 can generate Closest Wannier Functions (CWFs)[133]. As guiding functions, PAOs (pseudoatomic orbitals), hybrid orbitals, and molecular-like orbitals can be selected. In addition, by using a window function, CWFs can be generated with emphasis on a specific energy region. Since the resulting tight-binding model has a smaller dimension than the Hamiltonian expressed in PAOs, the computational cost of diagonalization is reduced, and physical quantities can be calculated while taking many k points into account. This approach is known as Wannier interpolation, and is useful for calculating physical quantities that require many k points for convergence.

First, let us perform a CWF calculation for GaAs using PAOs as the guiding functions. Run the calculation using the input file GaAs-CWF1.dat in the work directory.

     % mpirun -np 8 openmx GaAs-CWF1.dat | tee GaAs-CWF1.std

If the calculation finishes normally, GaAs-CWF1.Band and GaAs-CWF1.CWF.Band are output. By following the procedure in Sec. 22, “Band dispersion”, the band dispersion shown in Fig. 52(a) is obtained. It can be seen that the Wannier-interpolated bands reproduce the original bands well. The minimized distance measure function F (a dimensionless quantity) is written in the out file, and in this calculation it is F=0.16 (per CWF). From the magnitude of this value, one can judge how much the CWFs are deformed from the guiding functions. From a relative comparison, F=0.16 can be regarded as sufficiently small, whereas when F exceeds 0.7 it suggests that the chosen guiding functions deviate significantly from the symmetry of the Bloch functions. The obtained CWFs are shown in Fig. 52(d). They retain well the shape of the atomic-like orbitals of the PAOs used as guiding functions, confirming the closest property. In addition, Fig. 52(c) shows the tight-binding parameter t calculated from the CWFs as a function of distance. Since t is short ranged, the locality of the CWFs is confirmed. Although the CWFs are constructed based on the closest principle, and no localization principle is imposed, the guiding functions themselves are localized, and as a result the CWFs are localized in real space. This figure was obtained by plotting GaAs-CWF1.CWF.Dis_vs_H.


In this calculation, the basis functions were specified as follows.

   <Definition.of.Atomic.Species
     Ga   Ga7.0-s3p2d2f1   Ga_PBE19
     As   As7.0-s3p2d2f1   As_PBE19
   Definition.of.Atomic.Species>

The following keywords related to CWFs were then specified.

   CWF.Calc                 on
   CWF.Wannier90.fileout    off
   CWF.Dis.vs.H             on
   CWF.Guiding.Orbitals     AO

   <CWF.Guiding.AOs
    Ga  1s 1 2s 0 3s 0 1p 1 2p 0 1d 1 2d 0 1f 0
    As  1s 1 2s 0 3s 0 1p 1 2p 0 1d 1 2d 0 1f 0
   CWF.Guiding.AOs>

   CWF.window.function               Poly
   CWF.disentangling.Erange      -45.0 -43.0 1.0 10.0

   CWF.fileout.flag         on
   CWF.Plot.SuperCells    1 1 1
   CWF.fileout.Num           2
   <CWF.fileout.cube
    1
    2
   CWF.fileout.cube>
 

The meaning of each keyword is explained below.

CWF.Calc
Set to on when performing a CWF calculation. The default value is off.

CWF.Wannier90.fileout
Set to on to output interface files for Wannier90. The default value is off. When it is set to on, the mmn, amn, eig, and win files are output. See Sec. 47.1.10 for the interface.

CWF.Dis.vs.H
Set to on to output the Hamiltonian in text format. The default value is off. The output file has the extension CWF.Dis_vs_H. The information for each column is described in the header of the file as follows.

   #
   # spin, GA, GB, l1, l2, l3, i, j, distance (Ang.), Hopping integral (eV)
   #
    0  1  1 -6 -6 -6  0  0  58.716522376584940 -0.000022195182447
    0  1  1 -6 -6 -6  0  1  58.716522376584940  0.000002501704500
    0  1  1 -6 -6 -6  0  2  58.716522376584940  0.000002501704188
    ...
    ..

This means that spin, GA, GB, l1, l2, l3, i, j, distance (Ang.), and Hopping integral (eV) are stored in the following format.

  • •

    1st column: spin index (0 or 1)

  • •

    2nd column: serial number of atom

  • •

    3rd column: serial number of atom

  • •

    4th column: l1×𝐚1 (where 𝐚1 is the lattice vector 𝐚1)

  • •

    5th column: l2×𝐚2 (where 𝐚2 is the lattice vector 𝐚2)

  • •

    6th column: l3×𝐚3 (where 𝐚3 is the lattice vector 𝐚3)

  • •

    7th column: CWF index

  • •

    8th column: CWF index

  • •

    9th column: center-to-center distance between two CWFs

  • •

    10th column: hopping integral (eV)

For example, from the following line in the data part,

   0  1  1  0  0  0  0  0   0.000000000000000 -7.038661143545355

it can be seen that the on-site energy of the s-like CWF on atom 1 (a Ga atom) is about -7.039 eV. The above format is for collinear calculations. Note that in non-collinear calculations there is no spin-index column.

CWF.Guiding.Orbitals
Select the guiding functions from AO (atomic-like orbitals, PAOs), HO (hybrid orbitals), and MO (molecular-like orbitals). For AO and HO, the keyword CWF.Guiding.AOs is used to select guiding functions from the PAOs. For MO, the keywords CWF.MO.Selection and CWF.MO.Grouped.Atoms are used. They are explained in Sec. 47.1.4.

CWF.Guiding.AOs
When AO or HO guiding functions are selected by the keyword CWF.Guiding.Orbitals, this keyword is used to select the guiding functions from the PAOs. In GaAs-CWF1.dat, it is set as follows.

   <CWF.Guiding.AOs
    Ga  1s 1 2s 0 3s 0 1p 1 2p 0 1d 1 2d 0 1f 0
    As  1s 1 2s 0 3s 0 1p 1 2p 0 1d 1 2d 0 1f 0
   CWF.Guiding.AOs>

1 means included and 0 means not included. Corresponding to the basis functions specified by the keyword Definition.of.Atomic.Species, all entries must be explicitly given as either 0 or 1. In the above example, all occupied-state orbitals included in the pseudopotentials are selected. Namely, they are the Ga-3⁢d, Ga-4⁢s, Ga-4⁢p, As-3⁢d, As-4⁢s, and As-4⁢p orbitals.

CWF.window.function
As the window function w, the polynomial window function wP and the Fermi window function wF are available. This keyword specifies the window function w. The polynomial window function wP is specified by Poly, and the Fermi window function wF by Fermi. When calculating the projection matrix A from the guiding functions Q, the Bloch functions are weighted by the window function w[133]. The matrix element a of A is calculated by

a𝐤⁢μ,p=w⁢(ε𝐤⁢μ)⁢⟨ϕ𝐤⁢μ|Q𝟎⁢p⟩, (50)

The polynomial window function wP is defined by

wP⁢(ε)={0(ε≤ε0),∑i=04ci⁢x0i(ε0<ε≤ε1),1(ε1<ε≤ε2),∑i=04ci⁢x1i(ε2<ε≤ε3),0(ε3<ε)., (56)

where c0=1, c1=0, c2=−6, c3=8, and c4=−3, and x0=ε1−ε+με1−ε0, x1=ε2−ε+με2−ε3. The set {c} is determined so that the value is 1 and the first derivative is 0 at x0,1=0, and the value is 0 and the first and second derivatives are 0 at x0,1=1.

On the other hand, the Fermi window function wF is defined by

wF⁢(ε)=1(1+exp⁡(x0))⁢(1+exp⁡(x1))+δ, (57)

where x0=β0⁢(ε0−ε+μ), x1=β1⁢(ε−μ−ε1), β0,1=1kB⁢T0,1, and μ is the chemical potential. ε0 and ε1 are specified by the keyword CWF.disentangling.Erange. kB⁢T0,1 is specified by the keyword CWF.disentangling.smearing.kBT. δ is specified by the keyword CWF.disentangling.smearing.bound. See the following items for these keywords. A comparison of the two window functions is shown in Fig. 53. By tuning the parameters, the two window functions become similar, and as a result almost the same CWFs are obtained. However, the polynomial window function wP is exactly zero for ε≤ε0 and ε3<ε, so Bloch functions in those energy regions are excluded from the construction of the projection matrix A. Therefore, the sizes of the mmn and amn files used for the interface to Wannier90 can be reduced. This is a major advantage of the polynomial window function wP. This point will be explained again in Sec. 47.1.10.

The polynomial and Fermi window functions are different from the window functions used in the paper[133], but they function in almost the same way.

CWF.disentangling.Erange
When the polynomial window function wP is selected, ε0, ε1, ε2, and ε3 are specified as follows.

   CWF.disentangling.Erange      -45.0 -43.0 1.0 10.0   # in eV

In this specification, ε0=−45 eV, ε1=−43 eV, ε2=1 eV, and ε3=10 eV. Note that the chemical potential is taken as the energy reference. As can be seen from Fig. 52(a), the occupied states lie in the range −45∼0 eV. Therefore, we set ε0=−45 eV, ε1=−43 eV, and ε2=1 eV (the choice ε2=1 eV includes a small buffer, although there may be no significant difference even if ε2=0 eV). The contribution in the range 1–10 eV is then included with a small weight.

On the other hand, when the Fermi window function wF is selected, ε0 and ε1 are specified as follows.

   CWF.disentangling.Erange      -44.0 5.0  # in eV

Note that although the keyword name is the same, the specification method of CWF.disentangling.Erange differs depending on whether Fermi or Poly is selected.

CWF.disentangling.smearing.kBT
When Fermi is selected by CWF.window.function, this keyword specifies kB⁢T0 and kB⁢T1 in Eq. (57) as follows.

    CWF.disentangling.smearing.kBT    3.0 3.0  # in eV

The first number corresponds to kB⁢T0 and the second to kB⁢T1. If kB⁢T0,1 is set larger, the window function has longer tails, and states outside ε0 and ε1 are taken into account.

CWF.disentangling.smearing.bound
When Fermi is selected by CWF.window.function, this keyword specifies δ in Eq. (57). The default value is 1.0e-12, and there is usually no need to change it.

The keywords related to visualization of CWFs, namely CWF.fileout.flag, CWF.Plot.SuperCells, CWF.fileout.Num, and CWF.fileout.cube, are explained in Sec. 47.1.6.

 

As seen in Fig. 52(a), the bands around approximately -36, -15, and -11 eV are isolated. As the next example, let us construct CWFs excluding these bands. Run the calculation using the input file GaAs-CWF2.dat in the work directory.

     % mpirun -np 8 openmx GaAs-CWF2.dat | tee GaAs-CWF2.std

If the calculation finishes normally, GaAs-CWF2.Band and GaAs-CWF2.CWF.Band are output. By following the procedure in Sec. 22, “Band dispersion”, the band dispersion shown in Fig. 52(b) is obtained. It can be seen that, as intended, the bands around -36, -15, and -11 eV are not included in the Wannier-interpolated band dispersion. From PDOS analysis or from the eigenvalue information in the vps and pao files, one finds that the band around -36 eV originates from As-3⁢d orbitals, the band around -15 eV from Ga-3⁢d orbitals, and the band around -11 eV from As-4⁢s orbitals. Therefore, the guiding functions are specified as follows.

   <CWF.Guiding.AOs
    Ga  1s 1 2s 0 3s 0 1p 1 2p 0 1d 0 2d 0 1f 0
    As  1s 0 2s 0 3s 0 1p 1 2p 0 1d 0 2d 0 1f 0
   CWF.Guiding.AOs>

The window function is then specified as follows.

   CWF.window.function               Poly
   CWF.disentangling.Erange     -10.0 -9.0 0.0 10.0

Using the polynomial window function, occupied states below -10 eV are excluded, and the PAOs that mainly contribute in the energy region −10<ε are used as guiding functions. As a result, the bands in the region −10<ε are reproduced well. As in this example, by identifying the main PAOs contributing to each band from analyses such as PDOS, eigenvalues in the vps and pao files, or band-unfolding analyses, one can easily construct CWFs restricted to a given energy region.
