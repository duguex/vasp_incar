34 Molecular Orbitals

Kohn-Sham orbitals of molecules and crystals can be output in Gaussian cube format. Since the Gaussian cube format is a widely used data format, the Kohn-Sham orbitals can be visualized using many software packages such as OpenMX Viewer [165, 164], VESTA [115], and XCrySDen [116]. The relevant keywords are given below.

     MO.fileout         on    # on|off, default=off
     num.HOMOs           1    # default=2
     num.LUMOs           1    # default=2
     MO.Nkpoint          2    # default=1

     <MO.kpoint
       0.0  0.0  0.0
       0.5  0.0  0.0
     MO.kpoint>

To generate cube files, set the keyword MO.fileout to ON. The number of highest occupied molecular or crystal orbitals (HOMOs) to be output and that of lowest unoccupied molecular or crystal orbitals (LUMOs) can be specified by the keywords num.HOMOs and num.LUMOs, respectively. In band calculations, the k points at which HOMOs and LUMOs are calculated are specified by the keywords MO.Nkpoint and MO.kpoint. The keyword MO.Nkpoint gives the number of k points at which HOMOs and LUMOs are calculated. Using the keyword MO.kpoint, the k points can be explicitly specified as shown above. The k points are specified on the basis of the reciprocal lattice vectors of the unit cell vectors given by Atoms.UnitVectors. The output cube files are summarized as follows.

For clusters:

MO.fileout=ON and scf.EigenvalueSolver=Cluster generate the following files.

  • •

    System.Name.homo0_0.cube, System.Name.homo0_1.cube, …

    HOMOs are output in Gaussian cube format. The first number after homo represents the spin state (up=0, down=1). The second number represents the eigenstate, i.e., 0, 1, and 2 correspond to HOMO, HOMO-1, and HOMO-2, respectively. The total number is specified by the keyword num.HOMOs.

  • •

    System.Name.lumo0_0.cube, System.Name.lumo0_1.cube, …

    LUMOs are output in Gaussian cube format. The first number after lumo represents the spin state (up=0, down=1). The second number represents the eigenstate, i.e., 0, 1, and 2 correspond to LUMO, LUMO+1, and LUMO+2, respectively. The total number is specified by the keyword num.LUMOs.

For bulk systems:

MO.fileout=ON and scf.EigenvalueSolver=Band generate the following files.

  • •

    System.Name.homo0_0_0_r.cube, System.Name.homo1_0_1_r.cube, … System.Name.homo0_0_0_i.cube, System.Name.homo1_0_1_i.cube, …

    HOMOs are output in Gaussian cube format. The first number after homo means the k point, which is specified by the keyword MO.kpoint. The second number represents the spin state (up=0, down=1). The third number represents the eigenstate, i.e., 0, 1, and 2 correspond to HOMO, HOMO-1, and HOMO-2, respectively. The total number is specified by the keyword num.HOMOs. r and i represent the real and imaginary parts of the wave function.

  • •

    System.Name.lumo0_0_0_r.cube, System.Name.lumo1_0_1_r.cube, … System.Name.lumo0_0_0_i.cube, System.Name.lumo1_0_1_i.cube, …

    LUMOs are output in Gaussian cube format. The first number after lumo means the k point, which is specified by the keyword MO.kpoint. The second number represents the spin state (up=0, down=1). The third number represents the eigenstate, i.e., 0, 1, and 2 correspond to LUMO, LUMO+1, and LUMO+2, respectively. The total number is specified by the keyword num.LUMOs. r and i represent the real and imaginary parts of the wave function.
