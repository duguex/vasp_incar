19.4 Enthalpy Optimization

Optimization of a variable cell can be performed under an applied pressure. This is achieved by minimizing the enthalpy H given by the following equation.

H=E+p⁢V, (24)

where E is the total energy per unit cell, p is the applied pressure, and V is the volume of the unit cell. To perform enthalpy optimization, it is sufficient to include the following keyword in the input file.

   MD.applied.pressure         10.0       # in GPa, default=0

Positive pressure corresponds to compression of the cell. This feature is compatible with OptC1, OptC2, OptC3, OptC4, OptC5, OptC6, OptC7, and also RFC5, RFC6, and RFC7, which can be specified by the keyword MD.Type. As an example, enthalpy optimization can be performed using the input file Si8-pV.dat in the work directory. This is an optimization of a Si crystal under 10 GPa. It can be confirmed that the enthalpy is actually optimized not so much by a decrease in the total energy as by a contraction of the volume.

Furthermore, the following keyword can be used to apply pressure only along specific axes in an orthorhombic crystal system.

   MD.applied.pressure.flag   1 1 1   # default=1 1 1

The default setting is 1 1 1, which means isotropic pressure applied equally along the a, b, and c axes. If 1 0 0 is specified for this keyword, pressure is applied only along the a axis, which is perpendicular to the bc plane of an orthorhombic crystal system. This feature is valid for orthorhombic crystal systems. In this case, the unit vectors must be given so that nonzero elements appear only in the diagonal components, as in the following example.

    <Atoms.UnitVectors
     10.000   0.000   0.000
      0.000   8.000   0.000
      0.000   0.000  11.000
    Atoms.UnitVectors>

For crystal systems other than orthorhombic ones, anisotropic pressure is applied along the lattice vector perpendicular to the plane defined by the other lattice vectors. This situation is seen, for example, in a hexagonal crystal system, where this keyword is specified as follows.

   MD.applied.pressure.flag   0 0 1   # default=1 1 1

    <Atoms.UnitVectors
      6.000   0.000   0.000
     -3.000   5.196   0.000
      0.000   0.000  10.000
    Atoms.UnitVectors>
