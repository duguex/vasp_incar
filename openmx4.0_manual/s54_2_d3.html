54.2 DFT-D3 Method

The DFT-D3 method by Grimme and co-workers [149, 150] can also be used to include vdW interactions. The related parameters are listed below (the default parameters are set for GGA-PBE). 

  scf.dftD                     on            # on|off, default=off
  version.dftD                  3            # 2|3, default=2
  DFTD3.damp                   bj            # zero|bj, default=bj
  DFTD.Unit                    AU            # Ang|AU
  DFTD.rcut_dftD            100.0            # default=100 (DFTD.Unit)
  DFTD.cncut_dftD              40            # default=40 (DFTD.Unit)
  DFTD.IntDirection         1 1 1            # default=1 1 1 (1:on 0:off)

To perform a DFT-D2 or DFT-D3 calculation, set scf.dftD to on. For DFT-D2, set version.dftD to 2, and for DFT-D3, set it to 3. As the damping function for DFT-D3, both zero damping and Becke-Johnson (BJ) damping [150] are available. The interaction cutoff radius is specified by DFTD.rcut_dftD, and the cutoff used for the coordination number calculation is DFTD.cncut_dftD. We recommend using AU as the unit specified by DFTD.Unit. In DFTD.IntDirection, one specifies whether interactions with virtual atoms in the a, b, and c directions are included; they are included when the value is 1 and ignored when the value is 0. The periodicity of each atom is controlled by DFTD.periodicity in the same way as in the DFT-D2 method, as follows.

  <DFTD.periodicity
   1   1
   2   1
   3   1
   4   1
   ....
  DFTD.periodicity>

Here, the first column is the serial number, as in Atoms.SpeciesAndCoordinates, and the second column is a flag; for the corresponding atom, 1 means periodic and 0 means non-periodic. An atom specified as 0 is regarded as non-periodic, and its interaction with periodic images is not included.

The main modifications for the DFT-D3 method are limited to DFTD3vdW_init.c and Calc_EdftD() in Total_Energy.c. In DFTD3vdW_init.c, the vdW interaction parameters can be modified. By examining Calc_EdftD() in Total_Energy.c, one can also confirm how the energy is calculated.

When other functionals are used, set the following keywords. 

  DFTD.scale6            1     # default=0.75|1.0 (for DFT-D2|DFT-D3)
  DFTD.scale8       0.7875     # default=0.722|0.7875 (for PBE with zero|bj damping)
  DFTD.sr6           1.217     # default=1.217 (for PBE)
  DFTD.a1           0.4289     # default=0.4289 (for PBE)
  DFTD.a2           4.4407     # default=4.4407 (for PBE)

s6 and s8 are the scaling factors appearing in Eq. (3) of Grimme’s paper [149], and are specified by DFTD.scale6 and DFTD.scale8. These scaling factors depend on the functional and the damping function. In addition, when the zero-damping function is used, sr6 must be set, whereas when the BJ damping function is used, a1 and a2 must be set. These parameters appear in Eq. (6) of Grimme’s paper.

As an example of a DFT-D3 calculation, Fig. 73 shows the interaction between two benzene molecules arranged in parallel (D6⁢h symmetry) as a function of the intermolecular distance. The following input files used in the calculation are contained in the work/DFT-D3 directory.

  Dimer-Ben-10.0.dat  Dimer-Ben-3.88.dat  Dimer-Ben-4.5.dat  Mono-Ben-1.dat
  Dimer-Ben-3.3.dat   Dimer-Ben-3.89.dat  Dimer-Ben-5.0.dat  Mono-Ben-2.dat
  Dimer-Ben-3.4.dat   Dimer-Ben-3.8.dat   Dimer-Ben-6.0.dat  Mono-Ben.dat
  Dimer-Ben-3.6.dat   Dimer-Ben-3.9.dat   Dimer-Ben-7.0.dat
  Dimer-Ben-3.86.dat  Dimer-Ben-4.0.dat   Dimer-Ben-8.0.dat
  Dimer-Ben-3.87.dat  Dimer-Ben-4.2.dat   Dimer-Ben-9.0.dat

After optimizing a single molecule using Mono-Ben.dat, calculations at different intermolecular distances were carried out using Dimer-Ben-#.dat (#=3.3-9.0). In these calculations, the structure of benzene was fixed to the optimized geometry of the isolated molecule. Mono-Ben-1.dat and Mono-Ben-2.dat are input files for applying the counterpoise correction to the single-molecule calculation. The most stable intermolecular distance was obtained as 3.87Å, which is in good agreement with the result from density-fitted local second-order Møller-Plesset perturbation theory (DF-LMP2) [151] (3.89 Å). The interaction energy with the counterpoise correction is 1.73 kcal/mol, which is also in good agreement with the literature value (1.7 kcal/mol) [151], indicating that the basis set superposition error is not negligible.
