24.1 About COHP and COOP

In this section, we explain how to calculate COHP (Crystal Orbital Hamilton Population) [71] and COOP (Crystal Orbital Overlap Population) [72]. Like the Mulliken population analysis [74], COHP and COOP are methods for analyzing interatomic interactions in an energy-resolved manner. COHP is a quantity obtained by decomposing the band energy based on Hamiltonian matrix elements, while COOP is a quantity obtained by decomposing the electron number based on overlap matrix elements. Both are widely used to examine which atomic pairs and which atomic orbitals contribute to bonding or antibonding states.

In the notation used in OpenMX, the Hamiltonian matrix element and overlap matrix element in the real-space representation are written as hσ,i⁢α⁢j⁢β(Rn) and si⁢α⁢j⁢β(Rn), respectively. Here, i⁢α denotes the basis function α on atom i, and j⁢β denotes the basis function β on atom j in the cell translated by the lattice vector Rn. If the energy-resolved density matrix at energy E is defined as

ρσ,i⁢α⁢j⁢β(Rn)⁢(E) = 1VB⁢∫Bd3⁢k⁢∑μei⁢Rn⋅k⁢cσ⁢μ,i⁢α(k)⁣∗⁢cσ⁢μ,j⁢β(k)⁢δ⁢(E−εσ⁢μ(k)) (31)

then the ordinary density matrix ρσ,i⁢α⁢j⁢β(Rn) is given by

ρσ,i⁢α⁢j⁢β(Rn) = ∫−∞μ𝑑E⁢ρσ,i⁢α⁢j⁢β(Rn)⁢(E) (32)

where μ is the chemical potential.

Then, the fully orbital-resolved COHP and COOP can be written as

COHPσ,i⁢α⁢j⁢β(Rn)⁢(E) = ρσ,i⁢α⁢j⁢β(Rn)⁢(E)⁢hσ,i⁢α⁢j⁢β(Rn) (33)
COOPσ,i⁢α⁢j⁢β(Rn)⁢(E) = ρσ,i⁢α⁢j⁢β(Rn)⁢(E)⁢si⁢α⁢j⁢β(Rn) (34)

That is, COHP is the weighted contribution with the Hamiltonian matrix element, and COOP is the weighted contribution with the overlap matrix element.

On the other hand, a quantity summed over the orbitals on one side is obtained, for example, by taking the summation over the basis functions on the second atom as

COHPσ,i⁢α⁢j(Rn)⁢(E) = ∑βCOHPσ,i⁢α⁢j⁢β(Rn)⁢(E) (35)
COOPσ,i⁢α⁢j(Rn)⁢(E) = ∑βCOOPσ,i⁢α⁢j⁢β(Rn)⁢(E) (36)

Furthermore, the COHP and COOP for an atomic pair (i,j) obtained by summing over the orbitals on both sides are defined by

COHPσ,i⁢j(Rn)⁢(E) = ∑α,βCOHPσ,i⁢α⁢j⁢β(Rn)⁢(E) (37)
COOPσ,i⁢j(Rn)⁢(E) = ∑α,βCOOPσ,i⁢α⁢j⁢β(Rn)⁢(E) (38)

If one takes the summation over all spins, lattice translations, atoms, and atomic orbitals, and then integrates up to the chemical potential, COHP gives the band energy and COOP gives the number of electrons. Namely,

∑σ∑Rn∑i⁢α,j⁢β∫−∞μ𝑑E⁢COHPσ,i⁢α⁢j⁢β(Rn)⁢(E) = ∑σ∑Rn∑i⁢α,j⁢βρσ,i⁢α⁢j⁢β(Rn)⁢hσ,i⁢α⁢j⁢β(Rn) (39)
∑σ∑Rn∑i⁢α,j⁢β∫−∞μ𝑑E⁢COOPσ,i⁢α⁢j⁢β(Rn)⁢(E) = ∑σ∑Rn∑i⁢α,j⁢βρσ,i⁢α⁢j⁢β(Rn)⁢si⁢α⁢j⁢β(Rn) (40)

The former corresponds to the band energy, and the latter corresponds to the number of electrons. According to the sign convention adopted in this manual, a negative COHP is interpreted as bonding, and a positive COHP as antibonding. On the other hand, a positive COOP is interpreted as bonding, and a negative COOP as antibonding. The correspondence to the actual output files is also clear. For example, sidia_cohp_i1_o0_o0_s0_tetra.cohp corresponds to the fully orbital-resolved quantity COHPσ,i⁢α⁢j⁢β(Rn)⁢(E). Also, sidia_cohp_i1_o0_s0_tetra.cohp corresponds to COHPσ,i⁢α⁢j(Rn)⁢(E), in which the summation is taken over the basis-function index β on the second atom, and sidia_cohp_i1_s0_tetra.cohp corresponds to COHPσ,i⁢j(Rn)⁢(E), in which the orbital summation is taken on both sides. COOP files can be interpreted in exactly the same manner. The individual output files will be explained later.

The calculation of COHP and COOP is carried out simultaneously with the DOS calculation. Therefore, when calculating COHP and COOP, set the keyword Dos.fileout to on. After the ordinary OpenMX calculation finishes, System.Name.cohp is generated. By processing this file with the post-processing code cohp, one can obtain the energy-resolved COHP and COOP.
