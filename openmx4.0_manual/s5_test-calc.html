5 Test calculation

This section is for users who have completed the installation and want to confirm that a first calculation runs correctly. Start with Methane.dat, and check not only that the run finishes but also that the main output files are created. If the calculation does not finish normally, first return to Section 4.

After the installation has been completed successfully, move to the work directory, and execute openmx as follows using Methane.dat as the input file.

     % mpirun -np 1 openmx Methane.dat | tee met.std

If you use the OpenMP/MPI hybrid version, execute it with the following command.

     % mpirun -np 1 openmx Methane.dat -nt 1 | tee met.std

Methane.dat used in this calculation is an input file for performing an SCF calculation for a methane molecule. No structural optimization is carried out. This calculation finishes in about 5 seconds when it is run on a single core of a 3.6 GHz Xeon machine, although the actual execution time depends on the computer environment. If the calculation terminates normally, the following 11 files and 1 directory are created in the work directory.

      met.std               standard output of the SCF calculation
      met.out               input file and standard output
      met.xyz               final geometry
      met.ene               calculated values at each MD step
      met.md                geometry at each MD step
      met.md2               geometry at the final MD step
      met.cif               CIF file of the initial structure
      met.tden.cube         total electron density in Gaussian cube format
      met.v0.cube           Kohn-Sham potential in Gaussian cube format
      met.vhart.cube        Hartree potential in Gaussian cube format
      met.dden.cube         difference electron density calculated from atomic densities
      met_rst/              directory for storing restart files

The data written to the standard output are stored in the met.std file. This file is useful for understanding the computational process of the SCF calculation. The met.out file contains results such as the total energy, forces, Kohn-Sham eigenvalues, Mulliken charges, the convergence history of the SCF calculation, and the computational time. The output files met.tden.cube, met.v0.cube, met.vhart.cube, and met.dden.cube contain, respectively, the total electron density, the Kohn-Sham potential, the Hartree potential, and the difference electron density with respect to the superposition of the electron densities of the constituent isolated atoms, in Gaussian cube format. Since the Gaussian cube format is a widely used grid format, they can be visualized using free molecular modeling software such as OpenMX Viewer [164], VESTA [115], and XCrySDen [116]. Examples of visualization are shown in a later section.
