40.2 Additional functionalities

Standard DFT+U calculations are carried out using the keywords mentioned above. Here we explain additional functionalities available in OpenMX. These functionalities can be used only when scf.DFTU.Type=2.

40.2.1 Adjustment of the ratio of two Slater integrals (F4/F2)

In the generalized DFT+U method with scf.DFTU.Type=2, the Coulomb interaction tensor is generated from the input values U and J. Assuming spherical symmetry of the atom, this tensor is calculated from Slater integrals (F0,F2,F4,…) and Racah-Wigner coefficients. In the standard treatment of the generalized DFT+U method for d orbitals, the ratio F4/F2 is required, and usually F4/F2=0.625 is used. However, this value is valid only in a spherically symmetric atomic environment, and it may deviate from this value in solids. By the keyword scf.Slater.Ratio, the user can adjust F4/F2 according to their purpose.

  scf.Slater.Ratio                 0.75     # default=0.625

40.2.2 Estimation of J and F4/F2 from the input parameter U

By assuming a Yukawa-type screened Coulomb potential, J and F4/F2 can be estimated from the input value of U. For this purpose, set the keyword scf.Yukawa to on.

  scf.Yukawa                       on      # default=off

When scf.Yukawa=on is set, only the value of U in <Hubbard.U.values ... Hubbard.U.values> is read, and the value of J in <Hund.J.values ... Hund.J.values> and scf.Slater.Ratio are ignored. Instead, the values of J and F4/F2 are automatically generated by estimating the Thomas-Fermi screening length corresponding to the input value of U [22, 23]. As an example, suppose that the basis functions are defined as follows.

  <Definition.of.Atomic.Species
    Ni Ni6.0S-s2p2d2f1  Ni_CA19S
    O  O5.0-s2p2d1      O_CA19
  Definition.of.Atomic.Species>

Suppose that scf.Yukawa=on and that the value of U is set by the keyword Hubbard.U.values as follows.

  <Hubbard.U.values   # eV
    Ni 1s 0.0 2s 0.0 1p 0.0 2p 0.0 1d 6.4 2d 3.0 1f 0.0
    O  1s 0.0 2s 0.0 1p 0.0 2p 0.0 1d 0.0
  Hubbard.U.values>

In this case, the following message is displayed in the standard output before the SCF loop starts.

  *******************************************************
        Calculating Thomas-Fermi screening length
  *******************************************************

  <species: Ni, angular momentum= 2, multiplicity number= 0>
   TF-screening-length lambda= 1.340787 1/au
   Hubbard U= 6.400000 eV
   Hund J= 1.154943 eV
   Slater F0= 6.399932 eV
   Slater F2= 9.321381 eV
   Slater F4= 6.847820 eV
   F4/F2= 0.734636

  <species: Ni, angular momentum= 2, multiplicity number= 1>
   TF-screening-length lambda= 0.271461 1/au
   Hubbard U= 3.000000 eV
   Hund J= 0.380184 eV
   Slater F0= 3.000017 eV
   Slater F2= 2.970544 eV
   Slater F4= 2.352036 eV
   F4/F2= 0.791786

These values of U, J, and F4/F2 are used in the SCF loop of the DFT+U calculation. The input file NiO-Yukawa.dat used in this calculation example is stored in the work directory, so please refer to it.
