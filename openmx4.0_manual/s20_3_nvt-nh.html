20.3 NVT molecular dynamics by the Nose-Hoover method (NVT_NH)

By specifying the keyword MD.Type as NVT_NH, an NVT-ensemble molecular dynamics simulation by the Nose-Hoover method [32] can be performed.

    MD.Type         NVT_NH     # NOMD|Opt|NVE|NVT_VS|NVT_NH

In this NVT molecular dynamics, the temperature of atomic motion can be controlled by the following format.

   <MD.TempControl
     4
     1    1000.0
     100  1000.0
     400   700.0
     700   600.0
   MD.TempControl>

The first line of this format is <MD.TempControl, and the last line is MD.TempControl>. The initial 4 is the number of lines required for temperature control. In this case, the temperature is specified in the following four lines, where the number in the first column represents the MD step, and the second column represents the target temperature of atomic motion. The temperature between MD steps is given by linear interpolation. Also in NVT-ensemble molecular dynamics simulations by the Nose-Hoover method [32], the same keyword MD.TempControl as in velocity-scaling MD is used, but note that the format is different. In addition to the specification of MD.TempControl, please specify the mass of the heat bath using the following keyword.

    NH.Mass.HeatBath          30.0      # default = 20.0

Its dimension is length2 × mass. In this notation, the Bohr radius is used for length, and the unified atomic mass unit (in which the mass of the major isotope of carbon is taken as 12.0) is used for mass.
As explained in Section 20.2, the numerical values calculated at each MD step are stored in the output file System.Name.ene. In the Nose-Hoover method, the Hamiltonian of the extended system is a conserved quantity, and therefore, when checking the validity of temperature control, it is also useful to inspect the Nose-Hoover Hamiltonian recorded in the output file System.Name.ene. As an example, the result for a glycine molecule calculated by the Nose-Hoover method is shown in Fig. 13 (b). It can be seen that the temperature of atomic motion oscillates around the target temperature. In addition, to visualize the molecular dynamics trajectory, as in the case of NVT_VS, the free software packages OpenMX Viewer [165, 164] and XCrySDen [116] can be used to convert the output file System.Name.md easily into an animation.
