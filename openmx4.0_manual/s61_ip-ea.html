61 Ionization potentials and electron affinities of isolated systems

Ionization energies and electron affinities of isolated systems can be calculated by the delta-SCF method and the exact Coulomb cutoff method [101]. By using the exact Coulomb cutoff method, charged isolated systems can be calculated even under periodic boundary conditions. The ionization energy and electron affinity are calculated from the difference in total energy between two calculations, namely those for the ground state and the ionized state of an isolated system. First, we explain how to calculate the ionization energy of an isolated system. The first example is a water molecule. The calculation for the isolated state is performed as follows.

   % mpirun -np 3 ./openmx H2O+0.dat | tee h2o+0.std

The input file H2O+0.dat is located in the directory work. The geometric structure was optimized in advance using the same calculation conditions. To avoid spurious interactions between supercells, the exact Coulomb cutoff method [101] is specified by the following keyword. 

   scf.coulomb.cutoff            on     # default=off, on|off

Although the exact Coulomb cutoff method can avoid spurious interactions between supercells, the cutoff radius of the Coulomb interaction is set to half the length of the shortest lattice vector. Therefore, please set the cell length sufficiently large so that the Coulomb interaction inside the central unit cell is correctly calculated.

The calculation of the ionized state is performed as follows.

   % mpirun -np 3 ./openmx H2O+1.dat | tee h2o+1.std

The input file H2O+1.dat is located in the directory work. Compared with H2O+0.dat, the following keywords are changed or added. 

   scf.system.charge            1.0       # default=0.0
   scf.coulomb.cutoff            on       # on|off, default=off
   scf.SpinPolarization          on       # On|Off|NC

By setting the keyword scf.system.charge, the isolated system becomes positively charged. By specifying scf.coulomb.cutoff and using the exact Coulomb cutoff method, Coulomb divergence in the charged system is avoided. Since the system may become spin-polarized upon ionization, scf.SpinPolarization is set to on. After the two calculations are completed, the following total energies are obtained from the output files.

   Ground state:          -17.477268421216 (Hartree)
   Charged state of +1:   -17.010776518028 (Hartree)

Then, the ionization potential IP, defined as (total energy of the +1 charged state) - (total energy of the ground state), is calculated as follows.

IP = −17.010776518028−(−17.477268421216)=0.466491903188⁢(Hartree),
≈ 12.69⁢(eV).

The obtained value, 12.69 eV, agrees well with the experimental value of 12.65 eV [106]. In the same manner as for the ionization potential, the electron affinity of an isolated system, defined as (total energy of the ground state) - (total energy of the −1 charged state), can be calculated by the following specification. 

   scf.system.charge           -1.0       # default=0.0

By setting scf.system.charge=-1.0, one electron is added and the system becomes negatively charged.
