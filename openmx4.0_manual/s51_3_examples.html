51.3 Examples and Related Keywords

As examples, two input files are provided.

  • •

    C2H4_NEB.dat

    Formation of cyclobutane via the cycloaddition reaction of two ethylene molecules

  • •

    Si8_NEB.dat

    Diffusion of an interstitial hydrogen atom in diamond-structure Si

Keywords for an NEB Calculation

An NEB calculation is performed by setting the keyword MD.Type as follows. 

   MD.Type                NEB

The number of images along the path is specified by the following keyword. 

   MD.NEB.Number.Images        8            # default=10

Here, the two terminal structures (the reactant and product) are excluded from the number of images.

The spring constant is given as follows. 

   MD.NEB.Spring.Const         0.1          # default=0.1 (Hartree/Bohr^2)

In most cases, the resulting path does not depend strongly on this value.

Optimization of the MEP is performed using a hybrid optimization method (DIIS+BFGS). This optimization method is controlled by the following keywords. 

   MD.Opt.DIIS.History           4          # default=7
   MD.Opt.StartDIIS             10          # default=5
   MD.maxIter                  100          # default=1
   MD.Opt.criterion         1.0e-4          # default=0.0003 (Hartree/Bohr)

The specifications of these keywords are the same as those for structural optimization, so for details, please refer to Section 18. It is also possible to fix atomic positions using the keyword MD.Fixed.XYZ.

Execution of an NEB Calculation

As shown below, an NEB calculation can be performed using the input file C2H4_NEB.dat.

   % mpirun -np 16 openmx C2H4_NEB.dat

If the calculation finishes normally, 24 or more files will be generated. These output files are listed below.

In addition, c2h4.neb.ene and c2h4.neb.xyz store, as shown in Fig. 69(b), the variation of the total energy as a function of the distance from the reactant (Bohr) and the structural evolution, respectively, and can therefore be used to analyze the MEP. The contents of c2h4.neb.ene are as follows.

Here, the first column is the serial index of the image, where 0 and 9 correspond to the reactant and product, respectively. The second column is the total energy of each image. The third and fourth columns are the distance (Bohr) between two neighboring images in geometrical phase space and the distance (Bohr) from the reactant, respectively.

Since the calculation for each image is basically carried out as an independent OpenMX calculation with a different input file, the System.Name.dat_# files are generated automatically. Here, System.Name denotes System.Name, and # denotes the serial number of each image. The corresponding output files System.Name_#.out are also generated, which will be useful for analyzing how the electronic structure changes along the MEP.

As in C2H4_NEB.dat, an NEB calculation can also be performed for Si8_NEB.dat. If the calculation finishes successfully, the optimization history and the total energy change along the MEP shown in Fig. 70 will be obtained.
