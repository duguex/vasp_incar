56 Analysis of spin textures in momentum space

This section is for users who want to analyze spin textures with kSpin from non-collinear calculations including spin–orbit interaction. First understand the quantities output by kSpin, and then read only the subsections needed for modes such as FermiLoop, GridCalc, BandDispersion, and MulPOnly. For the setup of the non-collinear calculation itself, it is helpful to review Section 37 first.

Spin splitting in band structures, such as that observed in the Rashba effect, can arise from the inclusion of spin–orbit interaction. The spin splitting can be analyzed for each eigenstate and wave vector k separately. Such a spin structure in reciprocal space, resolved for each eigenstate and k point on the band dispersion, is called a spin texture. For non-collinear calculations including spin–orbit interaction, the spin texture can be analyzed using the post-process code kSpin. The spin density matrix resolved for each eigenstate and k point is hereafter referred to as the momentum-space spin density matrix. This momentum-space spin density matrix is calculated from a two-component spinor and takes the form of a 2×2 matrix. The spin texture is calculated from this 2×2 matrix. In addition to the spin texture, the analysis by the post-process code kSpin also provides the momentum-space spin density matrix itself, so that the physical origin of phenomena induced by spin–orbit interaction, such as the Rashba effect, can be analyzed. kSpin provides not only a decomposition with respect to eigenstates and k points, but also a function to analyze spin textures decomposed into atoms and pseudo-atomic orbitals. This function makes it possible to understand which atoms and orbitals play the central role in the spin splitting. Note also that kSpin can be applied not only to the Rashba effect, but also to topological insulators and non-Rashba-type spin splittings.

In the following subsections, we explain how kSpin can be applied to these analyses while showing practical examples. Note that kSpin can be used only for non-collinear calculations and is not available for collinear calculations. For non-collinear calculations, see Section 37.
