52.4.2 Calculation of the kinetic energy density

Using the structure obtained by structural optimization, the density matrix is calculated again with OpenMX, and then the kinetic energy density is calculated with FLPQ. For example, create a directory named flpq, move into it, and run OpenMX with the following option: 

  DM.export         on

Since structural optimization is not needed at this stage, set MD.type nomd. After the calculation finishes, a directory named OpenMX_LPQ_DM, which contains the density-matrix information, and a binary file named OpenMX_LPQ.bin are generated.

Next, run FLPQ in the same directory where OpenMX_LPQ.bin and OpenMX_LPQ_DM are located. If the calculation region and related settings need to be specified, prepare an input file named flpq.inp and run the following command. A sample flpq.inp for practice is stored in the directory work.

  $ PATH_TO_FLPQ/flpq flpq.inp

After the calculation finishes, a directory named LPQ is generated, and the kinetic-energy-density cube file

  LPQ.kinetic_energy_density.cube

is created inside it.

52.4.3 Calculation of the RCP

Using the structure obtained by structural optimization, calculate again with OpenMX to obtain the density matrix in the specified energy window, and then calculate the RCP with FLPQ. For example, create a directory named flpq_ew, move into it, and run OpenMX with the following options:

  DM.export                  window
  DM.specify.energy.range      on
  DM.energy.range          -3.0  0.0

Since structural optimization is not needed at this stage, set MD.type nomd. Referring to the DOS results, the energy range should be taken from the Fermi level down to the energy levels that contribute to bonding. After the calculation finishes, a directory named OpenMX_LPQ_DM, which contains the density-matrix information, and a binary file named OpenMX_LPQ.bin are generated.

Next, run FLPQ in the same directory where OpenMX_LPQ.bin and OpenMX_LPQ_DM are located. If the calculation region and related settings need to be specified, prepare an input file named flpq.inp and run the following command. Usually, the same input file as that used for the kinetic-energy-density calculation above can be reused.

  $ PATH_TO_FLPQ/flpq flpq.inp

After the calculation finishes, a directory named LPQ is generated, and the RCP cube file

  LPQ.regional_chemical_potential.cube

is created inside it.

52.4.4 Visualization with FLPQ Viewer

Finally, based on the data obtained above, plot the RCP as a color map on the material surface (the zero isosurface of the kinetic energy density). Prepare a toml file like the following as the input file for FLPQ Viewer. This file is stored as chempot.toml in the directory work.

# input file

[show]
structure = true
isosurface = true
lattice = false
axis = false

[structure]
cube_header = "flpq/LPQ/LPQ.kinetic_energy_density.cube"
bond_factor = 1.6
color_atoms = false

[isosurface]
cube1 = "flpq/LPQ/LPQ.kinetic_energy_density.cube"
cube2 = "flpq_ew/LPQ/LPQ.regional_chemical_potential.cube"
isovalue = 0.00001
max_value = -0.25
min_value = -0.4
periodicity = [1,1,1]

color_bar = true
color_name = "blue_green_red"
colors = ["#0000FF", "#00FFFF", "#00C600", "#FFFF00", "#FF0000"]
alpha = 0.8
shade = false
smooth = true

[view]
roughness = 1
supercell = [1,1,1]

[save]
interactive = false
output_name = "RCP"
Plotly = true

Specify the data for the structure in cube_header, the data used to draw the isosurface in cube1, and the data used to draw the color map in cube2. The zero isosurface of the kinetic energy density is specified by isovalue. In order to make the figure smoother, a small positive value is used here instead of exactly zero. The upper and lower limits of the RCP are specified by max_value and min_value. A visually pleasing plot can often be obtained by setting max_value around the orbital energy (a.u.) of the outermost valence orbital (HOMO). When FLPQ Viewer is executed, an html file is generated.

  python ${PATH_FLPQV}/flpqv/main_flpqv.py chempot.toml

Specify the path to the installed FLPQ Viewer in $PATH_FLPQV. (Note) If you are using a conda environment, execute the following command after conda deactivate.

  conda run -n flpqv_env python3 ${PATH_FLPQV}/flpqv/main_flpqv.py chempot.toml

By dragging and dropping the generated html file into a browser, you can visualize the result as shown in Fig.71.
