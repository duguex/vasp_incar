71.5 Additional remarks

The API-based executables presented here are minimal examples intended to illustrate the basic usage of the API. At first, it is safest to execute the supplied examples as they are and confirm that they work correctly, and only then modify such items as the input filenames, the communicator splitting scheme, and the number of OpenMP threads according to one’s purpose. In particular, in the present examples the OpenMP thread count is given by the variables Nth and nth in the source code, rather than being specified directly on the execution command line. This value is passed as an argument to the API, but the actual maximum usable number is limited by the external environment, for example by OpenMP-related environment variables and by the CPU resources assigned by the job scheduler. Moreover, the most important point in using the API is to keep the same MPI environment, compiler, and external-library settings as those used for ordinary OpenMX execution. In particular, in C/Fortran one should link libopenmx_api.a with the same settings as those used for the OpenMX core itself, while in Python one should import pyopenmx_api*.so in the corresponding environment.
