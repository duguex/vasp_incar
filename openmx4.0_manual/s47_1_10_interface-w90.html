47.1.10 CWF-Wannier90 interface

The results of OpenMX calculations can be further analyzed using Wannier90 [158]. One can calculate quantities such as DOS projected onto Wannier functions, band structures, Fermi surfaces, and Berry-phase-related properties (anomalous Hall conductivity, optical conductivity, etc.). To output the interface files for Wannier90, specify the following keyword.

   CWF.Wannier90.fileout    on    # on|off, default=off

When the calculation is performed with this keyword set to on, the mmn, amn, eig, and win files are generated. These files can be directly used as input for Wannier90-related tools. Since the calculation of the mmn, amn, eig, and win files takes time, it is important in the initial stage to keep CWF.Wannier90.fileout set to off and first confirm that the original bands are reproduced by Wannier interpolation. After the original bands have been reproduced, set CWF.Wannier90.fileout to on and generate these files.

If CWF.Wannier90.fileout is set to on in GaAs-CWF1.dat, discussed in Sec. 47.1.1, and the calculation is executed, the following four files are output.

   GaAs-CWF1_0.amn
   GaAs-CWF1_0.eig
   GaAs-CWF1_0.mmn
   GaAs-CWF1_0.win

Here, _0 means that the spin index is 0. If a spin-polarized collinear calculation is performed, both _0 and _1 files are output. In non-collinear calculations, the spin index is not appended to the file names. The first three files are read by the Wannier90 executable wannier90.x, while the last win file is the input file controlling the calculation of wannier90.x.

By default, the win file is set up for shift-current calculations.

    berry_task   sc    # sc|kubo

By changing the keyword berry_task appropriately, other physical quantities can also be calculated. For a detailed explanation of Wannier90, please refer to the Wannier90 [158] website.

Users employing the interface to Wannier90 should be careful in choosing the window function. The file sizes of mmn, amn, and eig depend strongly on the choice of the window function. When the Fermi window function wF is used, all Bloch functions are included in the generation of CWFs, and therefore the file sizes become large. If the number of Bloch functions included in the calculation is denoted by NB, the sizes of the mmn, amn, and eig files scale as O⁢(NB2), O⁢(NB), and O⁢(NB), respectively, and in particular the mmn file can exceed several tens of GB. Therefore, when using the interface to Wannier90, we recommend using the polynomial window function wP. Since the polynomial window function wP is exactly zero for ε≤ε0 and ε3<ε, Bloch functions in those energy regions are excluded from the calculation, and the sizes of the mmn, amn, and eig files can be reduced.
