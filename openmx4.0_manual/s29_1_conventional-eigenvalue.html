29.1 Conventional Eigenvalue Solver

If several hundred processor cores are available, structural optimization of systems consisting of 1000 atoms is possible using the conventional diagonalization method. Benchmark calculations for 1000-atom systems can be carried out by runtestL2 as follows.

     % mpirun -np 128 openmx -runtestL2 -nt 4

OpenMX performs seven test calculations and compares the results with the reference data stored in work/large2_example. Shown below are the results of runtestL2 executed on an AMD cluster computer using 192 MPI processes and 1 OpenMP thread.

In all of these calculations, two valence basis functions and one polarization basis function were assigned to each atom, so the calculations were performed with sufficient accuracy. Except for Pt500.dat, all the other systems consist of more than 1000 atoms. Here, the number at the end of each file name indicates the number of atoms contained in the corresponding system. The elapsed time per MD step shown in the table above ranges from about 10 minutes to 1 hour. Therefore, it can be seen that structural optimization of systems consisting of 1000 atoms is feasible if several hundred processor cores are available. The input and output files used in this calculation are stored in the directory work. Based on the information obtained from the output files, the elapsed time per SCF step is summarized below.

The dimension of the Kohn-Sham Hamiltonian is on the order of 10000, and the elapsed time per SCF step is about 15 seconds for all systems. It can be seen that the difference in the total computational time mainly arises from the difference in the number of SCF iterations.
