59.1 Z2 overview

The post-process code Z2FH can be used to calculate the Z2 invariant of a system. The Z2 invariant is calculated by the Berry-phase-based method proposed by Fukui and Hatsugai [90, 91]. Note that this functionality is available only for non-collinear DFT calculations and cannot be used for collinear DFT calculations. In addition, magnetic systems cannot be treated in the current implementation. If you publish results using this functionality, we would appreciate it if you would cite Ref. [93].

The Z2 invariant is a topological invariant that takes the value 0 or 1, and is defined for non-magnetic systems with time-reversal symmetry. Z2=1 and Z2=0 correspond to a topological insulator and a trivial insulator, respectively. The Z2 invariant is defined by

Z2=12⁢π⁢∑nocc.(∫∂B𝐀n⋅𝑑𝐤−∫BFn⁢z⁢𝑑k2)⁢(mod⁢ 2)

where 𝐀n=−i⁢⟨un⁢𝐤|∂∂𝐤|un⁢𝐤⟩ is called the Berry connection, and 𝐅n=∇×𝐀n is called the Berry curvature. The integration region B=[−𝐆12,𝐆12]⊗[0,𝐆22] needs only half of the Brillouin zone. This is because the topological invariant is defined on half of the Brillouin zone for a system with time-reversal symmetry. To perform the integration, the overlap matrix U is used. It was proposed by Fukui, Hatsugai, and Suzuki and is defined as UΔ⁢𝐤=det⟨un⁢(𝐤)|um⁢(𝐤+Δ⁢𝐤)⟩ [90, 91]. The Berry connection and the Berry curvature are calculated on each ‘plaquette’ as

Aa⁢b = Im⁢log⁡Ua⁢b,
F = Im⁢log⁡U12⁢U23⁢U34⁢U41.

Then the integer-valued field n(=0,±1) on each plaquette is calculated from

n⁢(𝐤)=12⁢π⁢(A12+A23+A31+A41−F)

By summing all values of n over half of the Brillouin zone and taking the total modulo 2, one obtains Z2. It should be noted that the Z2 invariant is gauge independent. However, the value of each n is gauge dependent, and can change depending on the computing environment, the compiler optimization level, and small differences in the electronic structure. For details of the calculation of 𝐀 and F, see Section 58. Because the calculation of the Z2 invariant is carried out by a loop integral over half of the Brillouin zone, it depends on the arbitrariness of the gauge of the wave function. Therefore, the gauge must be corrected on the boundary of half of the Brillouin zone. As shown in Fig. 88, we consider the following three kinds of gauge correction on the boundary.

Translational symmetry (red part)

|un⁢(𝐤+𝐆12)⟩=ei⁢𝐆1⋅𝐫⁢|un⁢(𝐤−𝐆12)⟩

Time-reversal symmetry (blue part)

|un⁢(𝐤)⟩=Θ⁢|un⁢(−𝐤)⟩=|un∗β⁢(−𝐤)⟩⁢|α⟩−|un∗α⁢(−𝐤)⟩⁢|β⟩

Kramers degeneracy (yellow part)

|u2⁢n⁢(𝐤)⟩=Θ⁢|u2⁢n−1⁢(−𝐤)⟩

In this calculation, the eigenvalue problem is solved only on half of the integration region. In other words, it is solved on one quarter of the Brillouin zone, as shown in Fig. 88.

When performing the integration in other regions, wave functions are generated by fixing the gauge of the wave function on the symmetry-related plaquettes, and the integration is then carried out.

In three-dimensional systems, the Brillouin zone has six time-reversal-invariant planes, kn=0 and kn=𝐆n2 (n=1,2,3). Therefore, as shown in Fig. 89, six Z2 invariants (x0,xπ,y0,yπ,z0,zπ) can be defined. Note that these invariants satisfy

x0+xπ=y0+yπ=z0+zπ⁢(mod⁢ 2)

Therefore, only four invariants are independent parameters. Based on this fact, the Z2 invariant of a three-dimensional system is defined as

Z2=(ν0,ν1,ν2,ν3)=(x0+xπ,xπ,yπ,zπ)

In particular, a system with ν0=1 is called a strong topological insulator, because the Z2=1 state appears in all directions of the Brillouin zone.
