45.1 Exchange-coupling overview

The exchange coupling parameters Ji⁢j between localized spins can be calculated using the Liechtenstein method based on perturbation theory [17]. This calculation is carried out using the post-process program jx. In OpenMX Ver. 4.0, this functionality is available only for collinear DFT calculations of cluster and bulk systems, and has not been generalized to noncollinear DFT calculations. If you publish papers or other works using this functionality, we would appreciate it if you would cite Refs. [18, 20].

This program jx provides the following three methods for calculating Ji⁢j.

For cluster systems, this program jx calculates the exchange coupling constant Ji⁢j between atomic sites i and j based on the following expression.

Ji⁢j = 14⁢∑n,n′−fn↑+fn′↓εn↑−εn′↓ (42)
×∑μ,ν∈i∑μ′,ν′∈jCj⁢μ′,n↑Ci⁢ν,n↑∗[P^i]ν⁢μCi⁢μ,n′↓Cj⁢ν′,n′↓∗[P^j]ν′⁢μ′
P^i≡H^i↑−H^i↓, (43)

εn⁢σ and 𝐂n⁢σ are the eigenvalues and eigenvectors of the Kohn-Sham equation. Here, 𝐤, n, and σ denote the wave vector, band index, and spin index, respectively. Also, [P^i]ν⁢μ and [P^j]ν′⁢μ′ denote the submatrices of the potential-difference operators for sites i and j, respectively.

For bulk systems, this program jx calculates the exchange coupling constant Ji⁢𝟎,j⁢𝐑 between atomic sites i and j located in cells 𝟎 and 𝐑, respectively, based on the following expression.

Ji⁢𝟎,j⁢𝐑 = 12⁢∑p=1NPR~p⁢∑μ,ν∈i∑μ′,ν′∈jRe⁢{[P^i]ν⁢μ⁢Gi⁢μ,j⁢ν′+⁢(↓,z~p,𝐑)⁢[P^j]ν′⁢μ′⁢Gj⁢μ′,i⁢ν+⁢(↑,z~p,−𝐑)}. (44)

z~p and R~p are the poles of the approximated Fermi function (located in the upper half of the complex plane) and the corresponding residues, respectively [82]. i and j are the atomic indices in the unit cell. 𝐑 is the index of the cell in which atom j is located. The Green’s functions Gj⁢μ′,i⁢ν+⁢(↑,ε,−𝐑) and Gi⁢μ,j⁢ν′+⁢(↓,ε,𝐑) are defined by the following equations.

Gj⁢μ′,i⁢ν+⁢(↑,ε,−𝐑) ≡ ∫d3⁢(k⁢a2⁢π)⁢ei⁢𝐤⋅𝐑⁢∑nCj⁢μ′,n↑⁢(𝐤)⁢Ci⁢μ,n↑⁢(𝐤)ε+i⁢η−εn↑⁢(𝐤) (45)
Gi⁢μ,j⁢ν′+⁢(↓,ε,𝐑) ≡ ∫d3⁢(k⁢a2⁢π)⁢e−i⁢𝐤⋅𝐑⁢∑n′Ci⁢μ,n′↓⁢(𝐤)⁢Cj⁢ν′,n′↓⁢(𝐤)ε+i⁢η−εn′↓⁢(𝐤). (46)

When the sum of the exchange coupling Ji⁢j over 𝐑 is considered, the calculation can also be performed using the following expression.

Ji⁢j = ∑𝐑Ji⁢𝟎,j⁢𝐑 (47)
= 14⁢∫d3⁢(k⁢a2⁢π)⁢∑n,n′−fn↑⁢(𝐤)+fn′↓⁢(𝐤)εn↑⁢(𝐤)−εn′↓⁢(𝐤)
×∑μ,ν∈i∑μ′,ν′∈jCj⁢μ′,n↑(𝐤)Ci⁢ν,n↑∗(𝐤)[P^i]ν⁢μCi⁢μ,n′↓(𝐤)Cj⁢ν′,n′↓∗(𝐤)[P^j]ν′⁢μ′.

For details of Eqs. (42), (44), and (47), please refer to Refs. [18, 20]. The difference in treatment between Eqs. (44) and (47) is illustrated schematically in Fig. 42. Figure 42(a) shows a schematic illustration of the interaction between independent sites, corresponding to Eq. (44). On the other hand, the interaction between periodic images corresponding to Eq. (47) is shown schematically in Fig. 42(b). As explained in a later subsection, either calculation can be selected at runtime by specifying the option Flag.PeriodicSum.
