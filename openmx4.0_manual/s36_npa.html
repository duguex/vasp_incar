36 Natural population analysis

This section is for users who want to analyze effective charges in terms of natural populations based on natural atomic orbitals. First confirm how this analysis differs from Mulliken, Voronoi, ESP, and CWF-based charge analyses, and then move to the practical settings only for the atoms of interest. For charge analyses more broadly, it is also useful to compare this section with Section 35.

In the natural bond orbital method by Weinhold [6], atomic effective charges are referred to as natural populations (NPs), and they are calculated from natural atomic orbitals (NAOs) localized on atoms. OpenMX supports NP analysis, and by using its own method based on the truncated cluster method [7], it is possible to carry out NP analysis efficiently for selected atoms even in large-scale systems. The NP calculation is performed after the SCF calculation, and the results are printed to standard output. Please follow the procedure below for NP analysis.

(a) For small-scale calculations (scf.EigenvalueSolver = Cluster)
The NP calculation is controlled by the following keyword .

    NBO.switch   on1

With this option, the NP calculation is performed using the full-size density matrix. An example for an ethylene carbonate molecule is provided in the directory work as EC_NAO.dat and EC_NAO.std.

(b) For large-scale calculations (scf.EigenvalueSolver = Krylov)
Large-scale NAO calculations using NBO.switch = on1 may run out of memory because of the size of the density matrix. In such cases, for large-scale systems, please perform the calculation with NBO.switch set as follows.

    NBO.switch   on2

This option is available for calculations using the O(N) Krylov subspace method (scf.EigenvalueSolver = Krylov). After the O(N) SCF calculation, NP analysis is carried out efficiently for a specified number of atoms. (When analyzing important events such as chemical reactions, in most cases it is sufficient to perform NP analysis not for all atoms but only for a local set of atoms.) The atoms to be subjected to NP analysis are specified as follows.

    NBO.Num.CenterAtoms     5
    <NBO.CenterAtoms
      269
      304
      323
      541
      574
    NBO.CenterAtoms>

Use the keyword NBO.Num.CenterAtoms to specify the number of atoms to be analyzed. Then list the serial numbers of the atoms to be analyzed between <NBO.CenterAtoms and NBO.CenterAtoms>. The serial numbers used here are those specified by the keyword Atoms.SpeciesAndCoordinates. NBO.CenterAtoms is valid only when NBO.switch is on2. If NBO.switch is on1, NBO.CenterAtoms is ignored, and NP analysis is carried out for all atoms. As an example of NP analysis for a large-scale system, SiO2_NAO.dat and SiO2_NAO.std are provided in the directory work. These are example calculations for bulk SiO2 consisting of 648 atoms.

(c) Parameter used in NAO calculations: NAO.threshold
In NAO calculations, there is a process that separates occupied NAOs from Rydberg (low-occupation) NAOs. The keyword used as the threshold for this separation is NAO.threshold, and it specifies the number of electrons for each spin orbital. The default value is set to 0.85, and in most cases this value works well. If an unnatural number of occupied NAOs is obtained, please adjust NAO.threshold.
