4.11 Installation via a Debian package

In a WSL environment running an Ubuntu-based Linux distribution, OpenMX Ver. 4.0 can be installed as a Debian package. This package is built for x86_64 CPUs and supports WSL environments on both Intel and AMD processors. In addition, since the Intel oneAPI runtime libraries required to execute OpenMX itself are bundled in the package, users can start calculations with the openmx command without separately installing Intel oneAPI at the first stage.

The Debian package of OpenMX can be downloaded from the OpenMX web site and installed as follows.

 For Ubuntu 24.04/26.04 and Debian 12/13 with OpenMPI
     % wget -O ./openmx_4.0.1-1_amd64.deb https://www.openmx-square.org/deb/openmx_4.0.1-1_amd64.deb
     % sudo apt install -y ./openmx_4.0.1-1_amd64.deb
 For Ubuntu 24.04 with Intel oneAPI
     % wget -O ./openmx4.0.1-wsl_amd64.deb https://www.openmx-square.org/deb/openmx4.0.1-wsl_amd64-Ubuntu24.04.deb
     % sudo apt install -y ./openmx4.0.1-wsl_amd64.deb
 For Ubuntu 26.04 with Intel oneAPI
     % wget -O ./openmx4.0.1-wsl_amd64.deb https://www.openmx-square.org/deb/openmx4.0.1-wsl_amd64-Ubuntu26.04.deb
     % sudo apt install -y ./openmx4.0.1-wsl_amd64.deb

If the installation completes successfully, the OpenMX executable and the accompanying utilities are placed under /opt/openmx4.0, and major executables such as openmx and DosMain can be invoked directly by their command names.

After installation, it is recommended to first create a working directory named openmx_work under the home directory and perform a test calculation using the supplied input file Methane.dat. The following commands create the working directory, copy the input file, and run the test calculation.

     % mkdir -p ~/openmx_work
     % cd ~/openmx_work
     % cp /opt/openmx4.0/work/Methane.dat ./
     % openmx ./Methane.dat | tee met.std

If the calculation finishes normally, compare the obtained output with the results in Sec. 5. If the total energy, eigenvalues, atomic charges, and other quantities are consistent with those in Sec. 5, the installation has completed successfully.

In an environment where Intel oneAPI is installed separately, MPI parallel execution is also available. For example, when using two MPI processes, the calculation can be executed as follows.

     % mpirun -np 2 openmx ./Methane.dat | tee met.std

First confirm the installation with a non-MPI execution, and then proceed to MPI parallel execution if needed.
