42 Second variational method: magnetic anisotropy energy (MAE)

In the previous section, we introduced the constraint DFT method for controlling spin orientation. The magnetic anisotropy energy of magnetic systems can be evaluated using the constraint DFT method. In this case, the magnetic anisotropy energy is calculated from the self-consistently obtained total energies. However, the computational cost is high, and for degenerate localized d orbitals, it may fail to give the correct result because the freedom in occupation-number space can trap the calculation in local solutions. One way to avoid these problems is to use the second variational method. The basic idea of the second variational method is to use the fact that spin-orbit interaction is a relatively small perturbation to the scalar-relativistic base band structure: first, the collinear eigenstates without SOC are used as a basis, and then the Hamiltonian including SOC is diagonalized within that subspace. In this method, the SCF electron density is first calculated by a collinear DFT calculation. Restart files are generated at this stage. Next, using these restart files, only one diagonalization is carried out within the framework of the non-collinear DFT method. In that step, spin-orbit interaction (SOI) is taken into account and diagonalization is performed. This computational scheme is called the second variational method. Since the second variational method is based on the Harris functional [14], if the input density is sufficiently good, the total-energy difference can be estimated with high accuracy by only one diagonalization. The effects of spin rotation and the perturbation due to spin-orbit interaction appear only in the band energy. The total energy can be written as the sum of the band energy and the double-counting terms, but by using the Harris functional, the total energy can be evaluated with an error of second order in the difference between the input electron density and the SCF electron density, by only one diagonalization. In that case, the double-counting terms are calculated only from the input electron density, so the perturbation energy due to spin rotation and spin-orbit interaction is included only in the band energy. Therefore, when comparing energies, one should focus only on the band energy. The double-counting terms in the Harris functional do not depend on the spin rotation angle. In the OpenMX output they may appear to change, but this is because each energy term is calculated from the output electrons rather than the input electrons (please be careful not to be misled by the output). Using the second variational method, first calculate the ferromagnetic state by the collinear DFT method and obtain the SCF electron density. Next, using the restart file that stores the SCF electron density, take spin-orbit interaction into account within the framework of non-collinear DFT, and perform only one diagonalization. The restart file is read by the following keywords .

       scf.restart.filename               FePt
       scf.restart                        c2n

The restart file to be read is specified by the keyword scf.restart.filename. By c2n of the keyword scf.restart, the restart file generated by the collinear DFT calculation is converted for use in a non-collinear DFT calculation. As an example, run the first collinear calculation using the input file FePt.dat available in work, and generate the restart file. In the second calculation, the spin orientation is specified by the following keywords. 

       scf.Restart.Spin.Angle.Theta       90.0
       scf.Restart.Spin.Angle.Phi          0.0

These two keywords specify the Euler angles (θ, ϕ) of the spin orientation. The spin direction on all real-space grids is aligned in the same direction specified by these Euler angles.

Therefore, note that the evaluation of magnetic anisotropy energy (MAE) by the second variational method is applicable only to ferromagnets. Here we show one example of how the second variational method is applied to the evaluation of MAE. Fig. 41 shows the MAE curve as a function of the spin rotation angle in bulk L10 FePt. The Full SCF result was obtained by the constraint DFT method described in Section 41. Since the input file FePt-NC-SCF.dat is stored in the work directory, the user can perform the same calculation. Using non-collinear DFT calculations including spin-orbit interaction, fully self-consistent calculations were performed for each spin rotation angle. Here the electronic temperature was 300 K and the number of k points was 173. As a result, the Full SCF calculation yielded an MAE of 2.78 meV/f.u. The two results obtained by the second variational method are also shown in Fig. 41. First, the collinear calculation is performed using the input file FePt.dat in the work directory to generate the restart file. Next, only one diagonalization is performed using the input file FePt-NC.dat in the work directory. In one of the two calculations by the second variational method, the same electronic temperature (300 K) and the same number of k points as in Full SCF were used. In this case, the MAE was 2.89 meV/f.u. In the other case, the electronic temperatures (k-point grids) in the first SCF calculation and the second calculation were 800 K (93) and 300 K (173), respectively. In this case, the MAE was 2.90 meV/f.u. Since these two calculations by the second variational method give almost the same result, it is likely acceptable to use different electronic temperatures and numbers of k points in the collinear SCF calculation for generating the SCF electron density and in the non-collinear calculation (including spin-orbit interaction). By assigning a high electronic temperature and a small number of k points to the SCF calculation, computational efficiency can be improved, while for the second non-collinear calculation, the accuracy can be improved by using a low electronic temperature and a large number of k points. We note again that in the second variational method one should focus on Uele rather than Utot in the output file. Since MAE is generally a tiny energy difference on the order of meV, it is important in the second-stage non-collinear calculation to use a low electronic temperature and a sufficiently dense k-point mesh, and to carefully confirm the convergence of Uele. Because the second variational method is based on the Harris functional, MAE should be evaluated using Uele. On the other hand, MAE in the full SCF calculation is evaluated using the total energy Utot. The difference between full SCF and the second variational method in the evaluation of MAE is about 0.1 meV/f.u. Therefore, the second variational method is considered to be an efficient approach to MAE evaluation from the viewpoints of both accuracy and efficiency.

The second variational method can be used not only for evaluating MAE but also for investigating how spin-orbit interaction changes the band structure. That is, it may also be applicable to the analysis of band structures of large-scale systems for which direct SCF calculations by the non-collinear DFT method are difficult.
