62.2 Case of Si

The calculation is explained using the input file Si2_k50x50x50.dat located in the directory work. This input file is intended for a bulk Si calculation with two atoms in the unit cell. For the SCF calculation and the conductivity calculation, 10×10×10 k points and 50×50×50 k points are used, respectively. The calculation is performed as follows.

   % mpirun -np 28 ./openmx Si2_k50x50x50.dat

After the SCF calculation is successfully completed, the optical-conductivity calculation starts. At that stage, the message ‘<Optical calculations start>’ is printed to the standard output.

From the standard output, we can see that the elapsed time required for the optical-conductivity calculation is about 278 seconds. After the calculation is completed, the following related output files are obtained.

   Si2_k50x50x50.cd_re                 real part of optical conductivity tensor
   Si2_k50x50x50.cd_im                 imaginary part of optical conductivity tensor
   Si2_k50x50x50.df_re                 real part of dielectric function tensor
   Si2_k50x50x50.df_im                 imaginary part of dielectric function tensor
   Si2_k50x50x50.absorption            absorption tensor
   Si2_k50x50x50.extinction            extinction tensor
   Si2_k50x50x50.transmission          transmission tensor
   Si2_k50x50x50.reflection            reflection tensor
   Si2_k50x50x50.refractive_index      refractive index tensor

The first column is the photon energy (eV), and from the second column onward, the tensor components σx⁢x, σx⁢y, and so on are listed. The last column gives the average of the diagonal components σx⁢x, σy⁢y, and σz⁢z. The other output files follow the same format as Si2_k50x50x50.cd_re. By plotting the first column as the horizontal axis and the second column as the vertical axis for Si2_k50x50x50.cd_re, Si2_k50x50x50.cd_im, Si2_k50x50x50.df_re, and Si2_k50x50x50.df_im, one obtains the optical conductivity σx⁢x and dielectric function εx⁢x shown in Fig. 93.
