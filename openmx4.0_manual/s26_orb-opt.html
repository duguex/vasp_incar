26 Optimization of basis functions

The orbital optimization method [44] can be used to variationally optimize the radial functions of basis orbitals. Using the methane molecule (input file Methane_OO.dat) as an example, we explain the procedure of orbital optimization. In the orbital optimization method, the optimized radial functions are represented as linear combinations of primitive radial functions. The coefficients of the linear combinations are called contraction coefficients, and these contraction coefficients are optimized based on the variational principle. The numbers of primitive radial functions and optimized radial functions in the orbital optimization method are specified in as follows.

    <Definition.of.Atomic.Species
      H   H5.0-s4>1            H_CA19
      C   C5.0-s4>1p4>1        C_CA19
    Definition.of.Atomic.Species>

For the s orbital of hydrogen (H), one optimized radial function is obtained as a linear combination of four primitive radial functions. Similarly, for carbon (C), one optimized radial function for the s orbital and one for the p orbital are obtained as linear combinations of four primitive radial functions. In addition, the orbital optimization method is controlled by the following keywords. 

    orbitalOpt.Method          species     # Off|Species|Atoms
    orbitalOpt.Opt.Method        EF        # DIIS|EF
    orbitalOpt.SD.step        0.001        # default=0.001
    orbitalOpt.HistoryPulay     30         # default=15
    orbitalOpt.StartPulay       10         # default=1
    orbitalOpt.scf.maxIter      60         # default=40
    orbitalOpt.Opt.maxIter     140         # default=100
    orbitalOpt.per.MDIter       20         # default=1000000
    orbitalOpt.criterion      1.0e-4       # default=1.0e-4

    CntOrb.fileout               on        # on|off, default=off
    Num.CntOrb.Atoms             2         # default=1
    <Atoms.Cont.Orbitals
     1
     2
    Atoms.Cont.Orbitals>

Run OpenMX in the usual way using the input file Methane_OO.dat, which is stored in the directory work, as follows:

    % ./openmx Methane_OO.dat

If the calculation finishes normally, the history of orbital optimization is recorded in the file met_oo.out.

In many cases, convergence is reached within 20 to 50 iterations. The total energies of the methane molecule calculated with primitive basis orbitals and optimized basis orbitals are shown below.

    Primitive basis orbitals
       Utot  =      -7.992595743656 (Hartree)

    Optimized orbitals by the orbital optimization
       Utot  =      -8.133760535960 (Hartree)

The total energy is lowered by orbital optimization, indicating that the basis orbitals are variationally optimized. Figure 21 shows the convergence behavior of the total energies for molecules and bulk systems obtained using primitive basis orbitals and optimized basis orbitals. For all the systems treated here, the optimized basis orbitals show better convergence characteristics. In the methane example above, the optimized basis orbitals are output to two files, C_1.pao and H_2.pao. These files, C_1.pao and H_2.pao, can be used directly as input data for pseudo-atomic basis orbitals in OpenMX calculations. Since the optimized basis orbitals are written to files, it is convenient to optimize the basis orbitals in advance for the system to be calculated. In doing so, we recommend choosing a small system that is chemically similar as the target system to which the orbital optimization method is applied.

The keyword orbitalOpt.Method provides the following two options. (1) atoms, in which the basis orbitals on each atom are optimized individually, (2) species, in which the basis orbitals for each atomic species are optimized.

  • •

    atoms

    The basis orbitals are optimized for each atom independently. Since the radial wave function R does not depend on the magnetic quantum number, the invariance of the total energy with respect to rotation of the system is guaranteed.

  • •

    species

    Basis orbitals for atomic species with the same name defined in Definition.of.Atomic.Species are optimized into the same orbitals. Since the radial wave function R does not depend on the magnetic quantum number, the invariance of the total energy with respect to rotation of the system is guaranteed. This is a useful option when one wishes to generate the same optimized basis orbitals for atoms in almost the same chemical environment.

Although similar information is also given in Section 8, the details of the related keywords are listed below for the convenience of users.
orbitalOpt.scf.maxIter
The keyword orbitalOpt.scf.maxIter specifies the maximum number of SCF iterations in orbital optimization.
orbitalOpt.Opt.maxIter
The keyword orbitalOpt.Opt.maxIter specifies the maximum number of orbital-optimization iterations. The orbital optimization loop terminates after the number of iterations specified by this keyword, even if the convergence criterion is not satisfied.
orbitalOpt.Opt.Method
Two methods are supported for achieving convergence in orbital optimization. EF denotes the eigenvector-following method, and DIIS denotes the direct inversion in the iterative subspace method. The algorithms are the same as those used for structural optimization. Specify either EF or DIIS for the keyword orbitalOpt.Opt.Method.
orbitalOpt.StartPulay
The quasi-Newton method, either EF or DIIS, starts from the optimization step specified by the keyword orbitalOpt.StartPulay.
orbitalOpt.HistoryPulay
In the quasi-Newton methods EF and DIIS, the keyword orbitalOpt.HistoryPulay specifies the number of previous steps referenced to estimate the contraction coefficients for the next step.
orbitalOpt.SD.step
The steepest-descent method is applied to the optimization steps before the quasi-Newton methods EF and DIIS are started. The prefactor used in the steepest-descent method is specified by the keyword orbitalOpt.SD.step. In many cases, an appropriate value of orbitalOpt.SD.step is about 0.001.
orbitalOpt.criterion
The keyword orbitalOpt.criterion specifies the convergence criterion for orbital optimization in units of (Hartree/bohr)2. The iteration loop terminates when the condition gradient norm < orbitalOpt.criterion is satisfied.
CntOrb.fileout
To output optimized radial functions to files, the keyword CntOrb.fileout must be set to on.
Num.CntOrb.Atoms
The keyword Num.CntOrb.Atoms specifies the number of atoms for which optimized radial functions are output to files.
Atoms.Cont.Orbitals
Using the serial numbers of atoms defined in the first column of the keyword Atoms.SpeciesAndCoordinates, the atoms for which optimized basis orbitals are output are specified by the keyword Atoms.Cont.Orbitals as follows.

    <Atoms.Cont.Orbitals
     1
     2
    Atoms.Cont.Orbitals>

The description starts with <Atoms.Cont.Orbitals and ends with Atoms.Cont.Orbitals>. The number of lines must be consistent with the number specified by
Num.CntOrb.Atoms. For example, if the optimized pseudo-atomic orbitals are saved as C_1.pao and H_2.pao, the atomic-species name corresponds to the symbol in the first column of the keyword Definition.of.Atomic.Species, and the number following the symbol indicates the value in the first column of the keyword Atoms.SpeciesAndCoordinates. These output files, C_1.pao and H_2.pao, can be used as input data for basis orbitals.
