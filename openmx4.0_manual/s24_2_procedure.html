24.2 COHP/COOP procedure

Let us calculate COHP and COOP for crystalline Si as an example. Run OpenMX as follows:

  $ mpiexec -np 28 ./openmx Sidia_COHP.dat | tee sidia_cohp.std

If the calculation finishes normally, the binary file sidia_cohp.cohp is generated. The input keywords related to COHP and COOP specified in the OpenMX input file Sidia_COHP.dat are listed below.

   Dos.fileout                   on
   Dos.Erange                    -20.0  20.0
   Dos.Kgrid                     13  13  13

   COHP.calc.flag      on
   COHP.num.pairs      1
   <COHP.pairs
    1  1 2  0 0 0
   COHP.pairs>

The meanings of these keywords are as follows.
Dos.fileout
The calculations of COHP and COOP are carried out simultaneously with the DOS calculation. Therefore, specify on when calculating COHP and COOP. The default value is off.

Dos.Erange
Specifies the energy range in eV for evaluating the DOS.

Dos.Kgrid
Specifies the number of k points used for the calculations of DOS, COHP, and COOP.

COHP.calc.flag
Specify on when calculating COHP and COOP. Since COOP is calculated simultaneously with COHP, there are no keywords related only to COOP. The default value is off.

COHP.num.pairs
Specifies the number of atomic pairs for which COHP and COOP are calculated.

COHP.pairs
Specifies the atomic pairs for which COHP and COOP are calculated. Each line is given in the following format.

 serial_number   atom1   atom2   l1   l2   l3

Here, the first column is the serial number, the second column is the index of the first atom of the pair, the third column is the index of the second atom of the pair, and the fourth to sixth columns are integers (l1,l2,l3) representing the translated cell in which the second atom exists. The position of the second atom is specified by

l1⁢𝐚1+l2⁢𝐚2+l3⁢𝐚3

where 𝐚1, 𝐚2, and 𝐚3 are the lattice vectors.

Based on sidia_cohp.cohp, the energy-resolved COHP and COOP files can be generated by the post-processing code cohp. First, compile cohp in the OpenMX source directory as follows.

   $ make cohp

The compiled executable cohp is copied to the work directory. Then, execute it as follows.

   [ozaki@gauss01 work]$ ./cohp sidia_cohp.cohp
   Which method do you use?, Tetrahedron(1), Gaussian Broadening(2)
   1
   Please input the number of energy meshes
   3000
   Which pair for COHP : (1 to 1)
   1
   generating...
    sidia_cohp_i1_o0_o0_s0_tetra.cohp
    sidia_cohp_i1_o0_o1_s0_tetra.cohp
    sidia_cohp_i1_o0_o2_s0_tetra.cohp
    sidia_cohp_i1_o0_o3_s0_tetra.cohp
    ...
    ...

Either the tetrahedron method or the Gaussian broadening method can be selected. Also specify the number of energy meshes.

Then specify the serial number of the atomic pair for which COHP is calculated. The serial number here is the number in the first column specified in COHP.pairs. After it is specified, multiple COHP files for the designated atomic pair are generated. The meanings of the subscripts in the output file names are as follows.

  • •

    i1: serial number of the atomic pair

  • •

    first o0: basis-function index of the first atom in the pair

  • •

    next o0: basis-function index of the second atom in the pair

  • •

    s0: spin index

In each file, the first, second, and third columns represent the energy (eV), COHP (dimensionless quantity), and the integrated COHP up to that energy, respectively. In addition to the COHP files decomposed into pseudo-atomic orbitals (PAOs), COHP files summed over the basis-function indices of the second atom of the pair are also output as follows.

    sidia_cohp_i1_o0_s0_tetra.cohp
    sidia_cohp_i1_o1_s0_tetra.cohp
    sidia_cohp_i1_o2_s0_tetra.cohp
    sidia_cohp_i1_o3_s0_tetra.cohp
    ...
    ...

Furthermore, a COHP file summed over all basis-function indices of both the first and second atoms of the pair is also output as follows.

    sidia_cohp_i1_s0_tetra.cohp

COOP files (with the extension coop) are also output in the same format.

Figure19(a) shows the total density of states of crystalline Si, and Fig.19(b) shows the COHP and COOP between neighboring Si atoms. It can be seen that the states below the chemical potential (0 eV) are bonding states. Figure19(b) was obtained by plotting sidia_cohp_i1_s0_tetra.cohp. By analyzing the orbital-resolved COHP files in detail, it is possible to further identify the contributions of the pseudo-atomic orbitals participating in bonding and antibonding.


Let us show another example. Figure20(b) shows the COHP between the 3⁢d transition metal and the N atom for rock-salt ScN, TiN, and VN. One can clearly understand how the bonding states change depending on the number of d electrons of the 3⁢d transition metal. In ScN, the states below the chemical potential (0 eV) are bonding states, whereas in TiN and VN, it can be seen that, with the increase in the number of d electrons, electrons occupy antibonding states.
