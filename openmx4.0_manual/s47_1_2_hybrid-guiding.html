47.1.2 Hybrid-orbital guiding functions

CWFs can be generated using hybrid orbitals as guiding functions. The hybrid orbitals here are constructed as linear combinations of PAOs on each atomic site. As in the previous subsection, we explain the procedure using GaAs as an example. The input file GaAs-CWF3.dat in the work directory is almost the same as GaAs-CWF2.dat used in the previous subsection, but because hybrid orbitals are used as guiding functions, the following setting is employed.

     CWF.Guiding.Orbitals     HO

Run the calculation using this input file GaAs-CWF3.dat.

     % mpirun -np 8 openmx GaAs-CWF3.dat | tee GaAs-CWF3.std

If the calculation finishes normally, GaAs-CWF3.Band and GaAs-CWF3.CWF.Band are output. By following the procedure in Sec. 22, “Band dispersion”, the band dispersion shown in Fig. 54(a) is obtained. It can be seen that the Wannier-interpolated bands reproduce the original bands well. The obtained CWFs are shown in Fig. 54(b). Unlike the case where PAOs are used as guiding functions (Fig. 52(d)), the CWFs are oriented toward neighboring atoms. However, if the same PAOs are chosen as guiding functions, the atomic-like orbitals and hybrid orbitals span the same subspace, and thus the resulting CWFs also span the same subspace. Therefore, the accuracy of the interpolated bands is identical.
