20.4 Multi-heat-bath molecular dynamics (NVT_VS4)

In OpenMX Ver. 4.0, multi-heat-bath molecular dynamics simulations can be performed. The temperature of each group of atoms is controlled by a heat bath based on the velocity-scaling method [31]. This method is invoked using the following keyword.

    MD.Type          NVT_VS4

The number of groups is specified by 

    MD.num.AtomGroup    2

The groups are defined by as follows.

    <MD.AtomGroup
      1  1
      2  1
      3  1
      4  2
      5  2
    MD.AtomGroup>

The first line is <MD.AtomGroup, and the last line is MD.AtomGroup>. The first column is the serial number used to identify each atom, corresponding to the numbering specified in Atoms.SpeciesAndCoordinates. The second column is the group number to which each atom belongs. This number must start from 1 and be assigned in the order 1, 2, 3, ⋯. The above example corresponds to a system consisting of only five atoms, divided into two groups. In Ver. 4.0, the temperature profile of all groups is controlled by the keyword MD.TempControl, as described in Section 20.2.
