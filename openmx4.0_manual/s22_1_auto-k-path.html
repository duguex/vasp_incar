22.1 Automatic k-path generation

In a standard band-structure calculation, the choice of which high-symmetry k points should be connected and in what order strongly affects both the readability of the resulting plot and the ease of comparison with the literature. Performing this task manually every time is cumbersome, and depending on the choice of unit cell, the names of high-symmetry points and the path itself can easily be misunderstood. In OpenMX, one can readily prepare a standard and reproducible k-path based on crystal symmetry by using the automatic generation function of OpenMX Viewer [165, 164] or cif2omx. In particular, OpenMX Viewer is very useful as a starting point for ordinary band calculations, because the first Brillouin zone and the suggested path can be visualized simultaneously while checking the path. The idea of the suggested path is based on the standard proposal by Setyawan and Curtarolo [167].

For the selection of a k-path in an ordinary band-structure calculation, we recommend using the automatic generation function of OpenMX Viewer [165, 164]. After loading a crystal structure, OpenMX Viewer can display the first Brillouin zone and superimpose the suggested k-path inside it. Therefore, one can determine the path for the band-structure calculation while visually checking which high-symmetry points should be connected and in what order. This is particularly useful for face-centered, body-centered, base-centered, and rhombohedral lattices, where the names of high-symmetry points and the appearance of the path may depend on the choice of unit cell. Figure 17 shows examples of the first Brillouin zone and the suggested k-path displayed by OpenMX Viewer. The red lines represent the suggested path, allowing one to grasp the positional relationships among the high-symmetry k points intuitively.

OpenMX Viewer not only displays the suggested k-path, but can also output the corresponding path information to a file. In addition, in the OpenMX input file generated by OpenMX Viewer, the keywords for band calculations containing the corresponding path information are automatically set. Therefore, it is no longer necessary to look up high-symmetry k points manually and write Band.kpath from scratch, and the input required for an ordinary band-structure calculation can be prepared in a short time. In practice, it is useful first to obtain a standard path using the automatic generation function of OpenMX Viewer, and then, depending on the target system and comparison with the existing literature, to adjust the number of division points in each segment and the path itself as needed. Since the suggested path may also change depending on which unit cell is adopted, please finally check the contents of Band.KPath.UnitCell and Band.kpath to confirm that the path corresponds to the intended unit cell.

The tool cif2omx introduced in Sec. 8.3 can also be used to automatically generate a k-path when an OpenMX dat file is created from a CIF file. When the crystal structure is given as a CIF file, it is efficient first to generate an initial dat file with cif2omx and then to use the automatically generated k-path as a starting point. This is particularly useful when one wants to prepare inputs for band-structure calculations for many crystal structures according to the same policy. On the other hand, the automatically generated path is a standard candidate based on crystal symmetry, and it is not always optimal as it stands for every research purpose. For example, if one wants to examine in detail how degeneracies are lifted, to sample densely around a specific crossing point or extremum, or to reproduce exactly the same path as in an existing paper, please modify the segments and the number of division points in Band.kpath as appropriate on the basis of the automatically generated path. Thus, the automatic generation functions provided by OpenMX Viewer and cif2omx are very useful because they quickly provide a reliable starting point for ordinary band-structure calculations, but it is important that the validity of the final path always be checked in light of the purpose of the calculation.
