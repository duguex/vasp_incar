53 STM images based on the Tersoff-Hamann method

STM images can be calculated by the Tersoff-Hamann method [78]. This method is nothing but a calculation of the partial charge density within an energy window measured from the chemical potential. The partial charge density is calculated using the following keywords. 

  partial.charge                 on       # on|off, default=off
  partial.charge.energy.window   0.0      # in eV

Here, the second keyword specifies the energy window (in eV) measured from the chemical potential (positive values correspond to the conduction band, while negative values correspond to the valence band). Since the calculation of the partial charge density is carried out during the DOS calculation, the following keywords also need to be specified.

 Dos.fileout                  on        # on|off, default=off
 Dos.Erange              -20.0  20.0    # default = -20 20
 Dos.Kgrid                  5 5 5       # default = Kgrid1 Kgrid2 Kgrid3

If the calculation finishes successfully, System.Name.pden.cube, which can be used for STM simulations within the scope of the Tersoff-Hamann approximation, is generated. As an example, Fig. 72 shows an STM image of a graphene layer obtained by this method.
