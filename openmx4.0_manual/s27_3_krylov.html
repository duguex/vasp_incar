27.3 O(N) Krylov subspace method

The DC method can be applied to a wide variety of systems and is numerically stable. However, in order to obtain highly accurate results for metallic systems, as shown in Fig. 23, it is necessary to enlarge the size of the truncated clusters, and in that case the computational cost increases. One way to reduce the computational cost is to map the vector space defined by the truncated clusters onto a lower-dimensional Krylov subspace [46]. The O(N) Krylov subspace method is available using the following keyword.

     scf.EigenvalueSolver       Krylov

Basically, the computational accuracy and efficiency are controlled by the following two keywords.

    orderN.HoppingRanges         6.0
    orderN.KrylovH.order         400

The keyword orderN.HoppingRanges defines the radius of a sphere centered on each atom, just as in the DC method. The dimension of the Krylov subspace for the Hamiltonian is specified by the keyword orderN.KrylovH.order. Moreover, the details of calculations using the O(N) Krylov subspace method can be controlled by the following keywords.

  • •

    orderN.Exact.Inverse.S       on| off, default=on

    If the keyword orderN.Exact.Inverse.S is set to on, the inverse of the overlap matrix for each truncated cluster is evaluated exactly. If it is set to off, refer to the entry for the keyword orderN.KrylovS.order below. The default is on.

  • •

    orderN.KrylovS.order       1200, default=orderN.KrylovH.order×4

    If orderN.Exact.Inverse.S=off, the inverse matrix is approximated by the Krylov subspace method. In this case, the dimension of the Krylov subspace for the overlap matrix of each truncated cluster is specified by the keyword orderN.KrylovS.order. The default value is four times the value specified by orderN.KrylovH.order.

  • •

    orderN.Recalc.Buffer       on| off, default=on

    If the keyword orderN.Recalc.Buffer is set to on, the buffer matrix is recalculated at every SCF iteration. If it is set to off, the buffer matrix is calculated in the first SCF step and then kept fixed in subsequent SCF iterations. The default is on.

  • •

    orderN.Expand.Core       on| off, default=on

    If the keyword orderN.Expand.Core is set to on, the core region consists of atoms inside a sphere with radius 1.2×rmin. Here, rmin is the distance between the central atom and its nearest-neighbor atom. This core region defines the set of vectors used in the first step of generating the Krylov subspace. If orderN.Expand.Core is set to off, only the central atom is regarded as the core region. The default is on.

In general, the keywords orderN.Exact.Inverse.S and orderN.Expand.Core tend to improve convergence when set to on for covalent materials, whereas convergence may improve in simple metals when they are set to off. Figure 28 shows the absolute errors in the total energy calculated by the Krylov method and the DC method for various materials. In particular, for metallic systems the Krylov subspace method is more efficient than the DC method, whereas for covalent and ionic systems the computational times are found to be comparable.


In order to realize large-scale calculations, the O(N) Krylov subspace method has been implemented with careful consideration of parallelization. In MPI parallelization, the computation can be accelerated up to a number of MPI processes equal to the number of atoms. Furthermore, by using OpenMP threads in OpenMP/MPI hybrid parallelization, the computational speed can be increased further. An example of a parallel calculation for a system consisting of more than 100,000 atoms on a massively parallel computer is shown in Fig. 29 [47, 48]. In this example, a benchmark calculation was carried out for diamond consisting of 131072 carbon atoms using 131072 MPI processes, and the parallel efficiency reached 68%.
