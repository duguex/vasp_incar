20.7 NPT molecular dynamics by the velocity-scaling method and the Wentzcovitch method (NPT_VS_WV)

On the basis of the velocity-scaling method [31] and the Wentzcovitch method [34], constant-temperature and constant-pressure molecular dynamics simulations can be performed. In this method as well, in addition to the forces acting on atoms, the cell degrees of freedom are evolved in time using the stress tensor calculated from the total energy. Most of the explanation here is similar to that for the NPT_VS_PR method in the previous subsection, but for the convenience of users, it is described independently here as well. In an NPT-ensemble molecular dynamics simulation, the fractional coordinates 𝐚 of the atoms are updated according to the following equation of motion.

(𝐚¨)i=−∑α(KT)iα⁢1m𝐚⁢∂E∂(𝐫)α−∑j(G−1⁢G˙)i⁢j⁢(𝐚˙)j, (28)

Here, i={a,b,c} and α={x,y,z}, and K≡(𝐊a,𝐊b,𝐊c) consists of the reciprocal lattice vectors 𝐊a,𝐊b,𝐊c. In addition, G=LT⁢L, and L≡(𝐋a,𝐋b,𝐋c) consists of the lattice vectors 𝐋a,𝐋b,𝐋c. The lattice vectors are updated according to the following equation of motion.

(L¨)iα=∑l[1W⁢∑β[1Ω⁢∑j⁢k(L)jα⁢[∑𝐚m𝐚⁢(𝐚˙)j⁢(𝐚˙)k]⁢(LT)kβ+(σstatic)α⁢β−Pext⁢(𝐈)α⁢β]⁢𝚺iβ⁢12⁢Tr⁢(𝐄𝐅′)lα−(𝐋˙⁢𝐅˙)lα], (29)

Here, σstatic is the static strain tensor, and W is the piston mass in the Wentzcovitch method. For details of the method, refer to the original paper [34]. To perform an NPT molecular dynamics simulation, specify the following keyword.

      MD.Type               NPT_VS_WV

The value of the piston mass W can be specified by the following keyword.

      NPT.Mass.Barostat     0.001

In this specification, the unified atomic mass unit is used, in which the mass of the major isotope of carbon is taken as 12.0. If this keyword is not specified, the default value of the piston mass W is automatically given by the following equation.

W=3400⁢π2⁢Ω⁢∑𝐚m𝐚, (30)

where Ω is the volume of the unit cell. The specified piston mass W can be confirmed by examining the standard output, where information such as the following is displayed.

      A default NPT.Mass.Barostat is set to 0.001542669557 (atomic mass unit).

As a starting point, please begin with this default value and adjust the piston mass W according to your purpose. Note that W is a quantity representing the fictitious inertia associated with the cell degrees of freedom. When W is made smaller, the cell responds more rapidly to the pressure difference, whereas when W is made larger, the response becomes slower.

The temperature of nuclear motion can be controlled by 

      <MD.TempControl
         1
         2000    10      1000.0  0.5            # step, interval, temp[K], alpha
      MD.TempControl>

This keyword has exactly the same role as in NVT molecular dynamics by the velocity-scaling method (NVT_VS). Please refer to Subsection 20.2. The applied pressure can also be controlled by 

      <MD.CellPressureControl
        3
        100   10.0
        400   20.0
       1000   40.0
      MD.CellPressureControl>

The description must begin with <MD.CellPressureControl, and must end with MD.CellPressureControl>. The initial number “3” indicates the number of lines that follow for controlling the applied pressure. In this case, it is seen that three lines are specified. In each of the following lines, the first column represents the MD step, and the second column gives the applied pressure in units of GPa. The pressure within each interval is given by linear interpolation. Positive pressure corresponds to compression of the cell. Note also that constrained molecular dynamics is not compatible with the NPT method.

In addition, the following two keywords can also be used to control an NPT molecular dynamics simulation. 

      NPT.LatticeRestriction      none       # none, cubic, ortho, default=none
      MD.TempTolerance            100        # Kelvin, default=100 K

The keyword NPT.LatticeRestriction can be used to restrict the shape of the unit cell. Only the three options “none”, “cubic”, and “ortho” are available. The default is “none”, in which case the unit-cell shape is not restricted. On the other hand, “cubic” and “ortho” restrict the unit-cell shape to cubic and orthorhombic, respectively. The keyword MD.TempTolerance controls the condition for applying velocity scaling. If the absolute difference between the calculated temperature and the given temperature is smaller than the Kelvin value specified by this keyword, velocity scaling is not applied. The default value is 100 (K).

Furthermore, when the unit cell is orthorhombic, anisotropic pressure can also be applied by the following keyword. 

   MD.applied.pressure.flag   1 1 1   # default=1 1 1

The default setting is “1 1 1”, which means that isotropic pressure is applied equally along the 𝐚, 𝐛, and 𝐜 axes. For example, if “1 0 0” is specified, the pressure is applied only along the 𝐚-axis direction, that is, in the direction perpendicular to the 𝐛𝐜 plane in an orthorhombic system. This function related to anisotropic pressure is effective for orthorhombic systems, in which case the unit vectors should be given as follows. 

    <Atoms.UnitVectors
     10.000   0.000   0.000
      0.000   8.000   0.000
      0.000   0.000  11.000
    Atoms.UnitVectors>

In this way, the nonzero components should appear only as diagonal components. Even in systems other than orthorhombic ones, anisotropic pressure can be applied along the lattice-vector direction perpendicular to the plane spanned by the other two lattice vectors. One example is found in a hexagonal system, for which the keyword should be specified as follows.

   MD.applied.pressure.flag   0 0 1   # default=1 1 1

    <Atoms.UnitVectors
      6.000   0.000   0.000
     -3.000   5.196   0.000
      0.000   0.000  10.000
    Atoms.UnitVectors>

As an example of the NPT_VS_WV method, Fig. 14 (a) shows the time evolution of the volume of a Si crystal under conditions of 10 GPa and 1000 K. This NPT simulation was carried out using the input file Si_NPT_VS_WV.dat stored in the directory work. When the calculation is performed with this input file, the output file Si_NPT_VS_WV.npt.ene is obtained. The quantities stored in the output file Si_NPT_VS_WV.npt.ene are listed below.

         1:    MD step
         2:    MD time (fs)
         3:    Volume (Bohr^3)
         4:    Calculated temperature (K)
         5:    Internal pressure = -1/3*Tr(stress tensor)/(volume of cell) (GPa)
         6:    Utot (Hartree)
         7:    Ukc (Hartree)
         8:    Ubaro = kinetic energy of cell (Hartree)
         9:    Wbaro = (given pressure)*(volume of cell) (Hartree)
        10:    Utot + Ukc + Ubaro + Wbaro (Hartree)

Here, the number in the first column indicates the column number in the output file. In Fig. 14 (a), the volume stored in the third column is plotted as a function of the MD time (fs) stored in the second column. Figures 14 (b) and (c) show the temperature (K) and pressure (GPa), respectively. Since 1000 K and 10 GPa are specified in the input file Si_NPT_VS_WV.dat, it can be seen that the temperature and pressure calculated for the system oscillate around the specified values as expected. The molecular-dynamics trajectory is stored in the output file Si_NPT_VS_WV.md, and can be visualized directly using OpenMX Viewer [165, 164]. Alternatively, the utility md2axsf can be used to convert the md file into an axsf file. See Subsection 20.10 for details.
