73 Automatic Memory Leak Tester

During the execution of OpenMX, the required memory is dynamically allocated as needed. In dynamic memory allocation, memory leaks may occur, and the memory usage may increase as the MD steps proceed, eventually leading to an abnormal termination.

Memory leaks can be checked by running OpenMX as follows.

Serial calculation 

     % ./openmx -mltest

Parallel calculation 

     % ./openmx -mltest "mpirun -np 4 openmx"

Memory leaks are monitored using the 14 test input files stored in the directory work/ml_example. In this process, the actual VSZ and RSS are monitored at the same monitoring points in the program code code. After the calculation finishes, the file mltest.result is generated. The monitored VSZ and RSS are output in the file mltest.result as functions of the MD steps, as shown below, so that you can check whether a memory leak has occurred.
