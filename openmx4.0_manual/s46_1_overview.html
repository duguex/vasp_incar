46.1 NEGF overview

Based on the non-equilibrium Green function method (NEGF), it is possible to calculate electron-transport properties of systems such as molecules, nanowires, and superlattice structures. The transport-calculation functionality supports both collinear and non-collinear calculations. In the NEGF method, a central region connected to two semi-infinite electrodes with different chemical potentials is treated, and electron transport in a non-equilibrium steady state is described. In the implementation of OpenMX Ver. 4.0, the electrodes and the central region can be treated within the same first-principles framework, and the electronic structure of the central region can be determined self-consistently even under a finite bias voltage [81]. Its features and capabilities are listed below.

  • •

    SCF calculations for systems connected to two electrodes under zero and finite bias voltages

  • •

    SCF calculations under a gate bias voltage

  • •

    Can be combined with the DFT+U method

  • •

    Spin-dependent transmission and current

  • •

    k-resolved transmission and current for directions perpendicular to the current

  • •

    Calculation of current-voltage characteristics

  • •

    Highly accurate and efficient contour integration

  • •

    Interpolation of bias-voltage effects

  • •

    Fast transmission calculations for periodic systems under zero bias voltage

  • •

    Eigenchannel analysis [154]

  • •

    Real-space current and spin current [152]

For details of the implementation of each functionality, refer to Ref. [81]. We first explain how to use each function for the collinear case. After that, supplementary remarks are given for the non-collinear case.

System to be considered

In the implementation of OpenMX Ver. 4.0, the system shown in Fig. 44 (a) is treated by the NEGF method. This system consists of left and right semi-infinite electrode regions and the central part connecting them, and two-dimensional periodicity on the bc plane is assumed. By taking this two-dimensional periodicity into account, the system can be transformed into a one-dimensional problem depending on the Bloch wave vector 𝐤, as shown in Fig. 44 (b). To take into account relaxation of the electronic structure near the interfaces between the central region C0 and the left and right regions L0 and R0, the implementation of OpenMX Ver. 4.0 self-consistently determines the Green function of the region C(≡L0⁢|C0|⁢R0). Note that, in the current implementation, it is assumed that the a axis of the unit cell is the direction of electron transport. This specification must be respected when constructing the geometry of the calculation model. In this regard, also see Section 46.2.


Flow of the calculation

NEGF calculations are carried out in the following three stages.
More specifically, (i) an SCF calculation for the electrodes, (ii) calculation of the equilibrium Green function for the extended central region, and, for finite bias, further (iii) evaluation of the non-equilibrium Green function and (iv) update and mixing of the electron density are performed, and after SCF convergence the transmission, current, current density, and eigenchannels are calculated.

Step 1 → Step 2 → Step 3

Each step is explained below.

  • •

    Step 1

    Perform band-structure calculations for the left and right electrode regions using the program code code. The obtained results are used for the electrode parts in the NEGF calculation of Step 2.

  • •

    Step 2

    For the system shown in Fig. 44, perform an NEGF calculation under zero or finite bias voltage using the program code code. At this stage, the results calculated in Step 1 are used to construct the electrode parts.

  • •

    Step 3

    Using the results obtained in Step 2, calculate the transmission, current density, spin-current density, and eigenchannels using the program code code.

Example: carbon chain

As a first example, we consider a carbon chain and explain the above three steps.

Step 1

      %./openmx Lead-Chain.dat | tee lead-chain.std

The file negf-chain.hks is generated by the Step 1 calculation.

Step 2

      %./openmx NEGF-Chain.dat | tee negf-chain.std

The file negf-chain.tranb is generated by the Step 2 calculation.

Step 3

After completing the Step 2 calculation, openmx automatically proceeds to the Step 3 calculation. If you want to perform the Step 2 and Step 3 calculations separately, run openmx as follows.

    %./openmx NEGF-Chain.dat | tee negf-chain.std

In Step 3, openmx reads negf-chain.tranb and calculates the transmission, current, and eigenchannels. After the calculation finishes, the following files are generated in Step 3.

  negf-chain.conductance            negf-chain.tranec0_0_0_2_i.cube
  negf-chain.current                negf-chain.tranec0_0_0_2_r.cube
  negf-chain.curden1.cube           negf-chain.tranec0_0_0_3_i.cube
  negf-chain.curden.xsf             negf-chain.tranec0_0_0_3_r.cube
  negf-chain.curden_atom.xsf        negf-chain.tranec0_0_0_4_i.cube
  negf-chain.tran0_0                negf-chain.tranec0_0_0_4_r.cube
  negf-chain.tranec0_0_0_0_i.cube   negf-chain.traneval0_0_0
  negf-chain.tranec0_0_0_0_r.cube   negf-chain.tranevec0_0_0
  negf-chain.tranec0_0_0_1_i.cube
  negf-chain.tranec0_0_0_1_r.cube

This calculation can be reproduced using the input files in the directory work. By plotting the sixth column of negf-chain.tran0_0 obtained in the Step 3 calculation as a function of the fourth column, the transmission curve shown in Fig. 45 is obtained.
