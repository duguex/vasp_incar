55.1 Analysis of band structures

First, let us decompose each band into contributions from pseudo-atomic orbitals for a band calculation of SiC in the primitive cell without structural imperfections. Here, band unfolding itself is not performed. The SCF calculation is carried out as follows.

  % mpirun -np 16 openmx SiC_Primitive.dat > sic_primitive.std &

The input file SiC_Primitive.dat is included in the work/unfolding_example directory, and the basis functions and structure are specified as follows.

Keywords relevant to analysis of band structure

For calculations using the band unfolding method, the following keywords must also be specified. 

  Unfolding.Electronic.Band      on       # on|off, default=off
  Unfolding.LowerBound        -10.0       # default=-10 eV
  Unfolding.UpperBound          6.0       # default= 10 eV

  Unfolding.Nkpoint               4

  <Unfolding.kpoint
  K 0.33333333333 0.33333333333 0.0000000000
  G 0.00000000000 0.00000000000 0.0000000000
  M 0.50000000000 0.00000000000 0.0000000000
  K 0.33333333333 0.33333333333 0.0000000000
  Unfolding.kpoint>

  Unfolding.desired_totalnkpt    30

The keywords listed above are explained below.

  • •

    Unfolding.Electronic.Band       on| off, default=off

    Setting this keyword to on enables the band unfolding method. The default is off.

  • •

    Unfolding.LowerBound

    Unfolding.LowerBound specifies the minimum band energy to be analyzed. The energy is referenced to the Fermi energy, and the default value is -10 eV.

  • •

    Unfolding.UpperBound

    Unfolding.UpperBound specifies the maximum band energy to be analyzed. The energy is referenced to the Fermi energy, and the default value is 10 eV.

  • •

    Unfolding.Nkpoint

    Unfolding.Nkpoint specifies the number of k points listed in Unfolding.kpoint.

  • •

    Unfolding.kpoint

    Unfolding.kpoint specifies the k points, with the number given by Unfolding.Nkpoint. In the above example, four k points are listed, defining the paths from K to G, from G to M, and from M to K. The band analysis is performed along this path. When specifying k points, please use normalized coordinates with respect to the reciprocal lattice vectors of the unit cell defined by Atoms.UnitVectors. The lattice vectors used in the band unfolding calculation can also be changed by Unfolding.ReferenceVectors. Note that if Unfolding.ReferenceVectors is not specified, the lattice vectors given in Atoms.UnitVectors are automatically used. Unfolding.ReferenceVectors is explained in the next subsection.

  • •

    Unfolding.desired_totalnkpt

    The path specified in Unfolding.kpoint is divided into approximately equal intervals, where the interval is estimated by (the total path length in k space)/Unfolding.desired_totalnkpt. However, the actual interval is automatically adjusted so that the k points specified in Unfolding.kpoint are always included in the analysis.

Output files relevant to analysis of band structure

Once the SCF calculation converges, the following files related to band analysis and unfolding are generated.

  • •

    sic_primitive.unfold_totup

    This file stores the total spectral weight obtained from Eq. (24) in Ref. [155]. The first column is the distance (in Bohr-1) from the first k point specified in Unfolding.kpoint, the second column is the energy (in eV) referenced to the Fermi energy, and the third column is the total spectral weight. For spin-polarized calculations, System.Name.unfold_totdn is additionally generated for the down-spin channel, while for non-collinear calculations a single file System.Name.unfold_tot is generated.

  • •

    sic_primitive.unfold_orbup

    This file stores the orbitally decomposed spectral weights obtained from Eq. (26) in Ref. [155]. The first column is the distance (in Bohr-1) from the first k point specified in Unfolding.kpoint, the second column is the energy (in eV) referenced to the Fermi energy, and the third column is the orbitally decomposed spectral weight. For the output order of the orbitally decomposed spectral weights, please refer to System.Name.out. For spin-polarized calculations, System.Name.unfold_orbdn is additionally generated for the down-spin channel, while for non-collinear calculations a single file System.Name.unfold_orb is generated.

  • •

    sic_primitive.unfold_plotexample

    An example gnuplot script for plotting the above data is generated as System.Name.unfold_plotexample. It can be plotted by typing the following command in the gnuplot command line.

            gnuplot> load ’sic_primitive.unfold_plotexample’

    Please edit it as needed for your purpose.

To plot sic_primitive.BANDDAT1 and sic_primitive.unfold_totup using gnuplot, use the following commands.

  gnuplot> set style data lines
  gnuplot> set zeroaxis
  gnuplot> set key below
  gnuplot> set ytics 1
  gnuplot> set mytics 5
  gnuplot> set xra [0.000000:1.708883]
  gnuplot> set yra [-10.0:6.0]
  gnuplot> set ylabel "eV"
  gnuplot> set xtics ("K" 0.000000, "G" 0.722258, "M" 1.347753, "K" 1.708882)
  gnuplot> p "sic_primitive.BANDDAT1","sic_primitive.unfold_totup" u 1:2:($3*0.02) w circle

These commands yield a figure similar to Fig. 74(a). The solid lines represent sic_primitive.BANDDAT1, and the circles represent sic_primitive.unfold_totup. The circle sizes reflect the spectral weights, but in the present case all circles have the same size, because the bands obtained in the Brillouin zone of the original cell are being analyzed.

Next, let us look at the orbitally decomposed spectral weight sic_primitive.unfold_orbup. As above, it can be plotted using the following commands.

  gnuplot> p "sic_primitive.BANDDAT1","sic_primitive.unfold_orbup" u 1:2:(($3+$4+$5+$6)*0.05) w circle,
  "sic_primitive.unfold_orbup" u 1:2:($7*0.05) w circle

These commands yield Fig. 74(b). In this example, the sum of the spectral weights of the carbon s, px, and py orbitals is plotted with green circles, while the spectral weight of the carbon pz orbital is plotted with purple circles. This analysis makes it possible to clearly distinguish the σ and π bands. For the format of sic_primitive.unfold_orbup, please refer to the explanation above.
