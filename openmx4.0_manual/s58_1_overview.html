58.1 Chern/Berry overview

The post-process code calB can be used to calculate the Chern number and the Berry curvature of bands. This calculation is based on the Fukui-Hatsugai-Suzuki method [90, 94], in which the Chern number and Berry curvature are calculated from overlap matrix elements between neighboring k-point Kohn–Sham orbitals. Note that this functionality is available only for non-collinear DFT calculations and cannot be used for collinear DFT calculations. If you publish results using this functionality, we would appreciate it if you would cite Ref. [93].

The Chern number is an integer-valued topological invariant characterizing the topology of bands in materials. In a system with a finite Chern number C, the anomalous Hall conductivity defined by the following equation is induced.

σx⁢y=−e2h⁢C⁢(C=1,2,3,⋯)

Using the Berry curvature 𝐅n=∇×𝐀n,𝐀n=−i⁢⟨un⁢𝐤|∂∂𝐤|un⁢𝐤⟩, the Chern number is defined as

C=12⁢π⁢∑nocc.∫Fn⁢z⁢𝑑k2

In the Fukui-Hatsugai-Suzuki method [90], the overlap matrix U defined by

UΔ⁢𝐤⁢(𝐤)=det⟨un⁢(𝐤)|um⁢(𝐤+Δ⁢𝐤)⟩

is used. This overlap matrix U plays the central role in calculating the Berry connection 𝐀⁢(𝐤) and Berry curvature F⁢(𝐤), defined by

𝐀⁢(𝐤)=Im⁢log⁡UΔ⁢𝐤⁢(𝐤),
F⁢(𝐤)=Im⁢log⁡UΔ⁢k1⁢(𝐤)⁢UΔ⁢k2⁢(𝐤+Δ⁢k1)⁢UΔ⁢k1−1⁢(𝐤+Δ⁢k2)⁢UΔ⁢k2−1⁢(𝐤)

As shown in Fig. 86, the Berry curvature is calculated on each ‘plaquette’ of a uniform grid introduced in the first Brillouin zone by the following formula. Here, a plaquette means a small region obtained by meshing the Brillouin zone.

F⁢(𝐤)=Im⁢log⁡U12⁢U23⁢U34⁢U41

By summing all contributions of the loop integral of the Berry curvature, the Chern number is obtained.

C=12⁢π⁢∑𝐤BZF⁢(𝐤)
