59.2 Z2 example

As an example, we calculate the Z2 invariant of the three-dimensional topological insulator Bi2Se3 [92].

SCF calculation
Using Bi2Se3-Z2.dat stored in the directory work, set the following keyword and perform an SCF calculation.

    HS.fileout      on      #on|off, default=off

If the SCF calculation finishes normally, the output file Bi2Se3-Z2.scfout is generated.

Calculation of the Z2 invariant
Before calculating the Z2 invariant using the post-process code Z2FH, compile the code in the directory work as follows.

    % make Z2FH

After compilation, the executable Z2FH is generated in the directory work. Then proceed to the calculation of the Z2 invariant as follows.

   % ./Z2FH Bi2Se3-Z2.scfout
 or
   % ./Z2FH Bi2Se3-Z2.scfout < Z2FH.in > Z2FH.out
 or
   % mpirun -np 4 ./Z2FH Bi2Se3-Z2.scfout < Z2FH.in > Z2FH.out

The file Z2FH.in contains the parameters required for the Z2FH calculation as follows.

   5
   1
   1

In the first execution example above, the program asks interactively as follows.

Parameters of Z2FH
The parameters in the input file Z2FH.in are explained below.

  • •

    In the first line, specify the number of meshes on half of the integration region. In other words, this corresponds to one quarter of the first Brillouin zone (see Fig. 88). If 5 is specified, the code performs the integration on square plaquettes formed by a 5×5 k-point mesh within one quarter of the Brillouin zone.

  • •

    In the second line, specify whether the calculation of the Z2 invariant is carried out on all six k planes on which the Z2 invariants are defined. If you want to calculate only the four planes corresponding to (ν0,ν1,ν2,ν3), specify 0. On the other hand, if 1 is specified, the calculation is performed for all six planes corresponding to (x0,xπ,y0,yπ,z0,zπ).

  • •

    In the third line, specify the k plane from which the calculation is restarted. The integers 1, 2, 3, 4, 5, and 6 correspond to the planes k1=0, k1=𝐆12, k2=0, k2=𝐆22, k3=0, and k3=𝐆32, respectively.

Output files
After the calculation by the post-process code MulPCalc, the following files are generated.

  • •

    Z2.dat

    This file records the results of the Z2-invariant calculation. When all k planes are calculated (that is, when 1 is specified in the second line), the six Z2 invariants on the six k planes are listed in the first line, and the four Z2 invariants are listed in the second line, as follows.

      Z2 invariant:(x0,xpi,y0,ypi,z0,zpi)=(1.000000,-0.000000,1.000000,-0.000000,1.000000,-0.000000)
  Z2 invariant:(nu0,nu1,nu2,nu3):(1,0,0,0)
  • •

    LCNum*.dat

    Data files of the integer-valued field n⁢(𝐤). Here * before LCNum runs from 1 to 6. The numbers (1,2,3,4,5,6) correspond to (x0,xπ,y0,yπ,z0,zπ), respectively. When only four planes are calculated, four files, LCNum(2,4,5,6).dat, are generated, corresponding to (xπ,yπ,z0,zπ).

  • •

    LCNum*.pl

    Script files for Gnuplot. Here * before LCNum runs from 1 to 6. The numbers (1,2,3,4,5,6) correspond to (x0,xπ,y0,yπ,z0,zπ), respectively. When only four planes are calculated, four files, LCNum(2,4,5,6).pl, are generated, corresponding to (xπ,yπ,z0,zπ). The integer-valued field n⁢(𝐤) can be visualized as follows.

          % gnuplot LCNum1.pl
  • •

    temporal_12345.input

    This file is a copy of the input file. It was used for the SCF calculation and reconstructed from the scfout file.

As an example, the integer-valued field n⁢(𝐤) on the plane k1=0 is shown in Fig. 90. This can be obtained by the procedure explained above as gnuplot LCNum1.pl. Since n⁢(𝐤) is a gauge-dependent quantity, the result may differ depending on the computational environment. On the other hand, the Z2 invariant should be reproduced.
