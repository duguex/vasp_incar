13.2 Open-Core Pseudopotentials

The 4f electrons of lanthanoids are often spin-polarized, and the majority-spin states lie several eV below the Fermi energy in many cases. However, LDA and GGA cannot reproduce these features of the band structure. This problem can also be solved by calculations using the plus U method, in which an on-site Coulomb repulsion is introduced for the 4f electrons, but in OpenMX, as a simpler method, open-core pseudopotentials incorporating the spin polarization of the 4f electrons are available (however, in the 2019 database, only some atoms are supported). In open-core pseudopotentials for lanthanoids, the 4f electrons are treated as part of the core states. The partial core correction charge is also generated so as to reproduce well the charge distribution of the 4f electrons treated as core states. Nd_CA19_OC.vps and Nd_PBE19_OC.vps included in the 2019 database were generated by this method.

Figure 5 shows the calculation results for NdCo5 with the CaCu5-type structure using the open-core pseudopotential. As can be seen, the use of the open-core pseudopotential yields qualitatively the same results as those obtained using the LDA+U method.

When using an open-core pseudopotential in OpenMX, the partial core correction charge can be spin-polarized by the following keyword.

  <scf.pcc.opencore
    Nd  1
    Co  0
  scf.pcc.opencore>

This is an example for NdCo5, where the first column gives the atomic species name defined by the keyword Definition.of.Atomic.Species, and the second column is a flag specifying the spin direction. The partial core correction charge is spin-polarized upward along the z axis when 1 is specified, and downward when -1 is specified. If no spin polarization is desired, specify 0. By using this keyword, it is possible to control the spin direction of the open-shell state of the 4f electrons for each site. Open-core pseudopotentials are effective when the 4f orbitals do not overlap between neighboring atoms. In addition, if the occupation state of the 4f electrons in a compound differs greatly from that assumed when the pseudopotential was generated, the application of the open-core pseudopotential is not justified.
