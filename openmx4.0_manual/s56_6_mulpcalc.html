56.6 MulPCalc: Atomically Decomposed Momentum-Space Spin Density Matrix

MulPCalc extracts data for analyzing the Mulliken density from the AtomMulP file, MulP_xx file, AMulPBand file, or AMulPBand_xx file generated by kSpin. First, compile it in the directory work to generate the executable.

    % make MulPCalc

If the compilation is successful, the executable kSpin is generated in the directory work. First, perform an OpenMX calculation using the input file SiC_Primitive_BD.dat stored in the directory work. After the SCF calculation, set the following keywords and run a BandDispersion calculation using the post-process code kSpin. 

    Filename.scfout    sic_primitive.scfout # default: default
    Filename.outdata   sic_primitive_BD     # default: default
    Calc.Type          BandDispersion       # default: MulPOnly
    Energy.Range       -10.0  6.0           # eV; default: 0.0  0.0

Next, run MulPCalc as follows.

    % ./MulPCalc SiC_Primitive_BD.dat

To extract the data of the pz orbital of the carbon atom, use the following settings. 

    Filename.atomMulP sic_primitive_BD.AMulPBand_p3 # default: default
    Filename.xyzdata   sic_primitive_BD_MC_C_p3     # default: default
    Num.of.Extract.Atom        1                 # default: 1
    Extract.Atom               1                 # default: 1 2 ... (Num.of.Extract.Atom)

In addition, the appearance of the figure can be adjusted by setting the following keywords. 

    MulP.Vec.Scale       0.1  0.1  0.1           # default: 1.0  1.0  1.0
    Data.Reduction             2                 # default: 1

Figure 82 can be obtained by running MulPCalc several times in the same way, and plotting the 11th, 4th, and 5th columns of the resulting MulPop files by using the circle style of gnuplot.


Another input-file example, Au111Surface23_FL.dat, is stored in the directory work. This is for a calculation of a slab model of a clean Au(111) surface. Note that this calculation requires more computational time than the other examples. The SCF calculation followed by the FermiLoop calculation yields the band dispersion and the spin texture. The calculated results are shown in Figs. 83(a) and 83(b). Here, two sets of Rashba bands appear because the surface states on the upper and lower surfaces of the slab model are degenerate. Using MulPCalc, it is possible to analyze only the contribution from the surface atoms on one side. The contribution of the spin texture from one surface is shown in Fig. 83(c). This result was obtained by using the functionality of MulPCalc.


The specifications of the keywords are explained below.

List of keywords related to MulPCalc (common to all Calc.Type values)

Filename.atomMulP
Specifies the name of the AtomMulP file, MulP_xx file, AMulPBand file, or AMulPBand_xx file.

Filename.xyzdata
Specifies the name of the output files. This corresponds to the keyword System.Name.

Num.of.Extract.Atom
Specifies the number of atoms for which Mulliken-density data are to be extracted by MulPCalc. The default value is 1.

Extract.Atom
Specifies the atoms for which Mulliken-density data are to be extracted by MulPCalc. The default value is 1 2 ... up to the value of the keyword Num.of.Extract.Atom.

Data.Reduction
Specifies the number of k points in the Mulliken-density data to be extracted by MulPCalc. This keyword is useful for thinning out k points or reducing the data size.

MulP.Vec.Scale
Specifies the scale of the vectors used to draw the spin texture. For example, the value 0.1 0.2 0.3 specifies scales of 0.1, 0.2, and 0.3 along the x, y, and z axes, respectively.

Filename.outdata
Use the same setting as in the kSpin calculation.

Calc.Type
Use the same setting as in the kSpin calculation.

List of keywords related to MulPCalc (Calc.Type = FermiLoop or GridCalc)

Search.kCentral
Use the same setting as in the kSpin calculation.

Calc.Type.3mesh
Use the same setting as in the kSpin calculation.

Energy.Range
Use the same setting as in the kSpin calculation.

List of keywords related to MulPCalc (Calc.Type = BandDispersion)

Energy.Range
Use the same setting as in the kSpin calculation.

Band.Nkpath
Use the same setting as in the kSpin calculation.

Band.kpath
Use the same setting as in the kSpin calculation.

List of keywords related to MulPCalc (Calc.Type = MulPOnly)

Calc.Type.3mesh
Specifies the plane to be calculated. The values 1, 2, and 3 correspond to the ka⁢kb, kb⁢kc, and kc⁢ka planes, respectively. The default value is 1.

Output files

If the calculation by MulPCalc completes normally, the following output files are generated in the working directory.

MulPop file
This file records the data at each k point. The first, second, and third columns correspond to the kx, ky, and kz components of the k point, in units of Å-1. The fourth column corresponds to the energy in eV, and the fifth, sixth, and seventh columns correspond to the total number of electrons, the number of α-spin electrons, and the number of β-spin electrons, respectively. The eighth, ninth, and tenth columns correspond to the expectation values of σx, σy, and σz in units of the Bohr magneton, respectively. If the keyword Calc.Type is set to BandDispersion, the eleventh column corresponds to the distance along the k path in units of Bohr-1.

MulPop_YY file
This file records the data at each k point for band index YY. The format of this file is the same as that of the MulPop file.

plotexample file
When the value of the keyword Calc.Type is other than 'GridCalc', this file can be used as a gnuplot script.

plotexample_YY file
If the value of the keyword Calc.Type is GridCalc, this file can be used as a gnuplot script for the band with index YY.
