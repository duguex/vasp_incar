47.2.5 MLWF output files

The four files generated in an MLWF calculation are explained below. The file with extension .mmn stores the overlap matrix elements Mm⁢n(𝐤,𝐛). The file with extension .amn stores the projection matrix elements Am⁢n(𝐤) for the initial guess. The file with extension .eigen stores the eigenenergies and eigenstates at each k point. The file with extension .HWR stores the hopping integrals between MLWFs on a set of lattice vectors inside the Wigner-Seitz supercell conjugate to the sampled k grid. When restarting the optimization, the file with extension .mmn is read. More detailed information on these four files is given below.

A. Format of the .mmn file
The structure of this file follows strictly the file structure of Wannier90 [158]. The first line of the file is a description of the numbers in the second line. The numbers in the second line are, from left to right, the number of bands included in the outer energy window (Nw⁢i⁢n), the number of k points, the number of b vectors, and the number of spin components. Each subsequent block is a data block for Mm⁢n(𝐤,𝐛), written in loop form. The outermost loop is over spin components, then over k points, and then over b vectors. The innermost loops are over the band indices n and m. In each block, the first line consists of five numbers. The first two are the current k-point index and the index of the neighboring 𝐤+𝐛 point. The next three numbers are the coordinates of the unit-cell 𝐤+𝐛 point. From the second line of each block onward, the real and imaginary parts of the matrix elements are given. Each block contains Nw⁢i⁢n×Nw⁢i⁢n complex numbers. As an example, the .mmn file generated from the input file Si.dat is shown below.

B. Format of the .amn file
The structure of this file also follows strictly the file structure of Wannier90 [158]. The first line of the file is a description of the entire file. The four numbers in the second line are the number of bands in the outer energy window (Nw⁢i⁢n), the number of k points, the number of MLWFs to be generated, and the number of spin components. Again, the data blocks are written in loop form. The outermost loop is over spin components, followed by k points, the MLWF index, and the band number. For each block the first three integers are the band index, MLWF index, and k-point index, respectively. They are followed by the real and imaginary parts of the matrix element. C. Format of the .eigen file
This file stores the eigenenergies and eigenstates at each k point. The first line is the Fermi level of the system. The second line gives the number of bands. The following data mainly consist of two parts. The first part contains the eigenenergies, and the second part corresponds to the eigenstates. In each part, the outermost loop is over spin components. The next loop is over k points, followed by the band index. For eigenstates, there is one or more additional inner loops with respect to the basis set. As an example, the file generated from the input file Si.dat is shown below.

D. Format of the .HWR file
This file stores the hopping integrals between the mth MLWF |m,𝟎⟩ in the central unit cell (𝐑=0) and the nth MLWF |n,𝐑⟩ in the unit cell at 𝐑. According to the following rules, the matrix elements ⟨m,𝟎|H^|n,𝐑⟩ are written out. The first line is only an explanation. The second and third lines give the number of MLWFs and the number of lattice vectors in the Wigner-Seitz supercell, respectively. Lines 5, 6, and 7 give the unit-cell vectors. The 8th line describes whether the calculation is collinear or non-collinear and how spin polarization is treated. The 9th line is the Fermi level (Hartree). The data blocks start from the 10th line and are written in loop form. The outermost loop is over spin components. The next loop is over 𝐑, and the last two loops are over m and n. Each 𝐑 is written in the first line of each block together with its degeneracy. In each line, the indices m and n are shown, followed by the real and imaginary parts of the hopping integral (Hartree). As an example, the file generated from the input file Si.dat is shown below.
