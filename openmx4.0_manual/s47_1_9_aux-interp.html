47.1.9 Auxiliary programs for Wannier interpolation

The auxiliary programs analysis_cwf_col.c and analysis_cwf_noncol.c are provided for independently performing Wannier interpolation using the tight-binding Hamiltonian obtained from a CWF calculation. The former is an interface program for collinear calculations, and the latter for non-collinear calculations. Since these codes are written in a relatively straightforward manner, they can be used as a starting point when implementing one’s own code for calculating physical quantities based on Wannier interpolation.

analysis_cwf_col.c can, for example, be compiled as follows.

   $ make analysis_cwf_col

If the compilation finishes normally, the executable file analysis_cwf_col is generated. This program reads a *.CWF.Hop file output by a CWF calculation as input. For example, in the case of the GaAs crystal (GaAs-CWF1.dat), the tight-binding parameters are stored in binary form in GaAs-CWF1.CWF.Hop.

   $ ./analysis_cwf_col GaAs-CWF1.CWF.Hop

By default, this program diagonalizes the Hamiltonian at one k point and outputs the eigenvalues. Thus, it is best understood first as the minimal example that reads in the tight-binding Hamiltonian stored in *.CWF.Hop and obtains Wannier-interpolated band eigenvalues. By referring to these auxiliary programs, one can understand how to read the information stored in *.CWF.Hop, how to construct the Hamiltonian in k space, and how to solve the eigenvalue problem. Therefore, it is possible to develop them further into codes that evaluate not only band dispersions but also other physical quantities based on Wannier interpolation. In addition, since the data structure and matrix handling differ between collinear and non-collinear calculations, please use either analysis_cwf_col.c or analysis_cwf_noncol.c according to the type of calculation of interest.
