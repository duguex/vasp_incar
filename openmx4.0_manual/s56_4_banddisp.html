56.4 BandDispersion: Calculation of Band Dispersion

The post-process code kSpin provides four methods for calculating the momentum-space spin density matrix. This is specified by the keyword Calc.Type. Here we explain BandDispersion among the four methods. Using the functionality of BandDispersion, the momentum-space spin density matrix decomposed into individual atoms can be calculated on a band-dispersion path within a user-specified energy range. As an example of spin-texture analysis using BandDispersion, we describe here a model of the Au(111) surface. First, perform an OpenMX calculation using the input file Au111Surface_BD.dat stored in the directory work. Next, the spin texture can be analyzed by using the functionality of MulPCalc (Sec. 56.6). The keywords relevant to the execution of kSpin are listed below. These keywords are written in the input file Au111Surface_BD.dat. The input file Au111Surface_BD.dat is stored in the directory work.

List of keywords related to kSpin 

    Filename.scfout      Au111Surface.scfout
    Filename.outdata     Au111Surface_BD
    Calc.Type            BandDispersion    # FermiLoop, GridCalc,
                                             BandDispersion, or MulPOnly
                                             default: MulPOnly
    Energy.Range        -1.0  1.0          # eV; default: 0.0  0.0
    Band.Nkpath                2
    <Band.kpath
      135  0.0  0.500000  0.000000    0.0   0.000000  0.000000     M  G
      135  0.0  0.000000  0.000000    0.0  -0.500000  0.000000     G -M
    Band.kpath>

Specifications of the keywords

The specifications of the keywords are explained below.

Filename.scfout
Specifies the name of the scfout file to be read by kSpin.

Filename.outdata
Specifies the name of the output files. This keyword corresponds to the OpenMX keyword System.Name.

Calc.Type
Choose one of FermiLoop, GridCalc, BandDispersion, or MulPOnly. The default setting is MulPOnly. Here we choose BandDispersion.

Energy.Range
Specifies the energy range used to search for the bands to be analyzed. The unit is eV. The default value is -0.5 0.5. That is, the lower energy limit is -0.5 (eV), and the upper energy limit is 0.5 (eV).

Band.Nkpath
Specifies the number of k-point paths used to calculate the band dispersion. The notation is the same as in a standard OpenMX calculation.

Band.kpath
Specifies the k-point paths used to calculate the band dispersion. The notation is the same as in a standard OpenMX calculation.

Calculation

The atomically decomposed momentum-space spin density matrix is calculated by the post-process code kSpin. Here we assume that the post-process code kSpin is located in the directory work. Move to the directory work and run the calculation as follows.

    % ./kSpin Au111Surface_BD.dat

Alternatively, for an MPI calculation, for example with 4 MPI processes, run as follows.

    % mpirun -np 4 ./kSpin Au111Surface_BD.dat

Output files

The contents of the output files are explained below.

BAND file
This file records the band-dispersion data. The first and second columns correspond to the distance between k points along the path (in Bohr-1) and the eigenenergy (in eV), respectively.

Band_YY_Z file
This file records the band-dispersion data for each branch (band index YY, k-path index Z). The format of this file is the same as that of the BAND file.

AMulPBand file
This file records the data of the momentum-space spin density matrix decomposed into individual atoms. It can be analyzed by MulPCalc (Sec. 56.6).

AMulPBand_xx file
This file records the data of the x⁢x component of the momentum-space spin density matrix decomposed into individual atoms. It can be analyzed by MulPCalc (Sec. 56.6).

plotexample file
This file provides an example gnuplot script.

atominfo file
This file provides information on the lattice vectors and the PAOs.

temporal_12345.input
This file is a copy of the input file recorded in the scfout file.

(Optional) Analysis of the atomically decomposed momentum-space spin density matrix

Using MulPCalc, data for analyzing the atomically decomposed momentum-space spin density matrix can be extracted from the AtomMulP file or the AMulPBand_xx file. Compile it in the directory work as follows to generate the executable.

    % make MulPCalc

If the compilation is successful, the executable MulPCalc is generated in the directory work. As an example, we focus on the band dispersion of the Rashba spin splitting on the Au(111) surface and analyze the momentum-space spin density matrix decomposed into atomic contributions. First, add the following keywords to the input file Au111Surface_BD.dat. 

    Filename.atomMulP Au111Surface_BD.AMulPBand # default: default
    Filename.xyzdata   Au111Surface_BD_MC       # default: default
    Num.of.Extract.Atom        3                # default: 1
    Extract.Atom               1 2 3            # default: 1 2 ... (Num.of.Extract.Atom)

After the calculation by the post-process code MulPCalc, the momentum-space spin density matrix decomposed into atomic contributions can be analyzed as follows.

    % ./MulPCalc Au111Surface_BD.dat

In addition, the appearance of the figure can be adjusted by setting the following keywords. 

    MulP.Vec.Scale       0.1  0.1  0.1          # default: 1.0  1.0  1.0
    Data.Reduction             1                # default: 1

After running MulPCalc, the following output files are obtained in the directory work.

    Au111Surface_BD_MC.MulPop
    Au111Surface_BD_MC.MulPop49
    Au111Surface_BD_MC.MulPop50
    Au111Surface_BD_MC.MulPop51
    Au111Surface_BD_MC.MulPop52
    Au111Surface_BD_MC.MulPop53
    Au111Surface_BD_MC.MulPop54
    Au111Surface_BD_MC.MulPop55
    Au111Surface_BD_MC.MulPop56
    Au111Surface_BD_MC.plotexample

As an example, by running the following command, Fig. 80(b) is obtained. This displays the information of the momentum-space spin density matrix decomposed into atomic contributions, overlaid on the Rashba spin-split bands of the Au(111) surface.

    % gnuplot Au111Surface_BD_MC.plotexample

For further information on MulPCalc, see also Sec. 56.6.
