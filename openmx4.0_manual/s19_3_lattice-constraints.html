19.3 Constraints on Lattice Vectors

When OptC1, OptC2, OptC5, or RFC5 is specified by the MD.Type keyword, it is possible to fix the Cartesian components of the lattice vectors at their initial values as follows. The keyword to be set is as follows.

    <MD.Fixed.Cell.Vectors
     0 0 1
     0 0 0
     0 0 0
    MD.Fixed.Cell.Vectors>

The flags in the first row correspond to ax, ay, and az; those in the second row to bx, by, and bz; and those in the third row to cx, cy, and cz. If the value is 1, the corresponding component is fixed, and if it is 0, it is variable. By combining RFC5 with MD.Fixed.Cell.Vectors, it is possible to impose the same constraint conditions as RFC6 and RFC7. Since arbitrary constraint conditions can be imposed, the use of the combination of RFC5 and MD.Fixed.Cell.Vectors is recommended.
