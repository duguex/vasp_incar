35.2 Voronoi charges

The Voronoi charge of each atom is calculated by integrating the electron density within the Voronoi polyhedron. In OpenMX, the Voronoi polyhedron is constructed from a continuously smeared boundary based on the fuzzy-cell partitioning method [75]. Since the Voronoi polyhedron is determined solely by the structure without considering atomic radii, it should be noted that Voronoi analysis often yields charges that are overestimated or underestimated. To calculate Voronoi charges, set the following keyword Voronoi.charge in the input file.

     Voronoi.charge      on       # on|off, default = off

For a methane molecule, the following Voronoi charges are output to System.Name.out.

***********************************************************

  Sum of Voronoi charges for down  =  4.000008070409

       Atom=   1   1.089297306  1.089297306   2.178594612   0.000000000   2.352820099
       Atom=   2   0.727677691  0.727677691   1.455355382   0.000000000  39.598893040
       Atom=   3   0.727677691  0.727677691   1.455355382   0.000000000  39.598893040
       Atom=   4   0.727677691  0.727677691   1.455355382   0.000000000  39.598893040

The carbon atom (Atom=1) is positively charged, whereas the hydrogen atoms (Atom=2–5) are negatively charged, and this result is not consistent with chemical intuition. Nevertheless, Voronoi analysis provides useful information for bulk solids with dense packing, and the Voronoi volume is also useful for analyzing the local structure in bulk systems.
