63.2 Interface with BoltzTraP2

OpenMX Ver. 4.0 provides an interface [112] to BoltzTraP2 [110, 111]. BoltzTraP2 is a program for calculating electronic transport coefficients within the semiclassical Boltzmann transport theory based on the k-dependence of the energy eigenvalues of the Kohn-Sham equation. This functionality supports non-spin-polarized, collinear spin-polarized, and non-collinear calculations. When publishing results obtained using this functionality, we would appreciate it if you cite Ref. [112].

First, install BoltzTraP2. An example is shown below.

  % conda create --name boltztrap2 -c conda-forge
  % conda activate boltztrap2
  % conda install -c conda-forge boltztrap2
  % pip install pyfftw
  % pip install vtk
  % conda info --envs

Use the last command, conda info --envs, to identify the directory of the environment where BoltzTraP2 has been installed. In the following, this directory is denoted by PATH_BTP2.

To allow BoltzTraP2 to read OpenMX output files directly, it is necessary to introduce an OpenMX loader. Copy dft_forOpenMXloader.py and io_forOpenMXloader.py to

  PATH_BTP2/lib/python3.11/site-packages/BoltzTraP2

Here, the python3.11 part may change depending on the Python version. Also, the python scripts can be found in the directory work.

  % cp dft_forOpenMXloader.py io_forOpenMXloader.py \
      PATH_BTP2/lib/python3.11/site-packages/BoltzTraP2
  % cd PATH_BTP2/lib/python3.11/site-packages/BoltzTraP2

Then, replace the existing dft.py and io.py included in BoltzTraP2. If you would like to keep the original files, for example, back them up and then replace them as follows.

  % cp dft.py dft.py.orig
  % cp io.py  io.py.orig
  % cp dft_forOpenMXloader.py dft.py
  % cp io_forOpenMXloader.py  io.py

In environments using NumPy 2.x, an error may occur due to np.infty in io.py. In that case, replace it with np.inf as follows.

  % sed -i ’s/np\.infty/np.inf/g’ io.py

In this OpenMX loader, in order to avoid conflicts with other loaders, the input file extensions are .MXenergy and .MXstructure instead of .energy and .structure.

As an example, let us consider undoped diamond-structure Si. For the calculation, the input file Si_BoltzTraP.dat in the directory work is used. First, perform the SCF calculation as usual.

  % mpirun -np 28 ./openmx Si_BoltzTraP

When the calculation finishes normally, the output file Si_BoltzTraP.out is obtained. Next, copy the conversion script MX_TRAP2.sh included in the work directory to the working directory, and execute it as follows.

  % bash MX_TRAP2.sh

When executed, a list of *.out files in the current directory is displayed, and you are prompted to enter the name of the out file to be analyzed. In this example, enter

  Please enter the outputfile name ; Outputfile name = Si_BoltzTraP.out

as shown above. If the conversion is completed normally, a directory named Si_BoltzTraP is created, and at least the following three files are stored in it.

  Si_BoltzTraP.MXenergy
  Si_BoltzTraP.MXstructure
  Si_BoltzTraP.out

Si_BoltzTraP.out is a backup of the original OpenMX output file. Si_BoltzTraP.MXstructure stores the lattice vectors of the unit cell and the atomic coordinates, while Si_BoltzTraP.MXenergy stores the eigenvalues on irreducible k points, the chemical potential, and other information required by BoltzTraP2.

Next, perform the Fourier interpolation in the working directory. For example, if the Fourier interpolation factor is set to 25, execute the following command.

  % PATH_BTP2/bin/btp2 interpolate -m 25 Si_BoltzTraP

Here, -m is the option for specifying the Fourier interpolation factor. In the above example, -m 25 sets the interpolation factor to 25. If the calculation finishes normally, interpolation.bt2 is generated. If necessary, it is convenient to rename the file as follows.

  % cp interpolation.bt2 Si_BoltzTraP.bt2

Next, perform the integration for the transport coefficients. An example for calculating the transport coefficients at 300 K within the constant relaxation-time approximation is shown below.

  % PATH_BTP2/bin/btp2 integrate -t Si_BoltzTraP.bt2 300

Here, -t indicates that the calculation is carried out within the constant relaxation-time approximation. The final 300 denotes the temperature in Kelvin. In addition to the constant relaxation-time approximation, BoltzTraP2 also supports the constant mean free path approximation. For details, refer to the BoltzTraP2 manual [111].

When btp2 integrate finishes normally, for example, the following files are output in the execution directory.

  Si_BoltzTraP.trace
  Si_BoltzTraP.condtens
  Si_BoltzTraP.halltens
  Si_BoltzTraP.btj

The meanings of these files are as follows.

  • •

    Si_BoltzTraP.trace: averages of the x⁢x, y⁢y, and z⁢z components of the transport properties

  • •

    Si_BoltzTraP.condtens: electrical conductivity tensor

  • •

    Si_BoltzTraP.halltens: Hall conductivity tensor

  • •

    Si_BoltzTraP.btj: auxiliary file used when plotting transport properties with the btp2 module

In the BoltzTraP version, the interpolation factor and temperature conditions were specified through the .intrans file, whereas in the BoltzTraP2 version they are mainly specified by the command-line arguments of btp2 interpolate and btp2 integrate.

Figure 101 shows the benchmark calculation for undoped diamond-structure Si. The figure shows the chemical-potential dependence of the Seebeck coefficient S and the electrical conductivity σ⁢τel−1 at 300 K. The Fourier interpolation factor was set to 25, and the calculation was carried out within the constant relaxation-time approximation. Here, μ=0 eV is aligned to the OpenMX chemical potential at 300 K. The input file used in the calculation is Si_BoltzTraP.dat stored in the work directory.

As described above, the SCF results of OpenMX can be connected to the transport-coefficient calculation by BoltzTraP2 in a small number of steps. Since the results depend on the choice of the Fourier interpolation factor, temperature, and approximation, appropriate conditions should be selected for practical applications while carefully checking the convergence.
