12.5 Placement of empty atoms

Primitive functions and optimized PAO functions are usually assigned to atoms. In addition, it is possible to assign basis functions to vacant regions by using empty atoms. The database website (http://www.openmx-square.org/) includes an entry for the empty atom E. The pseudopotential of the empty atom E is a flat zero potential, and by using this pseudopotential for the empty atom E, basis functions can be placed at any position in space independently of atomic positions. To do so, empty atoms are defined as follows.

   <Definition.of.Atomic.Species
     H    H5.0-s2p1      H_PBE19
     C    C5.0-s2p1      C_PBE19
     EH   H5.0-s2p1      E
     EC   C5.0-s2p1      E
   Definition.of.Atomic.Species>

In this example, two kinds of empty atoms are defined as EH and EC, and the basis functions specified by H5.0-s2p1 and C5.0-s2p1 are assigned to them, respectively. Therefore, arbitrary basis functions can be used for empty atoms, and the definition of empty atoms can also be made simply by using E.vps as the pseudopotential for empty atoms. Then, EH and EC can be placed at arbitrary positions by the keyword Atoms.SpeciesAndCoordinates, where the pseudopotential for the empty atom is zero, and the number of electrons supplied from the empty atom to the system is also zero. By placing empty atoms, not only can the basis set superposition error be estimated by using the counterpoise method (CP method) [49, 50], but also vacancy states and free-electron-like states on metal surfaces can be treated within the framework of the linear combination of pseudo-atomic orbitals (LCPAO) method. As an example, the calculation of the F center in NaCl with a Cl vacancy is shown in Fig. 4. It can be seen that the highest occupied state at the Γ point is the state of this F center. This calculation can be reproduced using NaCl_FC.dat in the work directory.
