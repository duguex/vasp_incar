17.1 Restarting SCF calculations

When calculating the density of states, band dispersion, molecular orbitals, and so on, it is possible to save computational time by performing a self-consistent calculation in advance and then skipping the self-consistent calculation in the second and subsequent runs. The keyword prepared for restarting such a calculation is scf.restart.

   scf.restart           on        # on|off|pp|c2n, default=off

If the keyword scf.restart is set to on, the restart files created in the first calculation are read and used as the initial Hamiltonian and the initial (spin) electron density in the second calculation. Here, System.Name in the second calculation must be the same as that in the first calculation. The restart files are stored in the directory System.Name_rst under the directory work. Here, System.Name means System.Name. The restart files in System.Name_rst contain all the information related to both the density-matrix mixing method and the Fourier-space mixing method. Therefore, it is also possible to use a different mixing method in the second calculation. As an example of restarting, the SCF convergence process is shown in Fig.9. This calculation was performed using the input file C60.dat in the directory work. From Fig.9, it can be seen that, in the second calculation, the SCF calculation terminates immediately owing to the use of the restart files.

If scf.restart is set to on, the restart Hamiltonian and electron-density files are read, and the SCF calculation starts. The calculation then ends when the convergence criterion is satisfied. In this case, the restart Hamiltonian and electron-density files are overwritten. On the other hand, there are cases where, after reading the restart Hamiltonian and electron-density files, one would like to perform only a single diagonalization and then carry out post-processing calculations such as the density of states and band calculations. In addition, one may wish to keep the restart Hamiltonian and electron-density files without updating them. In such a case, please use the following keyword setting.

   scf.restart           pp        # on|off|pp|c2n, default=off

pp means post processing. Specifying this tag automatically sets scf.maxIter=1 and MD.Type=nomd. Furthermore, the Hamiltonian and electron-density files for restart are not updated.

In addition, scf.restart also provides the option c2n. This option is used to convert and read restart files generated by a collinear DFT calculation for use in a noncollinear DFT calculation. In particular, this function is used in the evaluation of the magnetic anisotropy energy (MAE) by the second-variational method, as explained in Section 42, “Second-variational method: Magnetic Anisotropy Energy (MAE)”. In the second-variational method, one first obtains the SCF electron density by a collinear DFT calculation without spin-orbit interaction (SOI), and then, using the restart files, performs only a single diagonalization including SOI within the framework of noncollinear DFT. In this case, the restart files to be read are specified by the keyword scf.restart.filename.

   scf.restart.filename  FePt
   scf.restart           c2n       # on|off|pp|c2n, default=off

Here, scf.restart = c2n converts the restart files generated by the collinear calculation for use in the noncollinear calculation. Since this method is based on the Harris functional [14], if the input electron density is sufficiently good, energy differences can be evaluated with high accuracy by only a single diagonalization. However, in the evaluation of MAE, one should pay attention not to the total energy Utot in the output but to the band energy Uele, and, in the second-stage noncollinear calculation, it is important to carefully confirm the convergence of Uele by using a low electronic temperature and a sufficiently dense set of k points. In addition, this MAE evaluation by the second-variational method is applicable to ferromagnetic systems. For the detailed theoretical background, specific input examples, and the interpretation of Uele and Utot, please refer to Section 42.
