12.1 Basis-function overview

OpenMX uses numerical pseudo-atomic orbitals (PAOs) χ as basis functions to expand one-particle Kohn-Sham wave functions. The PAO function is given by the following equation as the product of the radial function R and the real spherical harmonic Y.

χ⁢(𝐫)=R⁢(r)⁢Y⁢(𝐫^),

The radial function R is given in the form of a numerical table and is finite within the cutoff radius in real space. In other words, the function R becomes zero beyond the specified cutoff radius. The PAO functions calculated by ADPACK are called primitive functions. Starting from these primitive PAO functions, it is possible to obtain optimized PAO functions by using the orbital optimization scheme implemented in OpenMX [44]. The data for these basis functions are stored in files with the extension pao. When an OpenMX calculation is executed, the numerical data stored in these files are read in. The value of a PAO function at an arbitrary radial distance r is obtained by interpolation. Files with the extension pao should be stored, for example, in a directory such as DFT_DATA19/PAO. This directory is specified by the following keyword. However, it is not necessary that the directory name contain PAO.

    DATA.PATH   ../DFT_DATA19    # default=../DFT_DATA19

Both absolute and relative paths can be specified, and the default is ../DFT_DATA19. In an OpenMX input file, basis functions are specified by the keyword Definition.of.Atomic.Species as follows.

   <Definition.of.Atomic.Species
     H   H5.0-s2p1      H_PBE19
     C   C5.0-s2p1      C_PBE19
   Definition.of.Atomic.Species>

Here, we introduce the abbreviated notation for the basis function, H5.0-s2p1. H5.0 denotes the filename of the PAO function without the extension. This file must exist in a directory such as DFT_DATA19/PAO specified by the keyword DATA.PATH. 5.0 indicates the cutoff radius of the PAO function. In addition, s2p1 means that in the specified file, two radial functions and one radial function are assigned to the s orbital and the p orbital, respectively. In this case, a total of five PAO basis functions (2×1+1×3=5) are assigned to H.

On the OpenMX website (http://www.openmx-square.org/), the database Ver. 2019 of optimized basis functions is publicly available free of charge. Therefore, general users are recommended to use these optimized basis functions. However, for advanced users, the primitive and optimized PAO functions are explained in the following sections.
