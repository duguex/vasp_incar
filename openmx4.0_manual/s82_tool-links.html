82 Links to Other Tools

This section summarizes links to other tools.

  • •

    Trial use

    If you would like to try OpenMX quickly, you can use the following tool.

    • –

      MateriApps LIVE!:
      https://cmsi.github.io/MateriAppsLive/

      MateriApps LIVE! is an environment in which computational materials science applications can be tested using your own laptop PC or similar devices. OpenMX is one of the applications included in MateriApps LIVE!, and it can be used as a trial environment through the VirtualBox version, Docker version, and so on.

  • •

    Physical property analysis using Wannier functions

    By using closest Wannier functions or maximally localized Wannier functions, various physical properties can be calculated efficiently and accurately. OpenMX provides an interface to the post-processing code Wannier90.

    • –

      Wannier90: https://wannier.org/

      In Wannier90, Wannier functions can be constructed from the results of first-principles SCF calculations, and calculations of Wannier-projected DOS and band structures, Fermi surfaces, Berry-phase-related properties (anomalous Hall conductivity, optical conductivity, orbital magnetization), and thermoelectric properties are possible. For details, see Sections 47.1.10 and 47.2.7.

  • •

    Phonon-related properties

      ALAMODE: https://alamode.readthedocs.io/en/latest/tutorial.html
