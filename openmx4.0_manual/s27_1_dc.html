27.1 Divide-conquer method (DC method)

The DC method is numerically stable, applicable to a wide range of materials, and allows one to control computational accuracy and efficiency with ease. This method is particularly suitable for covalent materials. In this subsection, we explain O(N) calculations using the DC method. In the input file DIA8_DC.dat in the directory work, please specify DC for the keyword scf.EigenvalueSolver.

     scf.EigenvalueSolver   DC

Run OpenMX in the usual way using the input file DIA8_DC.dat.

    % ./openmx DIA8_DC.dat

This input file is for a DC calculation of diamond containing 8 carbon atoms. Geometry optimization is not performed. The elapsed time is about 120 seconds when a Xeon processor (2.6 GHz) is used. Figure 22 shows the computational time and memory usage for diamond carbon calculated by the divide-conquer method as a function of the number of carbon atoms in the supercell. The computational time denotes the elapsed time for diagonalization in one SCF step, while the memory usage is shown per MPI process. It can be seen from the figure that both the computational time and the memory usage are nearly proportional to the number of atoms. The computational accuracy and efficiency of the DC method are controlled by the keyword orderN.HoppingRanges.

  • •

    orderN.HoppingRanges

    The radius (Å) of a sphere centered on each atom is defined by the keyword orderN.HoppingRanges. In the DC method, the DC-LNO method, and the O(N) Krylov subspace method, a truncated cluster is constructed by selecting atoms included within this sphere.

Let the number of atoms in the system be N. Then N clusters are constructed by physically truncating the system with spheres whose radii are specified by orderN.HoppingRanges. For each cluster, the eigenvalue problem is solved independently, and the projected density of states on the central atom is calculated. The total density of states of the whole system is then obtained by summing the projected densities of states from all atoms. Although the appropriate value of orderN.HoppingRanges depends on the system, the following range is recommended for molecular systems as a compromise between computational accuracy and efficiency.

     orderN.HoppingRanges     6.0 - 7.0    # in Ang.

Table 5 compares the total energies calculated by the conventional diagonalization method and the DC method for a C60 molecule, a small peptide molecule (valorphin) [118], and DNA composed of cytosine and guanine. It can be seen that the error in the total energy calculated by the DC method is on the order of milli-Hartree per atom for all the systems. Under the computational conditions used here, the DC method is expected to become faster than the conventional diagonalization method when the number of atoms exceeds about 500, although the crossover point in computational time between the conventional diagonalization method and the DC method depends on the system and on the number of cores used in parallel calculations.


To examine the dependence of the total-energy accuracy on the size of truncated clusters, the error in the total energy relative to the conventional diagonalization method is shown in Fig. 23. Here, the number of atoms in the truncated cluster is taken as a parameter for three cases: (a) gapped solids, (b) metals, and (c) molecules. What can be seen is that the error decreases almost exponentially for (a) gapped solids and (c) molecular systems, whereas the convergence is relatively slow for (b) metals.
