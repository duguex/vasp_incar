35.4 CWF charge analysis

The analysis based on closest Wannier functions (CWFs) is one of the four charge-analysis methods introduced in this section. For detailed execution procedures and input settings of the CWF method, see Sec. 47.1.8. Since the occupation numbers of CWFs localized on each atom are written to the output file, the CWF method can be used, like Mulliken charges, to estimate atomic charges and spins [133]. The output file GaAs-CWF1.out produced by the calculation using GaAs-CWF1.dat, discussed in Sec. 47.1.1, contains the following information.

The evaluation of effective charges based on CWFs can be used complementarily together with Mulliken charges, Voronoi charges, ESP fitting charges, or other analysis methods such as Bader charges. For details of the physical background and execution conditions specific to the CWF method, see Sec. 47.1.8.
