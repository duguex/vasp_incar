60.2 Gaseous Systems

In the following, the calculation procedure for the absolute binding energy of a core level is explained through concrete examples.

First, let us calculate the binding energy of the 1s state of a carbon atom in a C2H2 molecule.

The calculation of the initial state is performed as follows.

   % mpirun -np 4 ./openmx C2H2.dat

Here, the input file C2H2.dat is located in the directory work. In the initial-state calculation, the following keywords need to be specified. 

    scf.coulomb.cutoff          on       # default = off
    scf.SpinPolarization        on or nc # default = off

If scf.coulomb.cutoff=on is specified, the classical Coulomb interaction between supercells is cut off along all three directions, namely the a, b, and c axes, by using the exact Coulomb cutoff method [101]. In both the initial-state and final-state calculations, on or nc must be specified for the keyword scf.SpinPolarization. Since the system becomes spin-polarized after the creation of a core hole in the final-state calculation, please use the same option in both the initial-state and final-state calculations. To calculate the absolute binding energy of a core level, use a pseudopotential that contains the core state. In the input file C2H2.dat, the following pseudopotentials are specified. 

    <Definition.of.Atomic.Species
      H   H7.0-s3p2           H_PBE19
      C   C7.0_1s-s4p3d2      C_PBE19_1s
      C1  C7.0_1s_CH-s4p3d2   C_PBE19_1s
    Definition.of.Atomic.Species>

The pseudopotential C_PBE19_1s.vps contains the 1s, 2s, and 2p states as valence states. The basis sets C7.0_1s.pao and C7.0_1s_CH.pao are used for the initial-state and final-state calculations, respectively. In the final-state calculation, the radial wavefunction is substantially deformed by the core hole compared with the case without a core hole. To obtain a converged result, it is necessary to use a basis set optimized for the state with a core hole. The pseudopotentials and basis sets for the final-state calculation are available at the following website.

https://www.openmx-square.org/vps_pao_core2019/

At present, data for 21 elements, Li, Be, B, C, N, O, Al, Si, P, S, Fe, Ga, Ge, As, Se, Br, Mo, Pd, W, Ir, and Pt, are available on this website. Pseudopotentials and basis-function sets for other elements will be released in the near future.

In the initial-state calculation, the geometric structure is specified as follows.

   Atoms.Number         4
   Atoms.SpeciesAndCoordinates.Unit   Ang # Ang|AU
   <Atoms.SpeciesAndCoordinates           # Unit=Ang.
     1  C   0.6005  0.000  0.000  3.0 3.0
     2  C  -0.6005  0.000  0.000  3.0 3.0
     3  H   1.8015  0.000  0.000  0.5 0.5
     4  H  -1.8015  0.000  0.000  0.5 0.5
   Atoms.SpeciesAndCoordinates>

The atomic species of atom 1 is C, and for this atom the basis set C7.0_1s.pao is assigned in the initial state. In the final-state calculation explained next, a core hole in the 1s state will be created on atom 1.

The final-state calculation is performed as follows.

   % mpirun -np 4 ./openmx C2H2-CH.dat

The input file C2H2-CH.dat is located in the directory work. In the final-state calculation, the geometric structure is specified as follows.

   Atoms.Number         4
   Atoms.SpeciesAndCoordinates.Unit   Ang # Ang|AU
   <Atoms.SpeciesAndCoordinates           # Unit=Ang.
     1  C1  0.6005  0.000  0.000  3.0 3.0
     2  C  -0.6005  0.000  0.000  3.0 3.0
     3  H   1.8015  0.000  0.000  0.5 0.5
     4  H  -1.8015  0.000  0.000  0.5 0.5
   Atoms.SpeciesAndCoordinates>

The atomic positions are exactly the same as those in the initial-state calculation. This means that atomic relaxation in the excitation process is not taken into account. Note that the atomic species of atom 1 is C1, and that the basis-function set C7.0_1s_CH.pao is assigned to this atom in the final-state calculation. In the final-state calculation, the following keywords need to be specified.

    scf.system.charge            1.0    # default=0.0
    scf.coulomb.cutoff            on    # default = off
    scf.core.hole                 on    # default = off
    <core.hole.state
      1 s 1
    core.hole.state>

Taking into account that the final state of the molecular system is an (N−1)-electron system, the number of electrons is reduced by one using the keyword scf.system.charge. Next, to avoid the spurious interaction between core holes in neighboring supercells, the exact Coulomb cutoff method [101] is applied using the keyword scf.coulomb.cutoff. If the exact Coulomb cutoff method is not applied, a uniform compensating charge with the opposite sign is automatically introduced to avoid the Coulomb divergence in a periodically charged system. Since this treatment produces a spurious interaction, the total energies of the initial and final states can no longer be compared directly.

The keyword core.hole.state specifies the core state in which a core hole is to be created. The first number is the serial index of the atom specified in Atoms.SpeciesAndCoordinates. The second symbol specifies the target l channel, which can be s, p, d, or f. The last number specifies the orbital index, which can take a value from 1 to 4⁢l+1. The correspondence between the orbital index and the core state is given in Table 13. Note that the target core state for creating a core hole is the lowest state of the l channel included in the pseudopotential as a valence state. For the C2H2 molecule, the pseudopotential C_PBE19_1s.vps contains the 1s state as a valence state. Therefore, the following specification indicates that a core hole is created in the |1s↑⟩ state of atom 1.

    <core.hole.state
      1 s 1
    core.hole.state>

If an s state is selected as the target state, either scf.SpinPolarization=on or scf.SpinPolarization=nc can be specified. On the other hand, when a p, d, or f state is selected, scf.SpinPolarization=nc must be specified in order to include spin-orbit interaction.

After the initial-state and final-state calculations have been completed, the following total energies are obtained from the output files.

     Initial state: -76.787732114928 (Hartree)
     Final state:   -66.084858926233 (Hartree)

Then, using Eq. (65), the binding energy can be calculated as follows.

Eb(gas) = Ef(0)⁢(N−1)−Ei(0)⁢(N),
= −66.084858926233−(−76.787732114928)=10.702873188695⁢(Hartree),
≈ 291.24⁢(eV).

The obtained value, 291.24 eV, agrees well with the experimental value of 291.14 eV [100]. Other calculation examples and the corresponding input files used in the calculations are available at the website https://www.openmx-square.org/vps_pao_core2019/ for reference.
