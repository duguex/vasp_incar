56.3 GridCalc: Calculation on a k-Point Grid

The post-process code kSpin provides four methods for calculating the momentum-space spin density matrix. This is specified by the keyword Calc.Type. Here we explain GridCalc among the four methods. GridCalc calculates the spin texture and the momentum-space spin density matrix of each band on a specified k-point grid. The bands are selected within a user-specified energy range. Instead of specifying an energy range, the bands to be calculated can also be specified directly. As an example of spin-texture analysis using GridCalc, we describe here a model of the Au(111) surface. First, perform an OpenMX calculation using the input file Au111Surface_GC.dat stored in the directory work. Next, run the post-process code kSpin. The keywords relevant to the execution of kSpin are listed below. These keywords are written in the input file Au111Surface_GC.dat. The input file Au111Surface_GC.dat is stored in the directory work.

List of keywords related to kSpin 

    Filename.scfout      Au111Surface.scfout
    Filename.outdata     Au111Surface_GL
    Calc.Type            GridCalc          # FermiLoop, GridCalc,
                                             BandDispersion, or MulPOnly
                                             default: MulPOnly
    Energy.Range        -1.0  1.0          # eV; default: 0.0  0.0
    Search.kCentral      0.0  0.0  0.0     # default: 0.0  0.0  0.0
    Calc.Type.3mesh      2                 # default: 1
    kRange.3mesh         0.5  0.5          # default: 0.5  0.5
    k-plane.1stStep      14 14             # default: 2 2
    Calc.Bandbyband      Off               # default: Off
    Calc.Band.Min        55
    Calc.Band.Max        56
    MulP.Vec.Scale       0.1  0.1  0.1     # default: 1.0  1.0  1.0

Specifications of the keywords

The keywords listed above are the same as those for FermiLoop, but their specifications are explained below from the viewpoint of GridCalc. Note that the behavior of the keyword Energy.Range differs from that in FermiLoop.

Filename.scfout
Specifies the name of the scfout file to be read by kSpin.

Filename.outdata
Specifies the name of the output files. This keyword corresponds to the OpenMX keyword System.Name.

Calc.Type
Choose one of FermiLoop, GridCalc, BandDispersion, or MulPOnly. The default setting is MulPOnly. Here we choose GridCalc.

Energy.Range
Specifies the energy range used to search for the bands to be analyzed. The unit is eV. When the keyword Calc.Bandbyband is OFF, this keyword is effective (see Calc.Bandbyband). The default value is -0.5 0.5. That is, the lower energy limit is -0.5 (eV), and the upper energy limit is 0.5 (eV).

Search.kCentral
A search is performed for k points around a central k point whose energies lie within the energy range specified by Energy.Range. This keyword specifies that central k point. The notation for specifying k points follows that of the keyword Band.kpath. The default value is 0.0 0.0 0.0 (that is, the Γ point).

Calc.Type.3mesh
Specifies the plane on which the spin texture is calculated. The values 1, 2, and 3 correspond to the ka⁢kb, kb⁢kc, and kc⁢ka planes, respectively. The default value is 1.

kRange.3mesh
Specifies the two-dimensional region in reciprocal space where the k points are calculated, by two values. For example, when the value of the keyword Calc.Type.3mesh is 1 (the ka⁢kb plane), the value 0.2 0.3 specifies the region −0.2≤ka≤0.2, −0.3≤kb≤0.3. The notation for specifying k points follows that of the keyword Band.kpath. The default value is 0.5 0.5 (that is, the entire first Brillouin zone).

k-plane.1stStep
Gives the number of grid points dividing the region specified by the keyword kRange.3mesh. This is used in the first-stage search. For example, if the value of the keyword Calc.Type.3mesh is 1 (the ka⁢kb plane), the value 2 3 means that the region is divided into 2 grid points along the ka axis and 3 grid points along the kb axis. The default value is 2 2.

Calc.Bandbyband
Specify ON if the bands given to GridCalc are to be calculated explicitly; otherwise specify OFF (see also Calc.Band.Min and Calc.Band.Max). The default value is OFF.

Calc.Band.Min
Specifies the lower bound of the band range to be calculated by giving the band index. This keyword is effective when the value of the keyword Calc.Bandbyband is ON (see Calc.Bandbyband and Calc.Band.Max). The band index can be checked either by using OMXTool [159] or by using the function BandDispersion (Sec. 56.4).

Calc.Band.Max
Specifies the upper bound of the band range to be calculated by giving the band index. This keyword is effective when the value of the keyword Calc.Bandbyband is ON (see Calc.Bandbyband and Calc.Band.Max). The band index can be checked either by using OMXTool [159] or by using the function BandDispersion (Sec. 56.4).

MulP.Vec.Scale
Specifies the scale of the vectors used to draw the spin texture. For example, the value 0.1 0.2 0.3 specifies scales of 0.1, 0.2, and 0.3 along the x, y, and z axes, respectively. This keyword affects only XXXXX.Pxyz_YY. (XXXXX is the value of the keyword Filename.outdata, and YY is the band index.) The default value is 1.0 1.0 1.0.

Calculation

The spin texture and the momentum-space spin density matrix are calculated by the post-process code kSpin. Here we assume that the post-process code kSpin is located in the directory work. Move to the directory work and run the calculation as follows.

    % ./kSpin Au111Surface_GC.dat

Alternatively, for an MPI calculation, for example with 4 MPI processes, run as follows.

    % mpirun -np 4 ./kSpin Au111Surface_GC.dat

    % gnuplot Au111Surface_GC.plotexample_55
    % gnuplot Au111Surface_GC.plotexample_56

Output files

The contents of the output files are explained below.

EigenMap_YY file
This file records the k-point data of the band (band index YY). The first, second, and third columns correspond to the kx, ky, and kz components, respectively. The unit is Bohr-1. The fourth column is the energy (in eV).

Pxyz_YY file
This file records the expectation values of the Pauli-matrix vector at each k point listed in the EigenMap_YY file. The first, second, and third columns correspond to the kx, ky, and kz components, respectively. The unit is Bohr-1. The fourth, fifth, and sixth columns correspond to the expectation values of σx, σy, and σz, respectively. The unit is the Bohr magneton.

AtomMulP file
This file records the data of the momentum-space spin density matrix decomposed into atomic contributions, which can be analyzed by MulPCalc (Sec. 56.6).

MulP_xx file
This file records the data of the x⁢x component of the momentum-space spin density matrix decomposed into atomic contributions. This file can be analyzed by MulPCalc (Sec. 56.6).

plotexample file
This file provides an example gnuplot script.

atominfo file
This file provides information on the lattice vectors and the PAOs.

temporal_12345.input
This file is a copy of the input file recorded in the scfout file.

(Optional) Analysis of the momentum-space spin density matrix

Using MulPCalc, data for analyzing the momentum-space spin density matrix can be extracted from the AtomMulP file or the MulP_xx file. An example of the input for MulPCalc is given at the end of the input file Au111Surface_GC.dat. After the above calculation, the momentum-space spin density matrix can be analyzed as follows.

    % ./MulPCalc Au111Surface_GC.dat

For further information on MulPCalc, see also Sec. 56.6.
