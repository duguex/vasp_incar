67 Analysis of the difference between two geometrical structures

Using a utility tool, one can analyze the difference between two x⁢y⁢z files that store three-dimensional coordinates (Cartesian coordinates). It is possible to investigate how the structure changes due to electric fields or substituents. Three types of analysis methods, described below, are available for analyzing differences between geometrical structures.

The root mean square deviation (RMSD) between two geometrical structures is defined by the following equation.

RMSD=∑iNatom(Ri−Ri0)2Natom.

The mean deviation (MD) between two geometrical structures is defined by the following equation.

MD=∑iNatom|Ri−Ri0|Natom.

The mean deviation of bond lengths (MDBL) between two geometrical structures is defined by the following equation.

MDBL=∑iNbond|B⁢Li−B⁢Li0|Nbond.

Here, Natom and Nbond denote the number of atoms and the number of bonds with bond lengths (BL) within the cutoff radius, respectively. In addition, the deviation vectors between the x⁢y⁢z coordinates of the corresponding atoms are output to an xsf file named dgeo_vec.xsf in XCrySDen format, so that the difference between the two structures can be visualized.

The procedure of the analysis is described below.

(1) Compilation of diff_geo.c
The file diff_geo.c is provided in the directory work. Compile this file using the following command.

    % gcc diff_geo.c -lm -o diff_geo

If the compilation finishes normally, the executable file diff_geo is generated in the directory work. Copy this executable file to the directory work.

(2) Calculation of the difference between two geometrical structures
The following usage information is written in the header part of diff_geo.c.

     usage:
              ./diff_geo file1.xyz file2.xyz -d rmsd

        option
           -d rmsd      a root mean square of deviation
           -d md        a mean deviation
           -d mdbl 2.2  a mean deviation between bond lengths,
                        2.2 (Ang) means a cutoff bond length which
                        can be taken into account in the calculation

If one wants to know the RMSD between two geometrical structures, execute the program as follows.

    % ./diff_geo file1.xyz file2.xyz -d rmsd

The calculation result is shown in the standard output. In addition, the difference in the three-dimensional coordinates of each atom is stored in the file dgeo_vec.xsf in XCrySDen vector format. This file can be visualized in XCrySDen using ’Display→Forces’. To calculate MDBL, specify the cutoff bond length (Å). In the MDBL calculation, bond lengths within the cutoff radius are taken into account. Figure 104(a) shows vectors corresponding to the differences in atomic coordinates between optimized structures. This example indicates that this tool is useful for understanding how structural changes occur due to charge doping or an electric field.
