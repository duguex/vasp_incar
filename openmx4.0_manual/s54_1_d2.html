54.1 DFT-D2 Method

The keywords related to the DFT-D2 method are listed below.

   scf.dftD                     on           # on|off, default=off
   DFTD.Unit                   Ang           # Ang|AU
   DFTD.rcut_dftD             100.0          # default=100 (DFTD.Unit)
   DFTD.d                      20.0          # default=20
   DFTD.scale6                 0.75          # default=0.75
   DFTD.IntDirection          1 1 1          # default=1 1 1 (1:on 0:off)

To include vdW interactions, set scf.dftD to on. The cutoff radius for the two-body potential is specified by the keyword DFTD.rcut_dftD. Its unit is given by DFTD.Unit. The parameter d in Eq. (12) of Grimme’s paper [148] is specified by DFTD.d. Its default value is 20. The scaling factor in Eq. (11) of Grimme’s paper [148] is specified by DFTD.scale6. The default value is 0.75 when the PBE functional is used. In addition, the vdW interaction introduced by this method can be truncated along the a, b, and/or c directions by DFTD.IntDirection, where 1 means that the interaction is included and 0 means that it is excluded. Furthermore, the periodicity of each atom can be controlled individually as follows. 

  <DFTD.periodicity
     1   1
     2   1
     3   1
     4   1
    ....
  DFTD.periodicity>

Here, the first column is the serial number, as in Atoms.SpeciesAndCoordinates, and the second column is a flag; for the corresponding atom, 1 means periodic and 0 means non-periodic. An atom specified as 0 is regarded as non-periodic, and its interaction with periodic images is not included.

The main modifications for implementing vdW interactions have been made in two routines, Calc_EdftD() in Total_Energy.c and DFTDvdW_init.c. In DFTDvdW_init.c, the parameters for the vdW correction can be modified easily, and in Calc_EdftD() in Total_Energy.c, the implementation can be examined.

Since OpenMX uses localized orbitals as basis functions, it is important to consider the basis set superposition error (BSSE) when investigating the effect of weak interactions such as vdW interactions. To evaluate the BSSE, the counterpoise method (CP method) [49, 50] can be used. See Section 12.5 for the CP method.
