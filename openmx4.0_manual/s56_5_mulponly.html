56.5 MulPOnly: Calculation at User-Specified k Points

The post-process code kSpin provides four methods for calculating the momentum-space spin density matrix. This is specified by the keyword Calc.Type. Here we explain MulPOnly among the four methods. Using the functionality of MulPOnly, the momentum-space spin density matrix can be calculated for user-specified k points and bands. As an example of spin-texture analysis using MulPOnly and MulPCalc, we describe here a model of the Au(111) surface. First, perform an OpenMX calculation using the input file Au111Surface_MO.dat stored in the directory work. Next, the spin texture can be calculated by using the functionality of MulPOnly. The keywords relevant to the execution of kSpin are listed below. These keywords are written in the input file Au111Surface_MO.dat. The input file Au111Surface_MO.dat is stored in the directory work.

List of keywords related to kSpin 

    Filename.scfout       Au111Surface.scfout
    Filename.outdata      Au111Surface_MO
    Calc.Type             MulPOnly               # FermiLoop, GridCalc,
                                                   BandDispersion, or MulPOnly
                                                   default: MulPOnly
    Filename.kpointdata   kpoint.in

In addition, another input file with the name specified by the keyword Filename.kpointdata is required. This file describes the k points at which the momentum-space spin density matrix is to be calculated. As an example of the setting file, the file kpoint.in is stored in the directory work. Its format follows the rules below. In the first line, specify the number of k points for which the momentum-space spin density matrix is to be calculated. Next, specify the k point (the first, second, and third columns correspond to kx, ky, and kz, respectively) and its band index (the fourth column). To calculate the momentum-space spin density matrix for k points on a circle centered at the Γ point in reciprocal space, kpoint.in can be generated by executing the following command.

  rm -f kpoint.in && awk '{for (i=0; i<$1; i++){printf "%17.14f %17.14f %17.14f %d\n", 0, $2*cos(2*atan2(0, -1)/$1*i),
  $2*sin(2*atan2(0, -1)/$1*i), $3 >> "buffer"}; sum+=$1; if (!$1) {print sum; exit}}' - > N.in && cat N.in buffer >> kpoint.in && rm N.in buffer

Then input the following values.

 40 0.18 55          <- # of k-points; radius; band index
 40 0.15 56          <- # of k-points; radius; band index
 0                   <- exit

Specifications of the keywords

The specifications of the keywords are explained below.

Filename.scfout
Specifies the name of the scfout file to be read by kSpin.

Filename.outdata
Specifies the name of the output files. This keyword corresponds to the OpenMX keyword System.Name.

Calc.Type
Choose one of FermiLoop, GridCalc, BandDispersion, or MulPOnly. The default setting is MulPOnly. Here we choose MulPOnly.

Filename.kpointdata
Specifies the name of the data file containing the k points and band indices.

Calculation

The atomically decomposed momentum-space spin density matrix is calculated by the post-process code kSpin. Move to the directory work and run the calculation as follows.

    % ./kSpin Au111Surface_MO.dat

Alternatively, for an MPI calculation, for example with 4 MPI processes, run as follows.

    % mpirun -np 4 ./kSpin Au111Surface_MO.dat

Output files

The contents of the output files are explained below.

AtomMulP file
This file records the data of the atomically decomposed momentum-space spin density matrix. It can be analyzed by using the functionality of MulPCalc (Sec. 56.6).

MulP_xx file
This file records the data of the x⁢x component of the atomically decomposed momentum-space spin density matrix. It can be analyzed by using the functionality of MulPCalc (Sec. 56.6).

atominfo file
This file provides information on the lattice vectors and the PAOs.

temporal_12345.input
This file is a copy of the input file recorded in the scfout file.

Analysis of the atomically decomposed momentum-space spin density matrix

Using MulPCalc, data for analyzing the atomically decomposed momentum-space spin density matrix can be extracted from the AtomMulPBand file or the AMulPBand_xx file. Compile it in the directory work as follows to generate the executable.

    % make MulPCalc

If the compilation is successful, the executable MulPCalc is generated in the directory work. As an example, we focus on the band dispersion of the Rashba spin splitting on the Au(111) surface and analyze the momentum-space spin density matrix decomposed into atomic contributions. First, add the following keywords to the input file Au111Surface_MO.dat. 

    Filename.atomMulP Au111Surface_MO.AMulPBand   # default: default
    Filename.xyzdata   Au111Surface_MO_MC         # default: default
    Num.of.Extract.Atom        3                  # default: 1
    Extract.Atom               1 2 3              # default: 1 2 ... (Num.of.Extract.Atom)
    Calc.Type.3mesh            2                  # default: 1

After the calculation by the post-process code MulPCalc, the momentum-space spin density matrix decomposed into atomic contributions can be analyzed as follows.

    % ./MulPCalc Au111Surface_MO.dat

In addition, the appearance of the figure can be adjusted by setting the following keywords. 

    MulP.Vec.Scale       0.1  0.1  0.1          # default: 1.0  1.0  1.0
    Data.Reduction             1                # default: 1

After running MulPCalc, the following output files are obtained in the directory work.

    Au111Surface_MO_MC.MulPop
    Au111Surface_MO_MC.MulPop55
    Au111Surface_MO_MC.MulPop56
    Au111Surface_MO_MC.plotexample

As an example, by running the following command, Fig. 81 is obtained. This shows the spin texture of the Rashba spin splitting on the Au(111) surface.

    % gnuplot Au111Surface_MO_MC.plotexample

For further information on MulPCalc, see also Sec. 56.6.
