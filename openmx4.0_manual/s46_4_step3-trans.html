46.4 Step 3: Transmission, current (density), and eigenchannels

After completing the Step 2 and Step 3 calculations, the transmission, current (density), and eigenchannels can be calculated.

46.4.1 Transmission, current, and conductance

First, calculate the transmission, current, and conductance using openmx. The keywords related to this calculation are as follows.

    NEGF.tran.Analysis         on        #  default on
    NEGF.tran.CurrentDensity   on        #  default on
    NEGF.tran.energyrange -10 10 1.0e-3  # default=-10.0 10.0 1.0e-3 (eV)
    NEGF.tran.energydiv        200       # default=200
    NEGF.tran.Kgrid            1 1       # default= 1 1
  • •

    NEGF.tran.Analysis, NEGF.tran.Channel, NEGF.tran.CurrentDensity

    If NEGF.tran.Analysis is set to on, the transmission, current, and conductance are calculated.

  • •

    NEGF.tran.energyrange, NEGF.tran.energydiv

    The energy range for calculating the transmission is specified by the keyword NEGF.tran.energyrange. The first and second numbers are the lower and upper bounds of the energy, and the third number is the imaginary value used to smooth the transmission. The energy range specified by NEGF.tran.energyrange is divided into the number of points specified by the keyword NEGF.tran.energydiv, and the transmission is calculated at those energy points.

  • •

    NEGF.tran.Kgrid

    The respective numbers of k points used to discretize the reciprocal lattice vectors 𝐛~ and 𝐜~ are specified by NEGF.tran.Kgrid. The values given by NEGF.tran.Kgrid can be different from those used in NEGF.scf.Kgrid, and larger values are recommended for higher accuracy.

After the calculation finishes, the following three files are generated.

negf-chain.tran0_0, negf-chain.current, negf-chain.conductance:

  • •

    System.Name.tran#_%

    This file stores the transmission for the up- and down-spin states. The fourth column is the energy relative to the chemical potential of the left lead, and the sixth and eighth columns are the transmission for the up- and down-spin states, respectively. If a larger number of k points specified by NEGF.tran.Kgrid is used, files with different pairs of # and ‘%’ in the file extension are generated for each k point. The correspondence between the file numbers and the k points can be checked inside the file.

  • •

    System.Name.current

    This file stores the k-resolved current and its average value for the up- and down-spin states in units of ampere.

  • •

    System.Name.conductance

    This file stores the k-resolved conductance and its average value for the up- and down-spin states in units of the conductance quantum (G0≡e2h). The conductance G is evaluated based on the Landauer picture, and in the low-bias limit it is proportional to the transmission T at the chemical potential μL of the left electrode as follows.

    G=e2h⁢T⁢(μL)

As an example, Fig. 46 shows the k-resolved transmission of an Fe|MgO|Fe structure prepared from the file System.Name.conductance.

46.4.2 Real-space current/spin-current density

In Step 3, the current/spin-current density in real space can be calculated. The keyword related to this calculation is as follows.

NEGF.tran.CurrentDensity   on        #  default on
  • •

    NEGF.tran.CurrentDensity

    If NEGF.tran.CurrentDensity is on, the current density in real space is calculated.

These files contain the following physical quantities.

  • •

    System.Name.curden.xsf, System.Name.scurden.xsf

    These files contain the charge-current and spin-current densities on the real-space grid.
    They can be visualized in XCrySDen using ‘Display→Forces’.

  • •

    System.Name.curden1.cube, System.Name.scurden1.cube

    These files contain the a-component of the charge-current and spin-current densities on the real-space grid. They can be visualized with VESTA or XCrySDen.

  • •

    System.Name.curden_atom.xsf, System.Name.scurden_atom.xsf

    These files contain the charge-current and spin-current densities averaged over the Voronoi polyhedron of each atom. They can be visualized in XCrySDen using ‘Display→Forces’.

In OpenMX Ver. 4.0, 

    NEGF.OffDiagonalCurrent   on        #  default off

can also be set to perform non-collinear magnetic calculations, and the following files are generated.

  • •

    System.Name.odcurden_r.xsf, System.Name.odcurden_i.xsf

  • •

    System.Name.odcurden1_r.cube, System.Name.odcurden1_i.cube

  • •

    System.Name.odcurden_atom_r.xsf, System.Name.odcurden_atom_i.xsf

These files contain the off-diagonal spin components of the current density. Since these are generally complex quantities, they are output separately into real and imaginary parts.

As an example, Fig. 47 shows the current density of an 8-zigzag graphene nanoribbon with an antiferromagnetic junction under a bias voltage of 0.3 V.

46.4.3 Eigenchannel analysis

In Step 3, transmission eigenchannels can also be calculated. The keywords related to this calculation are as follows.

    NEGF.tran.Channel          on        #  default on
    NEGF.Channel.Nkpoint        1        # default=1
    <NEGF.Channel.kpoint
    0.0  0.0
    NEGF.Channel.kpoint>
    # default 0.0 0.0
    NEGF.Channel.Nenergy        1        # default=1
    <NEGF.Channel.energy
    0.0
    NEGF.Channel.energy>
    # default 0.0
    NEGF.Channel.Num    5    # default=5(for collinear), 10(for Non-collinear)
  • •

    NEGF.tran.Channel

    If NEGF.tran.Channel is on, the eigenchannels are calculated.

  • •

    NEGF.Channel.Nkpoint, <NEGF.Channel.kpoint, NEGF.Channel.kpoint>

    These keywords are used to specify the k points for which eigenchannels are calculated. Please list one k point per line between <NEGF.Channel.kpoint and NEGF.Channel.kpoint>. The total number of k points should be specified by NEGF.Channel.Nkpoint. The 𝐤 coordinates should be written as two-dimensional normalized coordinates, and k should be specified as coefficients of the two reciprocal lattice vectors perpendicular to the transport direction.

  • •

    NEGF.Channel.Nenergy, <NEGF.Channel.energy, NEGF.Channel.energy>

    These keywords are used to specify the energies of the eigenchannels to be calculated. Please list one energy per line between <NEGF.Channel.energy and NEGF.Channel.energy>. The total number of energies should be specified by NEGF.Channel.Nenergy. The unit of energy is eV, and the reference should be set to the chemical potential of the left electrode.

  • •

    NEGF.Channel.Num

    This parameter specifies the number of eigenchannels in the real-space representation. For each k, energy, and spin, the transmission eigenvalues are output in descending order. The file format is Gaussian cube, and the real and imaginary parts are output separately.

    System.Name.tranevec{#k}_{#E}_{#s}

    This file contains the LCAO components of the eigenchannels for the {#k}-th k, the {#E}-th energy, and the {#s}-th spin.
