56.1 Spin-texture overview

In this subsection, we explain how to calculate spin textures by using a simple model of the Au(111) surface. The spin texture and the momentum-space spin density matrix are analyzed by the following two or three steps.

1. SCF calculation

Run a standard SCF calculation using the input file Au111Surface_FL.dat stored in the directory work. Set the following keywords, scf.SpinPolarization and HS.fileout, to NC and ON, respectively, as follows. 

    scf.SpinPolarization         NC    # On|Off|NC
    HS.fileout                   ON    # on|off, default=Off

In addition, to analyze spin textures, set the keyword scf.SpinOrbit.Coupling to ON. 

    scf.SpinOrbit.Coupling       ON    # On|Off

If the calculation finishes normally, the output file Au111Surface.scfout is generated in the directory work. By setting the keywords for drawing a band structure as well, the band structure of the present Au(111) surface model can be obtained (see Fig. 77).


2. Calculation of the spin texture and momentum-space spin density matrix

Here we analyze the spin-split Rashba bands shown in Fig. 77. The spin texture and the momentum-space spin density matrix can be calculated by the post-process code kSpin. First, an executable can be obtained by compiling in the directory work as follows.

    % make kSpin

If the compilation is successful, the executable kSpin is generated in the directory work. Next, move to the directory work and execute it as follows.

    % ./kSpin Au111Surface_FL.dat

In the input file, it is necessary to set the appropriate keywords for kSpin. The required keywords will be explained later. Four methods are implemented in kSpin for calculating the momentum-space spin density matrix: FermiLoop, GridCalc, BandDispersion, and MulPOnly. The details of these four methods are explained in the corresponding subsections. The present example, Au111Surface_FL.dat, is for FermiLoop, and its analysis procedure is explained in Sec. 56.2.

3. (Optional) Analysis of the momentum-space spin density matrix

An analysis function for the momentum-space spin density matrix and its atomic decomposition is implemented. In addition to the atomic decomposition, it can be further decomposed into the s, p, d, and f orbital components. The post-process code kSpin can be used for analyzing the momentum-space spin density matrix decomposed into atoms and pseudo-atomic orbitals. For this functionality, see Sec. 56.6 on MulPCalc.
