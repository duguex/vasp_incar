23.2 For calculations with many k points

In DOS calculations for large systems with many k points, a large amount of memory is required, and the post-processing calculation using DosMain may terminate abnormally because of insufficient memory. In such a case, the on-the-fly Gaussian broadening method can be used. In this method, the Gaussian broadening method is applied on the fly during the DOS calculation in OpenMX, and the DOS is evaluated directly. The wavefunction information, which would otherwise become a large amount of data, is not written to the file System.Name.DOS.vec. Since this method does not require a large amount of memory, DOS calculations for large systems become possible. When this method is used, specify the following keywords in the input file:

     DosGauss.fileout      on       # default=off, on|off
     DosGauss.Num.Mesh    200       # default=200
     DosGauss.Width       0.2       # default=0.2 (eV)

To use this method, set the keyword DosGauss.fileout to on. The keyword DosGauss.Num.Mesh specifies the number of divisions of the energy range given by the keyword Dos.Erange. The keyword DosGauss.Width specifies the width a appearing in the Gaussian distribution exp⁡(−(E/a)2). The keywords DosGauss.fileout and Dos.fileout are mutually exclusive and cannot be used together. Therefore, when this keyword is used, Dos.fileout should be set to off as follows:

     Dos.fileout          off       # on|off, default=off

In addition, the following two keywords are valid for both Dos.fileout and DosGauss.fileout:

     Dos.Erange       -20.0  20.0   # default=-20 20
     Dos.Kgrid           5 5 5      # default=Kgrid1 Kgrid2 Kgrid3

With the keyword DosGauss.fileout, only the DOS based on the Gaussian broadening method can be calculated. DOS based on the tetrahedron method cannot be calculated, so please be careful. Even when DosGauss.fileout is used, the post-processing procedure using DosMain is the same as that described above, except that the DOS based on the tetrahedron method cannot be calculated.
