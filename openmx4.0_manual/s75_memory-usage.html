75 Analysis of memory usage

By analyzing the files *.memory0, *.memory1, …, and *.memory#, you can examine the memory usage. Here, * denotes the file name specified by the keyword System.Name, and the number (#) at the end of the file extension represents the process ID in MPI parallel calculations. These files are output by setting the keyword memory.usage.fileout as follows.

    memory.usage.fileout   on   # default=off, on|off
