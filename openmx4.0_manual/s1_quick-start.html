1 Quick start for first-time OpenMX users

If you are using OpenMX for the first time, a good starting point is to run one example calculation successfully from beginning to end and become familiar with the overall workflow, including input files, output files, and visualization. The present manual covers a wide range of functions, but at the initial stage it is often more helpful to read it by following sections that are close to your immediate interests. This section briefly summarizes such entry points.

1. First, run one calculation from beginning to end

To prepare a computational environment, in addition to installing OpenMX from source code in a Linux environment, one may also use Debian packages in a WSL-based Ubuntu environment. If your first goal is simply to start calculations, it is convenient to begin with the subsection “Installation using Debian packages” in Sec. 4, “Installation.” On the other hand, installation from source code on WSL is also available, and this is useful when you wish to go further, for example by adjusting the makefile, recompiling auxiliary codes, or using the API. For installation from source code on WSL, see the subsection Installation from source code on WSL in the same Sec. 4.

After installation, follow Sec. 5, “Test calculations,” to run Methane.dat and confirm that the calculation finishes normally and that output files such as met.out, met.std, and met.xyz are generated. Once normal operation has been confirmed at this stage, it becomes easier to identify the situation later when input files are modified.

Next, it is useful to read Sec. 8, “Input files,” and Sec. 9, “Output files,” in order to understand the basic structure of input files and what information is written to each output file. In addition, OpenMX Viewer, described in Sec. 10,“Interfacing with OpenMX Viewer,” can be used to inspect structures, check inputs before running calculations, and examine results afterward on screen. In particular, the ability to visualize coordinates, lattice vectors, periodicity, and cube data is helpful at an early stage. If you would like to start from the crystal structure of an actual material, the subsection Sec. 8.3, “Generation of dat files from CIF files: cif2omx,” is also useful.

2. After the basic calculation, move on to structure, electronic states, and physical properties

Once a basic SCF calculation has been completed, the natural next step is to deepen your understanding of the structure and the electronic states. If you wish to relax atomic positions and obtain a stable structure, see Sec. 18, “Geometry optimization.” If you wish to optimize lattice vectors as well, see Sec. 19, “Variable-cell geometry optimization.” For the analysis of electronic states, the basic starting points are Sec. 22, “Band dispersions,” and Sec. 23, “Density of states.” If you wish to examine chemical bonding between atoms, Sec. 24, “COHP and COOP,” is useful. In addition, if you would like to reinterpret supercell results in terms of the primitive-cell picture, or to examine band structures of systems containing defects, disorder, or structural fluctuations, Sec. 55, “Band-unfolding method,” is helpful.

For problems involving magnetism and spin, see Sec. 37, “Non-collinear DFT,” Sec. 38, “Relativistic effects,” and Sec. 42, “Second variational method: magnetic anisotropy energy (MAE).” These sections provide an entry point to non-collinear magnetism, spin–orbit interaction, orbital magnetic moments, and magnetic anisotropy energy. Furthermore, if you would like to organize electronic states from the viewpoint of localized orbitals, see Sec. 47, “Generation of Wannier functions.” This section explains not only Wannier-function generation within OpenMX but also the interface to Wannier90.

If you wish to proceed to more advanced property calculations, Sec. 62, “Optical conductivity and dielectric function,” Sec. 60, “Absolute binding energies of core electrons: energies of core levels in XPS,” and Sec. 49, “Effective screening medium (ESM) method,” provide a useful sequence of entry points. If you are interested in transport calculations, see Sec. 63, “Interface with BoltzTraP/BoltzTraP2,” when you wish to evaluate transport coefficients or thermoelectric properties based on the band structure, and see Sec. 46.1, “Overview of electronic transport calculations by the NEGF method,” when you wish to treat electrical conduction in open systems including electrodes or nanoscale junctions. If you are interested in topological properties, useful starting points are Sec. 56, “Analysis of spin textures in momentum space,” Sec. 58, “Calculation of the Chern number and Berry curvature by the Fukui–Hatsugai–Suzuki method,” and Sec. 59, “Calculation of the Z2 invariant by the Fukui–Hatsugai method.”

3. Move on to development and external interfacing

If you would like to use OpenMX together with other programs or peripheral tools, see Sec. 71, “External program interfacing through the OpenMX API.” This section explains how to use the API from C, Fortran, and Python, together with usage examples. If you would like to develop post-processing codes or peripheral tools using OpenMX output, Sec. 70, “Interfaces for developers,” is also useful. For broader related information, see Sec. 81, “Additional sources of information on OpenMX,” and Sec. 82, “Links to other tools.”

When adding new functions or modifying existing code, see Sec. 72, “Automatic force tester,” Sec. 73, “Automatic memory leak tester,” and Sec. 74, “Memory leak analysis tools for developers.” In particular, leakdetect.c and leakdetect.h are useful for checking whether memory management problems have been introduced after code modifications.

In summary, when using OpenMX for the first time, it is useful to begin by running one example calculation successfully, understanding the basics of input and output, and becoming familiar with the results with the help of tools such as OpenMX Viewer. From there, one may proceed to geometry optimization, band calculations, density-of-states calculations, bonding analysis by COHP/COOP, band unfolding, non-collinear calculations and spin–orbit interaction, and Wannier-function calculations, and then extend the scope as needed to optical response, XPS, transport calculations, and topological properties. If you wish to move on to development or external interfacing, the API, developer interfaces, various testers, and memory-leak analysis tools will be useful.
