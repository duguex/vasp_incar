44 Macroscopic polarization by the Berry phase method

Using the Berry phase method, one can calculate the macroscopic electric polarization of bulk systems [15]. As an example, we explain the procedure for calculating the Born effective charge of the sodium atom in sodium chloride from the macroscopic electric polarization.
(1) SCF calculation
First, perform a standard SCF calculation using the input file NaCl.dat in the work directory. In this case, turn on the keyword HS.fileout.

    HS.fileout               on     # on|off, default=off

After the SCF calculation finishes successfully, the output file nacl.scfout is generated in the work directory.

(2) Calculation of macroscopic polarization
The macroscopic polarization is calculated using the post-processing program polB. In this step, nacl.scfout is used as the input data. First, compile polB in the source directory as follows.

    % make polB

If the compilation is completed successfully, the executable file polB is generated in the work directory. Next, move to the work directory and run it as follows.

    % polB nacl.scfout
   or
    % polB nacl.scfout < in > out

In the latter case, save the following data in the text file in.

    9 9 9
    1 1 1

In the former case, the program interactively asks the following questions.

Let Vc be the unit-cell volume, e the elementary charge, Δ⁢uβ the displacement along the β coordinate, and Δ⁢Pα the change in the macroscopic polarization along the α coordinate. Then, the Born effective charge Zα⁢β∗ is defined as the following tensor:

Zα⁢β∗=Vc|e|⁢Δ⁢PαΔ⁢uβ

According to the above expression, to calculate the Born effective charge, one repeats the above procedure at least twice, and usually three times, while changing the x, y, and z coordinates of the sodium atom. For example, when the atom is displaced along the x direction and the polarization is calculated, the following results are obtained.

    Px = 94.39498187 (Debye/unit cell) at x= -0.05 (Ang)
    Px = 94.64718713 (Debye/unit cell) at x=  0.0  (Ang)
    Px = 94.89938866 (Debye/unit cell) at x=  0.05 (Ang)

Therefore, the Born effective charge of the sodium atom is calculated as follows.

Zx⁢x∗ = (94.89938866−94.39498187)/(2.54174776)0.1/0.529177
= 1.050

In crystalline sodium chloride, the off-diagonal components of the Born charge tensor are zero, and Zx⁢x∗=Zy⁢y∗=Zz⁢z∗ holds. Table 8 shows a comparison of the present result with another calculated value [127] and the experimental value [128]. It is found that the calculated value agrees well with the experimental value. The calculation of macroscopic polarization is supported for both collinear and non-collinear DFT methods. In addition, even when the number of MPI processes exceeds the number of atoms in the system, the program polB can still perform efficient parallel calculations.
