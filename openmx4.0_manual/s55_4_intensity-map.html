55.4 Intensity map of unfolded spectral weights

The unfolded spectral weights can be visualized as an intensity map. The weight w is smoothed by the following Lorentzian function.

L⁢(k,E)=w(k/Δk)2+(E/ΔE)2+1,

where k is the value of the 𝐤 vector in units of Bohr-1, E is the energy in eV, and Δk and ΔE control the degree of smoothing. Note that the absolute value of the intensity map has no physical meaning. Visualization of the intensity map can be carried out in the following three steps.

(1) Compilation of intensity_map.c
In the source directory, compile intensity_map.c as follows.

  gcc intensity_map.c -lm -o intensity_map

Copy the generated executable file intensity_map to the working directory.
(2) Generation of the intensity map
After the unfolding calculation has finished, a file containing the mesh data required to generate the intensity map can be produced. Here, as an example, we consider the (2×2) supercell of two-dimensional honeycomb SiC with an Si vacancy, discussed in the previous subsection. The input file for the unfolding calculation is SiC_C_SP_V.dat, and the mesh-data file sic-intmap.txt is generated as follows.

  ./intensity_map sic_c_sp_v.unfold_totup -c 3 -k 0.1 -e 0.1 -l -10 -u 6 > sic-intmap.txt

The meaning of each argument is as follows.

  • •

    -c : column number containing the spectral weight to be analyzed

  • •

    -k : value of Δk for the k vector (Bohr-1)

  • •

    -e : value of ΔE (eV)

  • •

    -l : minimum band energy to be drawn in the map (eV)

  • •

    -u : maximum band energy to be drawn in the map (eV)

When analyzing System.Name.unfold_orbup(dn), set the column number for -c by referring to the serial numbers of the pseudo-atomic orbitals in System.Name.out. Note that Ncol specified by -c is related to the pseudo-atomic-orbital serial number Nseq in System.Name.out. Their relation is Ncol=Nseq+2.

(3) Plotting the intensity map
The intensity map can be plotted using gnuplot. For the calculation using the input file SiC_C_SP_V.dat, plot it as follows.

  gnuplot> set yrange [-10.000000:6.000000]
  gnuplot> set ylabel ’Energy (eV)’
  gnuplot> set xtics(’K’ 0.000000,’G’ 0.722259,’M’ 1.347753,’K’ 1.708883)
  gnuplot> set xrange [0:1.708883]
  gnuplot> set arrow nohead from 0,0 to 1.708883,0
  gnuplot> set arrow nohead from 0.722259,-10.000000 to 0.722259,6.000000
  gnuplot> set arrow nohead from 1.347753,-10.000000 to 1.347753,6.000000
  gnuplot> set pm3d map
  gnuplot> sp ’sic-intmap.txt’

These commands yield Fig. 76(a).
