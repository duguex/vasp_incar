46.2 Step 1: Calculation of the lead regions

The Step 1 calculation is the same as an ordinary band-structure calculation. However, the two keywords NEGF.output_hks and NEGF.filename.hks must be added to the input file.

    NEGF.output_hks    on
    NEGF.filename.hks  lead-chain.hks

By adding the above keywords, information required to construct the electrode parts is saved in a file. Hamiltonian matrix elements, the electron distribution, and the difference-electron Hartree potential are stored in the file specified by the keyword NEGF.filename.hks. In the above case, the file lead-chain.hks is generated.
The file specified by NEGF.filename.hks will be used in the Step 2 calculation. In the current implementation, the direction of electron transport is assumed to be along the a axis. Therefore, when constructing the electrode model in the band-structure calculation, this specification should be kept in mind. However, the user does not need to rotate the structure manually. By simply changing the definition of the lattice vectors, the transport direction can be set appropriately. For example, for the following lattice vectors,

      <Atoms.UnitVectors
        3.0  0.0  0.0
        0.0  3.0  0.0
        0.0  0.0 10.0
      Atoms.UnitVectors>

if you want to assign the vector (0.0, 0.0, 10.0) as the a axis, you only need to interchange the order of the vectors as follows in order to set the transport direction properly.

      <Atoms.UnitVectors
        0.0  0.0 10.0
        3.0  0.0  0.0
        0.0  3.0  0.0
      Atoms.UnitVectors>

With this specification, the direction (0.0, 0.0, 10.0) becomes the transport direction. As shown in the above example, note that when changing the order of the lattice vectors, the keyword scf.Kgrid must be changed accordingly.

In the Step 2 calculation, the semi-infinite nature of the electrode regions is taken into account by using the surface Green function. Therefore, in the Step 2 calculation the semi-infinite character along the a axis can be treated without introducing any discretization in reciprocal space along the a axis. To maintain consistency between the calculations in Step 1 and Step 2 regarding the treatment of semi-infinite electrodes along the a axis, please assign a sufficiently large number of k points along the a axis in the Step 1 band-structure calculation. Also, the number of k points on the bc plane should be the same in Steps 1 and 2.
