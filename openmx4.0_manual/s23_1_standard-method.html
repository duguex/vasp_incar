23.1 Standard method

The density of states (DOS) based on Kohn-Sham eigenvalues is calculated in the following two steps.

(1) SCF calculation

Using diamond carbon as an example, we explain how to calculate the DOS. In the file Cdia.dat in the work directory, the keywords for the DOS calculation are specified as follows:

    Dos.fileout                  on
    Dos.Erange              -25.0  20.0
    Dos.Kgrid                12 12 12

The first and second values specified by the keyword Dos.Erange are the lower and upper bounds, respectively, of the energy range (eV) for the DOS calculation, where the energy origin (0.0) corresponds to the chemical potential. The values (n1,n2,n3) specified by the keyword Dos.Kgrid are the numbers of grid points used to discretize the first Brillouin zone in the DOS calculation.

Next, run OpenMX in the usual way as follows:

    % ./openmx Cdia.dat

Although a single-core example is shown here, parallel calculations can of course also be performed. If the calculation finishes normally, the two files cdia.Dos.val and cdia.Dos.vec are generated in the work directory. The file cdia.Dos.val stores the eigenvalues in text format, while cdia.Dos.vec stores the eigenvectors in binary format. This DOS calculation is also supported in O(N) calculations, in which case the Gaussian broadening method is applied.

(2) DOS calculation

Compile the utility program for the DOS calculation. Move to the source directory and compile it with the following command:

    % make DosMain

If the compilation finishes normally, the executable file DosMain is generated in the source directory. Copy DosMain to the work directory and move to the work directory. Using this program DosMain, the total DOS and projected DOS (PDOS) are calculated from the two files cdia.Dos.val and cdia.Dos.vec according to the following procedure:

    % ./DosMain cdia.Dos.val cdia.Dos.vec

At that point, the program interactively asks questions as follows:

    % ./DosMain cdia.Dos.val cdia.Dos.vec
    Max of Spe_Total_CNO = 8
    1 1 101 102 103 101 102 103
    <cdia.Dos.val>
    <cdia>
    Which method do you use?, Tetrahedron(1), Gaussian Broadeninig(2)
    1
    Do you want Dos(1) or PDos(2)?
    2

    Number of atoms=2
    Which atoms for PDOS : (1,...,2), ex 1 2
    1
    pdos_n=1
    1
    <Spectra_Tetrahedron> start
    Spe_Num_Relation 0 0 1
    Spe_Num_Relation 0 1 1
    Spe_Num_Relation 0 2 101
    Spe_Num_Relation 0 3 102
    Spe_Num_Relation 0 4 103
    Spe_Num_Relation 0 5 101
    Spe_Num_Relation 0 6 102
    Spe_Num_Relation 0 7 103
    make cdia.PDOS.Tetrahedron.atom1.s1
    make cdia.PDOS.Tetrahedron.atom1.p1
    make cdia.PDOS.Tetrahedron.atom1.p2
    make cdia.PDOS.Tetrahedron.atom1.p3
    make cdia.PDOS.Tetrahedron.atom1

For the DOS calculation, either the tetrahedron method [70] or the Gaussian broadening method can be selected. The user can also choose either DOS or PDOS. If PDOS is selected, choose the atom(s) on which the PDOS is to be evaluated. In that case, the PDOS projected onto the orbitals (s, p⁢x⁢(p⁢1), p⁢y⁢(p⁢2), p⁢z⁢(p⁢3), ..) of the selected atom is output to each file. In these files, the first and second columns are the energy (eV) and the value of DOS (eV-1) or PDOS (eV-1), respectively, while the numerical values in the third column represent the integrated DOS or PDOS. When a spin-polarized calculation is performed using LSDA-CA, LSDA-PW, or GGA-PBE, the numerical values in the second and third columns of these files correspond to the DOS or PDOS of the up-spin and down-spin states, respectively, and the numerical values in the fourth and fifth columns are the corresponding integrated values. When the Gaussian broadening method is used, the Gaussian parameter value a (eV), which determines the width of the Gaussian distribution defined by exp⁡(−(E/a)2), must be specified.
