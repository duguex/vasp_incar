58.2 Chern/Berry example

As an example, Fig. 87 shows the Berry curvature of graphene. Since the absolute value of the Berry curvature is approximately proportional to the inverse square of the band gap, a large Berry curvature appears around the K and K′ points, where massive Dirac points emerge when spin–orbit interaction is taken into account. Using the input file Graphene-Chern.dat stored in the directory work, the calculation procedure is explained below.

SCF calculation
Perform an SCF calculation for graphene using the input file Graphene-Chern.dat stored in the directory work. Set the keyword HS.fileout to on as follows.

    HS.fileout      on      #on|off, default=off

If the SCF calculation finishes normally, the output file Graphene-Chern.scfout is obtained.

Calculation of the Chern number and Berry curvature
Next, proceed to the calculation of the Chern number and Berry curvature by using the post-process code calB. Move to the directory work and compile the code calB as follows.

    % make calB

If the compilation finishes normally, the executable calB is generated in the directory work. Next, move to the directory work and execute calB as follows.

    % ./calB Graphene-Chern.scfout
 or
    % ./calB Graphene-Chern.scfout < calB.in > calB.out
 or
    % mpirun -np 4 ./calB Graphene-Chern.scfout < calB.in > calB.out

Parameters of calB
Prepare an input file calB.in with the following contents.

   1
   0
   0 0 1
   100 100

The meanings of the parameters are explained below.

  • •

    In the first line, specify whether the Berry curvature is calculated as the sum over all bands, or whether it is calculated for isolated bands. Set 1 for the former and 0 for the latter. The latter setting is valid only when the set of bands is completely isolated from the other bands.

  • •

    In the second line, specify the number of bands to be considered in the calculation. The bands are counted from the lowest band. If 0 is specified, all valence bands are taken into account.

  • •

    In the third line, specify the plane in reciprocal space on which the calculation is performed. For example, 0 0 1 corresponds to the plane k3=0.

  • •

    In the fourth line, specify the mesh size. In the graphene example, the k3=0 plane specified in the third line is divided into a 100×100 mesh.

Output files
After running calB, the following files are generated.

  • •

    BerryC*.dat

    This file records the Berry curvature and the Chern number obtained in the calculation. Here * in the file name BerryC* denotes the number of included bands. In the graphene example, * is 8. The unit of the Berry curvature is Å2. A part of BerryC8.dat for the graphene example is shown below.

       #Mesh Number:100*100
   #Band Number:8
   #ChernNumber = 0.000000
   #k1          k2           F (ang^2)
   0.005000 0.005000 -1.59799534e-05
   0.015000 0.005000 1.94455630e-05
   0.025000 0.005000 3.58476883e-05
   ....
   ..

    The data can be visualized by using Gnuplot as follows.

        % splot "BerryC8.dat" w l

    Figure 87 shows the Berry curvature on the k3=0 plane.

  • •

    temporal_12345.input

    This file is a copy of the input file. It was used for the SCF calculation and reconstructed from the scfout file.
