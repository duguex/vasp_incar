18.6 Format of the md file

The OpenMX Viewer can read an md file, which is an extended version of the xyz file, and display each step of molecular dynamics (MD) or structural optimization as an animation. A key feature of the md file is that, for each step, it can store not only atomic coordinates but also cell vectors, forces, velocities, net charges, local magnetic moments, and spin orientation information. Therefore, the OpenMX Viewer can visualize not only changes in atomic structure, but also variations in charge, spin, force, and velocity at each step.

An md file consists of multiple data blocks corresponding to individual structural steps. One block corresponds to one structural step. The first line of each block gives the number of atoms, the second line gives information for the entire step, and the third and subsequent lines give one line of information for each atom. Formally, each block is written as follows.

Natom
comment ... Cell_Vectors= ax ay az  bx by bz  cx cy cz  scf_conv=...
Elem  x  y  z  Fx  Fy  Fz  vx  vy  vz  Q  m  theta  phi
Elem  x  y  z  Fx  Fy  Fz  vx  vy  vz  Q  m  theta  phi
...

Here, Natom is the number of atoms, and comment is an arbitrary comment string. In the second line, Cell_Vectors= is the keyword for specifying the cell vectors, and it is followed by nine real numbers arranged in the order of ax, ay, az, bx, by, bz, cx, cy, and cz. The unit is Å. Also, scf_conv=1 means that the SCF calculation converged at that MD step, while scf_conv=0 means that the SCF calculation did not converge. Note that the part before Cell_Vectors= is treated as a comment, so information such as time, total energy, and temperature can be written freely. For example, for a system consisting of 10 atoms, the first block can be written as follows:

10
time= 0.000 (fs) Energy= -56.61840 (Hartree) Temperature= 1000.000 (Given Temp.= 1000.000) Cell_Vectors= 10.18041 0.00000 0.00000  0.00000 10.18041 0.00000 0.00000 0.00000 8.55154  scf_conv=1
C  -0.55502 -0.05167  0.35409   0.03654 -0.00779 -0.03763 -1394.21538 338.60117 -141.80824  -0.49099  0.00000  0.00000  0.00000
....
...

In the above example, the time is set to 0.000 fs, the total energy is −56.61840 Hartree, and the temperature is set to 1000.000 K. The cell vectors are given by

𝐚=(10.18041, 0.00000, 0.00000),
𝐛=(0.00000, 10.18041, 0.00000),
𝐜=(0.00000, 0.00000, 8.55154)

which means that a rectangular cell is defined. Furthermore, from scf_conv=1, we see that the SCF calculation converged at this step. Each line corresponding to an atom consists of 14 data entries:

atomic symbol,x,y,z,Fx,Fy,Fz,vx,vy,vz,Q,m,θ,ϕ

Here, x, y, and z are the atomic coordinates (Å), Fx, Fy, and Fz are the force components (Hartree/Bohr), and vx, vy, and vz are the velocity components (m/sec.). Also, Q is the net charge, where the electron charge is defined to be negative. m is the local magnetic moment (Bohr magneton). Furthermore, θ and ϕ are the Euler angles (degree) representing the spin orientation. For example, the line for the C atom in the first block,

C  -0.55502 -0.05167  0.35409   0.03654 -0.00779 -0.03763 -1394.21538 338.60117 -141.80824  -0.49099  0.00000  0.00000  0.00000

means that the coordinates are (−0.55502,−0.05167,0.35409) Å, the force is (0.03654,−0.00779,−0.03763) Hartree/Bohr, the velocity is (−1394.21538,338.60117,−141.80824) m/sec., the net charge is −0.49099, the local magnetic moment is 0.00000⁢μB, and the spin angles are (0.00000,0.00000) degree. Thus, this carbon atom is slightly negatively charged, and its local magnetic moment is essentially zero. Similarly, the net charge of the O atom appearing in the same step is −0.58253, and that of one of the H atoms is 0.20500. This indicates that the oxygen atom tends to accept electrons, whereas the hydrogen atom tends to lose electrons. In this way, the net-charge information contained in the md file allows one to visually inspect the tendency of charge transfer during MD or structural optimization. In the second block, the time changes to 0.200 fs, and the total energy changes to −56.61485 Hartree. The coordinates of the first C atom also change from (−0.55502,−0.05167,0.35409) Å to (−0.55777,−0.05100,0.35377) Å. Thus, by reading the blocks in sequence, one can continuously track the time evolution or optimization process of the structure and physical quantities.

Using this md file, the OpenMX Viewer can visualize, in addition to structural animation, net charges by Net Charge, local magnetic moments by Spin, forces by Force, and velocities by Velocity. Therefore, the md file is useful not merely as a history of coordinates, but as a format that records, in an integrated manner, the electronic-state and atomic-motion information at each step. An animatable xyz file has a similar format, but an important feature of the md file is that the cell vectors are explicitly provided by Cell_Vectors=. For this reason, the OpenMX Viewer can correctly display structural changes in periodic systems as well.

Furthermore, this md format is also consistent with the openmx/md format supported by dpdata, which is widely used for data conversion and preprocessing in DeePMD-kit [166]. In dpdata, System.Name.dat and System.Name.md are typically read as a pair, and OpenMX outputs can then be converted into data for machine-learning potentials. Therefore, this format is useful not only for visualization, but also from the viewpoint of connecting first-principles calculation data to the construction of machine-learning potentials.
